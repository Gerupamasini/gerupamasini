# なぎさ干潟 — 架空の干潟（flat.html）

葛西海浜公園（西なぎさ）をモデルにした、歩ける架空の干潟です。300 m × 300 m の範囲を一人称で歩けます。人や生き物は置いていません。干潟全体を 1 つのシード値から生成するため、同じシードなら毎回同じ干潟になり、シードを変えると別の干潟になります。

## 起動

```bash
npm install
npm run dev     # http://localhost:5173/gerupamasini/flat.html
npm run build   # dist/flat.html も一緒に出力されます
```

## 操作

| 入力 | 動作 |
| --- | --- |
| クリック | 視点操作を開始（ポインタロック。ロックできない環境ではドラッグで見回せます） |
| W A S D / 矢印キー | 歩く（泥地や水の中では遅くなり、長靴より深い水には入れません） |
| Shift | 走る |
| C | しゃがむ（目の高さ 0.5 m。水面や砂漣を間近で見るとき用） |
| H | 設定パネルの表示切替（時刻・潮位・雲・巻雲・霞・露出・品質・別の干潟） |

| --- | --- | --- |
| `seed` | 20261002 | 干潟のシード |
| `tide` | -0.42 | 潮位（m、T.P.）。-1〜+0.8 |
| `time` | 13.6 | 時刻（時、小数可） |
| `date` | 2026-04-18 | 日付（太陽の位置に使います） |
| `cover` / `cirrus` | 0.66 / 0.3 | 高積雲・巻雲の量（0〜1） |
| `haze` | 42 | 霞の濃さ（視程に相当） |
| `wind` | 1.0 | 風の強さ（水面のさざ波） |
| `q` | high | 品質 `low` / `mid` / `high` / `ultra` |
| `cam` | — | `x,z,方位角(度),仰角(度)[,目の高さ]` で初期視点を指定 |
| `exposure` | 自動 | 指定すると自動露出を止めて固定露出にします |
| `curve` | 1 | トーンカーブ（1: ACES、0: AgX） |

## 干潟の作り（src/flat/gen/）

座標はメートル単位で、x が東、z が南（海側）、y が上です。高さは T.P.（平均海面 0）で表します。

- **断面**: 公園（+4.6 m）→ 階段護岸 → 乾いた後浜とバーム → 前浜 → 低潮位テラス（リッジ・ラネル系の砂州、潮だまり、澪筋）→ 沖の干潟、の順に海へ下ります。汀線は複数の正弦波を重ねた曲線で、場所ごとに形が違います。
- **潮だまり**: 窪地の形を複数のローブとノイズで不規則にし、Priority-Flood（Barnes 2014）でこぼれ口の高さまで水を張ります。小さすぎたり浅すぎたりする水たまりや、岸沿いの幅 1〜2 セルの細い溝は捨てます。また、水域のそばでも敷居で隔てられた窪地には水を回り込ませません。
- **澪筋（クリーク）**: 正弦生成曲線で蛇行させ、蛇行の波長を川幅に比例させています。曲がりの外側を深く、内側を緩い寄州にした非対称断面です。非対称の度合いは曲率に応じて連続的に変えているので、蛇行の変曲点で岸が段になりません。川床は下流へ向かって単調に下がります。本流には樹枝状の支流が付きます。
- **底質**: 相対的な起伏、傾斜、澪筋の縁、遮蔽具合から砂・砂泥・泥を決めます。境界はノイズで崩してあります。貝殻の溜まり（澪筋の底、ラネルの底、漂着線）も持っています。
- **砂漣（風紋・波紋）の場**: 向きは「湾から入って汀線の法線方向へ屈折した波」を基準に、10 m 規模で平滑化した等深線に沿って曲げます。曲げる量は等深線法線の射影 `v vᵀ q` で決めるため、尾根や窪みを越えても向きが反転しません（反転させると継ぎ目・山形の折れ・同心円が出ます）。さらにノイズで ±25° ほど揺らします。澪筋の流れに沿う流水リップルは別の場として持ち、岸でクロスフェードします。乾いた後浜には風向きに直交する風紋を置きます。向きと波長は半精度浮動小数で保存しています。8 bit で保存すると量子化の 1 段ごとにフェーザーの位相がずれて、折れ線が描かれてしまうためです。

水の状態（`computeWater`）は潮位を変えるたびに計算し直します。外洋につながる海、こぼれ口まで溜まった潮だまり、澪筋を流れ下る引き潮の細流、風上側の吹送距離、最寄りの水までの距離とその水位、そして滑らかな地下水位を求めます。

## 描画（src/flat/render/）

- **地形**: CDLOD（頂点モーフィング付き四分木）。メガリップル（砂波、波長 0.6〜1.5 m）は近くでは実際のジオメトリにし、遠くでは陰影だけで表します。
- **砂漣**: フェーザーノイズ（Tricard 2019）を使い、カーネルの重なりでできる特異点を分岐・途切れとして出します。
  - カーネルは 1 セル先でちょうど 0 になる窓付きガウスにしてあり、3×3 探索で途切れません。
  - 打ち消し合いで局所波数がおかしくなった所（極端に詰まる、逆向き、45° 以上ねじれる）は振幅を落とし、そこで峰が終わるようにしています。
  - 峰の蛇行は、波数ベクトル方向へ滑らかに変位させるドメインワープで付けています。
  - 断面は非対称（符号付きで、急な面が +k 側を向きます）にし、トロコイド形、平らに削られた峰、峰の間を横切る干渉リップルの要素も入れています。
  - 近くでは局所 1 次元の視差（POM）と自己影を付けます。
- **地表の質感**: 粒子・貝殻片・小石（ボロノイ）、泥の珪藻膜、濡れた砂、谷に残る水膜、漂着線の海藻、還元泥。
- **水**: 地面の上に重ねる画面空間パスです。
  - 海・潮だまり・澪筋それぞれの水位で視線と交差させます。
  - さざ波は分散関係に従う 24 成分の波の和です。各成分の位相と振幅は自分の波長の数倍の距離でゆらぐので、峰が短く途切れ、格子模様になりません。
  - 吹送距離が短い潮だまりでは短い波しか育たず、突風（キャッツポー）の当たる所だけが荒れます。
  - 屈折、濁った湾の水による吸収と散乱、雲を含む空の反射（ぼかし量はさざ波の傾き分布で決めます）、SSR、太陽のきらめき、水底のコースティクスを描きます。
  - 海の縁では遡上波とその泡を描きます。
- **空**: 単散乱の大気と薄い海霞、光学的厚さとして扱う高積雲・巻雲、雲の影、遠くの対岸。
- **小物**: 二枚貝・カキ殻・小石はシェーダー側で描画中の地面（メガリップル込み）の上に置くので、浮いたり埋まりすぎたりしません。ほかに護岸、街灯、クロマツ、沖の防波堤、海苔ひびの杭、コンクリートブロックがあります。
- **後処理**: TAA（水面は反応マスクで履歴を短くしています）、ブルーム、ACES、軽いグレーディングと粒状感。

## ゲームへの組み込み

```ts
import { generateFlat } from './src/flat/gen/generate';
import { computeWater } from './src/flat/gen/water';
import { bakeNormals } from './src/flat/gen/normals';
import { FlatField } from './src/flat/FlatField';

const data = generateFlat(seed);                  // 重い処理なので Worker で実行します（src/flat/gen/worker.ts を参照）
const normals = {
  fine: bakeNormals(data.fine.height, data.fine.n, data.fine.cell),
  far: bakeNormals(data.far.height, data.far.n, data.far.cell),
};
const water = computeWater(data, tide);           // 潮位が変わったら計算し直します
const field = new FlatField(data, normals, water);
field.heightAt(x, z);      // 地面の高さ（m）
field.waterLevelAt(x, z);  // 水面の高さ。乾いていれば null
field.depthAt(x, z);       // 水深（m）
field.mudAt(x, z);         // 0 砂 … 1 泥
field.kindAt(x, z);        // 最寄りの水の種類（KIND_POOL / KIND_SEA / KIND_CREEK）
field.setWater(computeWater(data, newTide));
```

`field.uniforms` には、地形・底質・砂漣・水のテクスチャとシェーダー共通の定数が入っています。シェーダー側では `FIELD_GLSL`、`SEDIMENT_GLSL`、`WAVES_GLSL` を読み込んで使います。
