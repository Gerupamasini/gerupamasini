# Animation Specification — シロチドリ

**重要な制約**: 本環境では動画資料を開けなかった（research.md §0）。以下の周期・振幅は、文章資料と生体力学のスケーリング則から導いた値で、**信頼度 D** のものが多い。値はすべて `KentishPloverConfig.animation` にあり、動画解析ができる環境で差し替える前提で設計している。

アニメーションはキーフレームクリップの再生ではなく、**手続き的なレイヤー合成**で生成する（地面への足の固定、頭部の空間安定、個体差の適用が必要なため）。検証・外部ツール用に、各アクションを AnimationClip にベイクして GLB に書き出せる（`tools/export-glb.mjs`）。

## レイヤー構成

1. **Posture**: 体の高さ・ピッチ、首の伸展（relaxed ↔ alert ↔ hunched）、羽毛の膨らみ、翼の畳み具合、尾のピッチ。
2. **Locomotion**: 左右脚の位相、足の着地点（ワールド固定）、2骨IK（脛足根＋跗蹠）、趾の屈曲、体の上下・左右移動。
3. **Head/Gaze**: サッケード（素早い頭の回転）＋固視。移動中はワールド空間で頭位置を安定化。
4. **Action**: 1回性の動作（啄み、羽繕い、頭掻き、伸び、身震い、足ふるわせ、追い払い、離陸、着地）。
5. **Flight**: 羽ばたき周期、翼の捻り（下打ちで回内）、初列の開き。
6. **Micro**: 呼吸、瞬き（瞬膜）、羽毛の微動、重心移動。

## 01 Idle
呼吸で胸と背の輪郭がわずかに膨縮。サッケード→固視の頭部運動、たまに片側の目で上空を見る（頭を傾ける）。左右の脚への荷重移動（体を 0.5–1 mm 横に移し、反対側の足根間関節をわずかに曲げる）。瞬膜の瞬き。全ての周期は個体ごとの独立したノイズで駆動し、完全なループにしない。

## 02 Walk
- 脚: 遊脚期に趾を屈曲して持ち上げ（地面すれすれ、足の最大高 ≈ 6 mm）、接地直前に趾を広げ、踵（足根間関節）から荷重を受けて跗蹠が前傾。立脚後半に足根間関節が上がり、趾が最後に離れる。
- 頭: ワールド空間で位置を安定化（上下動の 80% を首で吸収）。チドリは明確な head-bobbing をしない（S32 の種差、観察の一般的記述）。
- 体: 立脚中期に最高点（倒立振り子）。

## 03 Run
歩行の2倍速再生ではない: デューティ比が下がり（0.45）、体幹が前傾（+8°）、首が縮み頭が体に近づき、脚の振り出しが大きく、足の最大高は低い（地面を滑るように見える）。頭はほぼ水平移動、体幹もほぼ水平（脚だけが速く動く「ゼンマイ仕掛け」の見え方。上下動は加速度制限で ≈0.2 mm）。

## 04 Stop / Observe
減速度 12 m/s² で 2–3 歩で止まる → 止まった瞬間に体がわずかに前に揺れ（慣性）首で吸収 → 頭を上げて左右をサッケードで見回す → 次の行動へ。

## 05 Forage Search
体を前傾させ頭を下げ、嘴を地面に向けて片目ずつ地面を見る（頭を傾けて側方視）。湿った泥では稀に foot-trembling（片脚を 8–12 Hz で 0.6–1.2 s 震わせる、S22）。

## 06 Peck
餌の方向へ頭を向ける → 首を引いて照準（0.1 s）→ 素早く突き出し（0.08 s、嘴先端が目標に届くよう首＋体の前傾で到達を計算）→ 餌の種類ごとの処理（ゴカイ: 引き抜き 1–2 回、カニ: 首振り、小型: 即座に嚥下）→ 頭を戻す。

## 07 Preen（variants）
breast（胸）、flank（翼の下）、scapulars（背・肩）、wing（初列を嘴でしごく）、tail/oilGland（尾脂腺へ嘴を当ててから羽へ）、scratch（**間接的頭掻き**: 翼をわずかに下げ、その外側から脚を上げて頭を掻く, S33）、wingStretch（両翼を背上に上げる, S33）、shake（身震い: 羽毛を膨らませ体を揺する）。

## 08 Rest
- oneLeg: 片脚立ち（S31）、首を縮め頭を肩に沈める、下瞼が上がり半眼〜閉眼。
- tucked: 頭を後ろに回し嘴を肩羽に差し込む（シギチ一般, C）。
- sit: 腹を地面につけて伏せる（塒、乾いた砂）（C）。
いずれも周期的に目を開けて周囲を確認（警戒の間欠）。

## 09 Alert
首を伸ばし頭を上げる（頭頂高 +10–14 mm）、体をやや立てる、羽毛を締めて細く見せる、脅威に片目を向けて頭を固定（サッケードの頻度が下がり、脅威方向で固視）。

## 10 Takeoff
しゃがみ（体高 −8 mm, 0.12 s）→ 脚の伸展で跳躍（0.06 s）と同時に翼を上に展開 → 最初の下打ち → 高頻度の羽ばたきで上昇。

## 11 Flight
- 下打ち（周期の約55%）: 翼を完全伸展、前縁を下げ（回内）、初列は閉じた面。
- 上打ち: 手首を屈曲して翼を体に寄せ、初列の間に隙間。小型鳥の flexed-wing upstroke（一般則）。
- 巡航では時折短い滑空（翼を半分畳む）を挟む。体のピッチは加速度と上昇率から、ロールは旋回の向心加速度から計算。
- 脚は後方に引き込み、腹部羽毛の下に収める（C）。

## 12 Landing
減速のため翼を高迎角に立てて羽ばたきを大振幅化 → 尾を広げて下げる → 脚を前に出す → 接地で脚が衝撃を吸収（しゃがみ）→ 2–3 歩走って止まる → 翼を上げてから畳む（着地直後に翼を背上で一瞬立てる動作はチドリ類でよく見られる、C）。
