# ヤマメ骨格資料（追加画像 x01・k01〜k06）の解析 — 3D リグ・頭部形状の根拠

> 作成: 魚類骨学者兼3Dリガー役（2026-10-02）。対象は、ユーザーが追加提供した軟X線側面像 **x01.jpg**（1280×436、群馬県立自然史博物館 紀要、冷凍個体）と、透明骨格標本の商品写真 **k01〜k06.jpg**（透明工房、瓶の高さ6.0 cm）。
> 方針は「見えるものだけ。想像で補完しない」。座標はすべて**各画像の元画素**（左上原点、x右・y下）。ズームと局所コントラスト強調（自動コントラスト、x01 は背景差し引き）で読み、計数は numpy による画素プロファイルのピーク検出で行った。
> 信頼度: **high**＝別画像または別手法で独立に一致、**med**＝明瞭だが不確かさの要因が残る、**low**＝推定・外挿・解像度不足。
> 既存所見（r15 の P ランク F-01〜F-11、s01.jpg）と比較する。標本の種・成熟状態・SL は未確認（k02 に「ヤマメ」「…s masou masou」、k04 に「masou masou」のラベル文字が写るが、同定はしていない）。
