**基準個体(reference_adult)** : `sl_mm = 190`(FL≈211 mm, TL≈218 mm, 全長約22cm)。[E: 資料の河川型「全長30cm以下が典型」[r01v 採用値1, B]の範囲内で、体長-体重式の有効域(FL<=21.9cm)に収まる最大級の値のため]。式 W=0.0106·FL^3.0397 (FL 1.9–21.9cm) [r01v 採用値6, A単一] から約 113 g。FL 10/15/20cm = 11.6/39.8/95.5 g (再計算) [r01v V-10]。**FL>21.9cm は式の外挿**(その場合 b≈3.0 と K≈1.1–1.2 を仮定、暫定)。

### 2.2.3 ロール偏りの検証(背側が手前に傾く写真で体高が過大になる問題)

- カタログ上、70枚の多くで背側が手前に15–60度ロールしている [P: catalog view_tilt_note]。ロールすると背面が輪郭に加わり体高が過大に出るとの懸念があった。
- 再集計の結果: 体高最大値は M-all 0.242 → M-Y 0.241 → M-T 0.241 → M-Y8 0.242。最大体高位置は 0.445 → 0.439 → 0.423(M-Y8, n=8)。**ロールの強い写真を外しても体高は変わらず(±0.001)、偏りは SD(0.024)に比べ無視できる**。ただし (a) 「高信頼」群も全てカタログ記載の自己申告で、真の側面写真は少数、(b) 全群が同じ撮影条件(上から見下ろし、横たわる魚)を共有するため共通の偏りは検出できない、(c) 横倒しで腹が潰れ体高が大きくなる記述あり(p002) [P: landmarks_c01_A p002 notes]。結論: **0.24 を既定、0.22–0.26 を妥当域とする**(暫定)。
- 尾部側(s>=0.75)は高信頼群ほど細い(0.80で 0.149 → M-Y8 0.135)。尾柄の細さは写真ロールより個体群差の影響が大きく、n=8 では判断できない。
