# 08 不足している資料(ヤマメ Oncorhynchus masou masou 河川型 超写実3Dモデル仕様書)

対象読者: 利用者(ゲーム開発者)と実装エージェント。本章は 01〜07 の各章と research の Gaps から、**実装に効く不足資料**を重要度順に集約する。新しい数値は作らない。各行の根拠は元の章の「不足資料」節を参照する。

## 8.0 読み方

**重要度**

| 記号 | 意味 |
|---|---|
| ◎ | 実装を左右する。欠けたままだと多数のパラメータが [E](設計値)のままになる、または実装方針(リグ・LOD・描画方式)が変わる |
| ○ | 精度・説得力を左右する。[E] でも動くが、実魚との差が見えやすい |
| △ | 品質向上・将来拡張・権利整理 |

**タグ**: `[spec02 #4]`=02 章の不足資料節の番号。`[spec05 §5.10.2 #1]`=05 章の同節。`[spec01 §1.9 #3]`=01 章の順位。`[spec07 §7.8.3 #3]`=07 章の未検証事項。

**共通の背景**: 検索は題名・URL・要約しか返さず、論文・図鑑の**本文は 1 本も読めていない**。WebFetch は遮断(EGRESS_BLOCKED)。表・図にしか無い値(係数、%SL 表)は全て未取得である [spec01 §1.0.1]。したがって「資料が欲しい」の大半は、**本文・表・図へアクセスできるようにすること**で解消する(8.4 のドメイン許可)、または**利用者が実物の写真・映像・標本を提供すること**で解消する(8.3)。

## 8.6 利用者に依頼する撮影・提供ガイド(実行手順)

### 8.6.1 側面写真(◎1, ◎6)

| 項目 | 指示 |
|---|---|
| 構図 | 魚の体側に**垂直**にカメラ。魚は横向きで、背が上、頭が左(または右で統一)。左右両側を撮る。鰭(胸・背・臀・尾)を自然に開く |
| スケール | 定規(mm)またはメッシュ・格子を**魚と同一平面**に置く。撮影後に尾叉長と体長をノギス/定規で記録 |
| 色 | グレーカード(18% 反射)または ColorChecker を魚の横に同一フレームで。日陰または曇天。フラッシュを使わない。RAW 推奨。ホワイトバランス固定 |
| 状態 | 濡れた状態を基本。水膜の反射が強い面は偏光フィルタ、または魚を傾けずに撮る |
| 属性メモ | 採集地(河川名)、日付、水温、性別(分かれば)、産卵期か、放流魚か(鰭の欠け) |

### 8.6.2 断面・体幅・頭部(◎2, ○15)

背面・腹面・正面・斜め前の写真(スケール付き)。口を閉じた/大きく開けた頭部の真横接写、口内(舌・歯)、鰓蓋を開けた状態、虹彩の接写。

### 8.6.3 骨格(◎3)

透明骨格標本の**左側面全身**(尾部まで)、頭部のみ真横・背面・口蓋、口を開いた状態、鰓蓋を外した状態。標本ラベル(種名)も写す。顎の可動角を測るなら、標本を固定し、分度器または基準線つきで開口 0°/最大を撮影。

### 8.6.4 映像(◎4, ◎5)

| 項目 | 指示 |
|---|---|
| フレームレート | 摂餌・開口: ≥250 fps(スマートフォンの 240 fps でも一次確認は可)。C-start: ≥500 fps が望ましい |
| 視点 | 側面(カメラは水槽/水路の側壁に垂直)。可能なら背面も同時 |
| スケール | 水路の背面に既知間隔の格子 |
| 記録 | 水温、流速(流下物の通過時間)、魚の体長(SL)、水深 |
| 内容 | 定位、1/2/3 BL/s の定常遊泳、加速、旋回、障害物後流、刺激に対する逃避(音・影)、餌への迎撃と復帰、呼吸(鰓蓋) |
| 権利 | 自分で撮影した映像、または利用許諾が明記されたもの。第三者の映像は参照(視認)のみ |
