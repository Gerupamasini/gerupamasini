# 05 アニメーション仕様(ヤマメ Oncorhynchus masou masou 河川型)

対象読者: 利用者(ゲーム開発者)と実装エージェント。three.js r186 / WebGLRenderer 前提 [threejs_audit_b §1]。

## 0. 読み方・規約

**出典タグ**: `[r08 F-12, A]`=ノート番号+Finding番号+証拠ランク。`[r08 V-10, A単一]`=検証ファイルの項目(CONFIRMED-SINGLE等を併記)。`[P: ...]`=写真集計。`[E: 理由]`=資料の裏付けが無い設計値。`PROXY:種名`=ヤマメ以外の値。`[S/T audit_b ...]`=three.js のソース確認/Node 実行。

**最重要の前提**: ヤマメの過渡運動・鰭運動・開口を直接測った資料は 1 件も無い [r09 §1-1]。ヤマメ成魚の f−U も無い [r08 Gap5]。遊泳の数値の大半は PROXY:ニジマス(O. mykiss)で、ヤマメ稚魚(全長 4.4〜8.8 cm)の実測 2 件のみ例外 [r08 F-10, F-11]。したがって本章の数値は **「ニジマス実測の範囲に収まる [E] 初期値」** であり、全パラメータを外部設定(JSON)に出して差し替え可能にすること。

## 5.2 遊泳の体波モデル

### 5.2.1 体波の式
中心線の横変位(片振幅)と回転ボーンへの変換:

```
y(s,t)  = A(s) · sin(k·s − ω·t)         k = 2π/λ,  ω = 2π f   (s: SL 単位)
y'(s,t) = A'(s)·sin(ks−ωt) + A(s)·k·cos(ks−ωt)
θ(s,t)  = atan(y')                       … 区間中点の接線角
bone_j.quaternion = restQ_j ⊗ R_Y( θ_j − θ_{j−1} + bias_j )     (θ_{−1}=0、j=0 は絶対ヨー θ_0 = 頭部ヨー)
```
[S/T audit_b §1.3]。bias_j は 5.4 の旋回オフセット。波速 c=λ·f(SL/s)で、**c > U(前進速度)を常に満たす**(抗力低減の必要条件、ロボット魚 PROXY)[r13 F-43, A PROXY]。

### 5.2.2 振幅包絡 A(s): 採用する関数形(区分線形、[E])
**検証での扱い**: ① Di Santo 2021 の「二次多項式」は**関数形のみ**参考(44 種・遊泳モードは連続体)。90/92%・60%・r=−0.89 は再現できず不記載、係数 a0,a1,a2 は未取得 [r08 V-01]。② サイスの 3 点値 A(0)=0.02, A(0.2)=0.01, A(1.0)=0.10L と二次式 A=0.02−0.0825x+0.1625x² は**採用不可**。3 点は区分線形なら要約本文(最小は頭から 0.1L、以後ほぼ直線増加)と両立するが、3 点値自体が未検証(PROXY:Pollachius virens)[r08 V-02, §2-A]。

**採用**: 定性のみ援用(頭は尾端より小さいが非ゼロ、最小は頭近く、以後ほぼ直線的に尾へ増加)し、数値は [E]。
```
A(s) = A_tail · interp(s ; knots)      knots (s → 相対値):  0→0.20,  0.10→0.09,  0.20→0.10,  1.00→1.00
```
s≥0.2 の傾きは 1.125·A_tail/SL。**A_tail=0.10 SL(片振幅)** とした理由 [E]: 尾端振幅は約 0.1〜0.2 L で速度にほぼ依存せず大型ほど相対的に小さい [r08 検証採用表, A単一]。ヤマメ稚魚は振幅/全長≈0.12(定義不明、振動数・速度に依存しない)[r08 V-03, A単一]。下記の尾鰭後縁の観測量が A_te=1.33·A_tail=0.133 SL(≒0.11 TL)となり両者の範囲に入る。

| パラメータ | 既定 | 範囲 | 備考 |
|---|---|---|---|
| env_knots_s | [0, 0.10, 0.20, 1.0] | 頭最小位置 0.05〜0.15 | [E] |
| env_knots_rel | [0.20, 0.09, 0.10, 1.00] | 頭比 0.10〜0.30 | [E] 頭比 0.2 はサイスの 0.02/0.10 と同値だが未検証値なので根拠にしない |
| A_tail(s=1) | 0.10 SL | 0.07〜0.14 | 個体差。後縁振幅 A_te=A_tail·√(1+(k·L_fin)²)=1.33·A_tail(L_fin=0.125SL、剛体鰭仮定の算出) |
| head_yaw(算出) | 約 ±10° | | s=0 の接線角振幅 √(A'²+(A(0)k)²)=0.17rad(算出)。頭部ヨーのニジマス実測は未取得 [r08 Gap2]。`head_yaw_gain` 0〜1.5 で調整 |

二次関数形も切替可能にしておく(`env_type: "quad"`、係数 a0..a2 を入力)。係数が取得できた時に差し替える。

### 5.2.4 速度 → (f, A, 体波)の連続写像
駆動量は**対水速度 U_w**(流れの中で定位するなら対地 0 でも U_w=流速)[r08 F-30, M(物理原理、確信度高)]。
```
U_bl = U_w / SL                                  (BL/s)
f    = softmax( f_idle , U_bl / S_L )            S_L = 0.70 (ストライド長, 尾1打で進む SL 数)
A_tail(U_bl) = 0.10 · g(U_bl)                    g = 0.55 + 0.45·smoothstep(0, 1.0, U_bl)   (速度が上がっても 1.0 のまま)
A_tail は加速中 ×1.25 (Acceleration 状態、時定数 τ_a=0.4 s で 1.0 へ戻る)
f, A, U は 1 次遅れ(τ_f=0.25 s, τ_A=0.30 s, τ_U は 5.3)で追従する
```
| U_bl (BL/s) | 0 | 0.5 | 1.0 | 1.5 | 2.5 | 4 | 6 | 8 | 10 |
|---|---|---|---|---|---|---|---|---|---|
| f (Hz) | 0.6 | 0.71 | 1.43 | 2.14 | 3.57 | 5.7 | 8.6 | 11.4 | 14.3 |
| A_tail (SL) | 0.055 | 0.08 | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 | 0.10 |

**根拠と制約**
- 速度は主に周波数で変え、振幅は速度に対し変化が小さい [r08 検証採用表, A単一]。ニジマス全長 5.5〜56 cm で a は速度非依存・大型ほど相対的に小さい [r08 F-06, A]。
- 低速の自由遊泳の尾鰭打数 1〜2.5 Hz(PROXY:ブラウントラウト、≒1 BL/s、好む打数 1.0〜2.0)と、ニジマスの加速度ロガー 1.27±0.40, 1.40±0.5 Hz(PROXY)が整合 [r13 V1, A(周波数帯は MULTI)]。S_L=0.70 で 1 BL/s→1.43 Hz。
- S_L=0.70(範囲 0.55〜0.85)は [E]。f≒1.4·(U/L) の算出式(ストライド長 0.6〜0.8)は独立の裏付けが得られていない [r08 F-27, M]。
- **ヤマメ稚魚の 20.8〜39.1 Hz は巡航値として使わない**。水路平均流速 48〜137 cm/s は 60 分臨界速度 16〜41 cm/s の 1.2〜8.6 倍で、短時間の高速値 [r08 §2-B, V-03]。**成魚の f−U を稚魚と低速値の線形補間で作ることも不採用** [r13 §3-B]。
- f_idle=0.6 Hz は静水中の微小な尾の揺れ [E]。
- Kármán 歩行・entraining は 5.3 の任意モード(既定オフ)。

## 5.4 旋回

### 5.4.1 中心線曲率の付与
体全体を連続的に湾曲させる。各ボーンに曲率オフセットを足す(波は変えない):
```
bias_j = η · κ_turn · g(s_j) · Δs        Δs = 1/24,  κ_turn = 1/R (符号付き, 左 +)
g(s) = smoothstep(0, 0.15, s) · (1 − 0.5·smoothstep(0.8, 1.0, s))
```
定常旋回では体が軌跡に沿うので体軸曲率≒1/R(η=1、0.7〜1.2)[E: 幾何学的な近似]。例: R=2 SL で 1 関節 +1.2°、R=0.6 SL で +4.0°(波の 12° に加算)。旋回の方式は他に、前部筋の非対称収縮・波形オフセット・曲率パルス(ダニオ、PROXY)・C/L 字があり、パルス方式は定常遊泳とも接続できる [r13 §1-12]。ヤマメの通常旋回の曲率は未取得なので上の連続オフセットを採用する [E]。

ヨー角速度は ψ̇ = U·κ_traj。ニジマスが胸鰭で旋回するときの体のヨー回転は 4〜41 °/s、横力は平均 2.7 mN(体長・水温不明)[r10 V-01, A単一 PROXY]。絶対値は流用せず、「低速の旋回は数十 °/s オーダー」という目安にだけ使う。既定の 1 BL/s・R=2 SL では 29 °/s となり範囲内。

```
pec_in  = 5 + 30*w_hover + 65*w_brake ;  pec_in_sweep = 20*q    // 内側は後方へスイープ
speed_close = smoothstep(1,4,U_bl)               // 腹鰭を閉じる
```

## 5.7 ブレンド方式

### 5.7.1 担当の分離(1 ボーン 1 所有者)
| 所有 | 対象 | 方式 |
|---|---|---|
| プロシージャル(CPU, 絶対値書込み) | spine_00..23、頭挙上、jaw/hyoid/opercle(呼吸+ストライク合成)、eye、胸鰭 abd、腹鰭、背・臀鰭、尾鰭 spread、モーフ影響度 | 毎フレーム `restQ ⊗ 値` |
| 固定クリップ(AnimationMixer, additive) | 各鰭の微小ふらつき(2〜4 s ループ)、胸鰭スカルの揺らぎ、咳(鰓蓋)、休息ポーズの微調整 | `makeClipAdditive(clip,0)` 後に weight=振幅、timeScale=周波数。**脊椎にはトラックを持たせない** [audit_b §1.4-1] |
| 同一ボーンを両方が触る場合 | | audit_b §1.4-B の 4 ステップ(前回 mixer 出力を戻す→`mixer.update`→δ=restQ⁻¹⊗mixerOut→proc ⊗ δ)。mixer は値が変わった時だけ書くため素朴な `q.multiply(δ)` は蓄積バグ [T audit_b T3-a, T14-a] |

### 5.7.2 毎フレームの更新順序 [S/T audit_b §1.2]
1. `THREE.Timer`(`Clock` は r183 で非推奨)。`dt = min(delta, 1/20)`。
2. 行動層 → モード状態、目標 U・κ、f・A・φ(φ += 2π·f_disp·dt)。
3. (同一ボーン併用時のみ)前回 mixer 出力を戻す。
4. `mixer.update(dt)`(副ボーン)。
5. プロシージャル上書き(脊椎・顎・鰓蓋・眼・鰭・モーフ)。
6. 個体の移動・向きは **mesh と root の共通の親 Group** で(root ボーンを動かさない)。
7. `renderer.render()` が `updateMatrixWorld` → `skeleton.update()` を実行(手動は影を間引く場合のみ、必ず先に `updateMatrixWorld(true)`)。
8. 逆順(プロシージャル→mixer)は mixer に上書きされるので禁止。`stop()`/フェード終了で original に戻るため、手続き値が消える点に注意 [audit_b §3-6]。クロスフェードは `crossFadeFrom/To` が incoming を `play()` しないので別途 `reset().play()` [audit_b §1.4-7]。

### 5.7.3 カリング
ロード時に休止姿勢で `computeBoundingSphere()` し、半径に「最大横振幅+頭の振れ」の余白を足して固定。クローン前に計算(複製される)。毎フレーム再計算は 5k 頂点で約 2〜2.5 ms なので禁止 [audit_b §1.5]。強い曲げでは休止球から最大 2.25(体長 5 で休止球半径 2.62)はみ出した。実際の泳ぎ(尾端 ≲0.12〜0.2L)での必要余白は未計測 [audit_b §4]。
