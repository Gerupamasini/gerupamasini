# 04 行動仕様(ヤマメ Oncorhynchus masou masou 河川型)

> 対象: Three.js 上のヤマメの行動モデル。読者はユーザーと実装エージェント。
> 根拠: research/r11, r12, r13, r16(映像所在), r09, r08 と各 `_verification`、photo_analysis/catalog_c01..c07.json。
> **前提(最重要)**: ヤマメ(河川型)の焦点流速、縄張り実測面積、反応距離、警戒距離(FID)、逃避後の再出現時間、日周活動量は**どの資料でも数値が取れていない**。検索は要約のみで全文未読。行動の骨格は定性資料とPROXY(他種)で組み、**数値は全て config の調整値**とする。

## 0. 出典タグ規則

| タグ | 意味 |
|---|---|
| `[rNN F-xx, A/B/C/M]` | 調査ノート番号・Finding番号・証拠ランク。`v:` を付けた場合は検証ファイルの判定(CONFIRMED-SINGLE 等) |
| `PROXY:種名` | ヤマメ以外のデータ |
| `[P: catalog posture n=XX]` | ユーザー写真70枚のカタログ集計(目視推定、スケール校正なし) |
| `[E: 理由]` | 資料の裏付けは無いが実装上必要な設計値 |

**体長の規約(A-02)**: 本章の `BL`・`bodyLength_m` は SL(標準体長)と同一(BL≡SL、単位 m)。FL を使う式(縄張り式など)は FL=1.109·SL(02 §2.1)で換算してから入れる。既定個体は SL=0.19 m(02 §2.1)。

**写真の扱い**: アマゴ/交雑疑い(p019, p037, p057, p059, p070)、種不明確(p031, p005 conf0.4, p026 conf0.45)、混在(p015)、イワナ型(p027)、コイ科(p020)はヤマメ統計から除外または「暫定」とする。釣獲後・水槽・手持ち写真(60%+16%)は野外行動の根拠にしない [r11 F-29, P]。

## 4.1 設計原則と階層

### 4.1.1 原則

1. 5層に分け、上の層は下の層へ**高水準コマンド**(目標速度・向き・姿勢モード)だけを渡す [r13 F-01/F-03, B: Tu & Terzopoulos 1994 の「行動層→運動制御器」分離。ヤマメ固有の根拠ではない]。
2. 恐れ(警戒)の判定を**最初**に行い、閾値超なら他の欲求を計算しない [r13 F-02, B]。どの欲求も閾値以下の既定は「定位(待機)」[E: Tu&Terzopoulos は wander が既定。ヤマメの待ち伏せ型に置換、r13 §1 項28 設計案]。
3. 意思決定は Utility 型+小さな状態機械。直前の選択に**モメンタムボーナス**またはヒステリシス(新規が現行を一定マージン超で切替)を付ける [r13 §1 項30, B/C]。倍率・マージンの値は資料に無く [E]。
4. 定位点(focal point)の選択は inSTREAM/NREI の考え方のみ借りる: 移動半径内の候補セルを評価し最良へ [r13 F-06, A]。ドリフト捕食モデルは総エネルギー獲得を**約2倍過大評価**した報告がある(Hughes ら2003、二次情報 v:CONFIRMED-SINGLE)ため、**スコアは定位点どうしの相対比較にのみ使う** [r13 v:V6]。個体群動態・成長の再現はしない。
5. 全パラメータに provenance(rank/PROXY/E)を持たせ、ExplainTrace(4.7)に出す。

### 4.1.2 層と更新頻度

| 層 | 入力 | 出力 | 更新頻度(既定) | 備考 |
|---|---|---|---|---|
| L1 Perception | 世界状態(流速場、物体、プレイヤー、光、水温) | `PerceptSnapshot` | 近景 15 Hz / 中景 5 Hz / 遠景 1 Hz | [E: 視覚検出は毎フレーム不要。LOD段階は r13 §1 項32 の High/Med/Low/Off 構成例、周期の数値は資料なし] |
| L2 Internal state | Percept、前状態 | `Needs{F,H,T,R}`、個体特性 | 5 Hz(近景) | F=警戒, H=空腹, T=縄張り刺激, R=休息/低温 [r13 F-02 の H・F を踏襲、T・R は新設 E] |
| L3 Decision | Needs、候補評価 | `StateId`+`LocomotionGoal` | 近景 10 Hz / 遠景 1–2 Hz。割り込み(Startle)は即時 | [E] |
| L4 Steering | Goal、流速場、障害物 | `SteerCmd{speed_rel_water, heading, rate_limits}` | 毎フレーム | Reynolds 3階層(action selection/steering/locomotion) [r13 §1 項31, B]。flow field following、arrival、obstacle avoidance を使う |
| L5 Locomotion | SteerCmd | 体波(周波数/振幅)、胸鰭モード、口・鰓蓋 | 毎フレーム | 本章は SteerCmd 仕様まで。体波パラメータは 05 章。04 の State から 05 のモード・鰭プリセットへの対応は 05 §5.3.5 |

LOD(AI): カメラ距離で High/Medium/Low/Off。Off は停止でなく低コストで状態のみ進める [r13 §1 項32, B/C]。距離は描画 LOD に合わせ、06 §6.8.1 の LOD 区分(SL 倍)を参照する(固定距離の例示は置かない)[E]。

### 4.2.3 不採用(検証で採用不可。使わない)

| 値 | 理由 |
|---|---|
| 定位点滞在 81%・能動採餌 14%・餌の約2/3は定位点より下流で捕獲 | 4検証とも出典を特定できず(r11 v:V-09, r12 v:C10, r13 v:V7, r09 v:V05)。別研究の「81%」と混線の疑い。**状態遷移の割合に使わない** |
| 餌の53%が陸生無脊椎動物をサクラマスの値とすること | 種別値と食い違う(56.7%/22.6%)。通年一定でもない |
| 登川 43.4/約20 cm/s を焦点流速とすること | 利用場所の平均、測定法不明 |
| 縄張り式を FL20–25 cm へ外挿した 3.7/6.6 m² と円換算半径 | r11 v が不採用。4.6 で FL15 cm 頭打ちにして回避(r12 v は外挿明記で許容、差は4.10) |
| 縄張りを固定円として扱う | 式は面積のみ。形・定位点との関係は不定 |
| 「夏最高 25℃」「20℃ 超で活動低下」を行動閾値とすること | 前者は生息上限の目安、後者は出典で確認できない |
| 春・夏・秋の摂餌時間帯スケジュール | 出典未特定、昼間(6–18時)のみの調査の可能性 |
| 旋回半径 0.17–0.18 L を体軸曲率上限・通常旋回に転用 | 高速スタートの**重心軌跡**の最小半径(r13 v:V3) |

選択可能な状態(優先60以下で割り込みでないもの)を、各 `S_i = w_i · Π_k c_k(x_k)`(`c_k` は 0..1 の応答曲線)で評価:

## 4.6 操舵(Steering)

### 4.6.1 方位・定位(rheotaxis)

- 既定の向き = 局所流の上流方向(`heading = -normalize(u_local)`)。ヤマメは上流を向いて定位 [r11 F-23, C]。
- 感覚基盤は側線(流れの空間構造)・視覚(透明度に制限)・前庭/触覚(流されの検出)で、単独でも成立するが各に限界 [r12 F-27, A レビュー]。→ 暗所・濁りでも向きは保つが、`visibility_m` が小さく `u_local` が弱い場合は向きのばらつき `σ_heading` を増やす [E]。
- 水槽写真で複数個体が同方向を向く例(p014, p015, p018, p041)があるが、流向は写真から判別不能で、群れ行動の可能性を排除できない [r12 F-14, P]。

### 4.6.3 定位点の選択・復帰・移動

定位点スコア(候補点 `p` について、**相対比較のみ**):

```
score(p) = prey_flux(p)·cap_prob(u_p) − swim_cost(u_p) − intercept_cost − risk(p)
         + w_cover·cover(p) − w_turb·turb(p) − w_rank·conflict(p)
```
- `prey_flux`: 近傍の速い流れが運ぶ餌量(低流速点が速い流れに隣接するほど高い) [r12 F-16, A]。
- `cap_prob(u)`: 4.6.4 の関数。
- `swim_cost(u)`: 対水速度が小さいほど安い [r12 F-28, A]。
- `risk`: 浅さ(≤20 cm)、カバーまでの距離 [r12 F-41, A PROXY]。
- `conflict`: 優位個体の近傍(体長比で重み) [r12 F-31, A]。
- 係数は全て [E](資料なし)。サイズ依存の符号(大型ほど低流速側か高流速側か)は資料間で逆(グレイリング r12 F-17 B vs ニジマス・ブラウン r12 F-35 B)のため**符号を固定せず** `size_flow_sign` で調整。
- 探索半径(移動可能範囲) `search_radius = R_max·logistic(BL)`(inSTREAM v7.2 の形 [r13 F-06, A]。`R_max`=10 m と勾配は [E]。資料にあるのは「体長のロジスティック関数が最大半径へ近づく」形のみ)。
- 候補評価周期: `reloc_eval_period`=30 s [E]。

復帰(arrival): 定位点まで `arrive_radius`=0.3 BL で減速、最終 `v` を局所流速に合わせる [r13 §1 項31 arrival, B]。

## 4.7 ExplainTrace(「なぜその場所/向き/今」を説明する記録)

### 4.7.1 記録ポイント

状態遷移時、定位点選択/変更時、迎撃・逃避の開始時、割り込み時に必ず記録。加えて 1 s ごとにサンプル。リングバッファ容量は個体あたり 256 件 [E]。

```ts
interface TraceEntry{
  t:number; fishId:string; layer:'L1'|'L2'|'L3'|'L4'; event:string;
  state:{from:StateId; to:StateId; interrupt:boolean; dwell_s:number};
  candidates:{state:StateId; S:number; terms:Record<string,number>; momentumApplied:boolean}[];
  needs:{F:number;H:number;T:number;R:number};
  why_here?:{   // 定位点の理由
    focalId:string; u_cms:number; depth_m:number; heightBD:number; coverDist_m:number;
    scoreTerms:Record<string,number>; rejectedAlt:{pos:Vec3; score:number}[]; rankReason?:string };
  why_heading?:{ source:'rheotaxis'|'threat'|'prey'|'territory'|'cover'; flowDir:Vec3; headingErr_deg:number; weight:Record<string,number> };
  why_now?:{ trigger:'prey'|'threat'|'intruder'|'hunger'|'temp'|'light'|'timer'; targetId?:string; dist_m:number; thresholdName:string; thresholdValue:number; p_roll?:number };
  paramsUsed:{name:string; value:number; prov:Provenance; proxy:string|null}[];  // PROXY/E を明示
  env:{temp_C:number; light_lx:number; visibility_m:number; u_local:number};
}
```

### 4.7.2 出力要件

| 質問 | 出力 | 例 |
|---|---|---|
| なぜその場所に? | `why_here`(スコア項の寄与順、棄却された代替点) | 「低流速ポケット+近くの速い流れ+カバー 0.4 m。優位個体(体長比1.3)の定位点を避けた」 |
| なぜその向き? | `why_heading` | 「上流方向(rheotaxis)。誤差 3°」「Alert中、脅威方向へ頭を向けた」 |
| なぜ今泳いだ? | `why_now` | 「餌候補が反応距離 0.28 m に入り、Strike の S=0.82 が Hold の 0.33 を超えた。cap_prob=0.65 でロール成功」 |

`paramsUsed` の `prov` が E/PROXY のものは UI で色分けする(「この判断は資料の裏付けが無い値に依存」を可視化)。

## 4.8 個体差

### 4.8.1 特性(Traits)

| 特性 | 既定分布 | 範囲 | 効果 | 根拠 |
|---|---|---|---|---|
| `wariness` | 正規(0.5, 0.15) | 0–1 | `alert_dist`・`flee_dist` 係数 ×(0.7–1.4)、`hide_dwell` ×(0.5–2)、`tau_F` | [E]。人の多い川の野生個体は神経質 [r11 F-23, C] |
| `boldness` | 1−wariness の相関(ρ=−0.7)+ノイズ | 0–1 | 迎撃を開始する F の上限 `F_strike_max` | [E] |
| `territoriality` | 正規(0.5, 0.2)、**rank に比例して上限** | 0–1 | `T_disp`, `T_chase`, 防衛域 | [E]。優位個体が攻撃の大半(67%) [r12 F-39, A PROXY] |
| `body_length` | 個体群分布(parr 10–16 cm、adult 18–30 cm の例) | – | 順位、FID、縄張り | 順位は体サイズ順 [r11 F-12, A]。FID は体サイズと正の相関 [r12 F-42, A 魚類一般]。範囲は [E] |
| `forage_mode` | drift(優位)/patrol(劣位・餌乏しい時) | – | SlowPatrol の許可 | [r12 F-20, A PROXY charr] |
| 日内リズム位相 | ±1 h の個体差 | – | `daylight` 応答の位相 | [E]。日周の資料なし |

### 4.8.2 禁止する組合せ(生物学的に不自然)

1. 小さい個体が大きい個体より良い定位点を恒常的に占める(`rank` は体長順、逆転は餌・先住の例外 ≤10% の個体のみ) [r11 F-12, A / r12 F-17, B PROXY]。
2. `wariness>0.8` かつ `hide_dwell<20 s`、`boldness>0.8` かつ `flee_dist` が平均の 1.2 倍超。
3. 低 rank かつ高 `territoriality`(劣位個体が頻繁に Chase を起こす) [r12 F-39, A PROXY]。
4. 水温 ≥12℃ で夜行性が昼より優勢、あるいは水温 ≤8℃ で昼の活発な摂餌と追い払い [E: PROXY 閾値の範囲外を禁止]。
5. 成魚が通常時に高密度の群れ(0.1–1 BL の間隔)で定位する(水槽写真は根拠にならない) [r11 F-28]。
6. 産卵行動(SpawnDig 等)を `spawn_season`(4.4.4)以外に発生させる。雄の婚姻色(黒ずみ・桜色雲状斑)は産卵期のみ [r11 F-22, B]。
7. 瀬で `height_above_bed` が 0.1 体高未満の持続的な浮上(0.25–1 体高の範囲外) [P: catalog posture n=5]。
8. 稚魚(2.4–3.3 cm)を成魚と同じ流速に定位させる(稚魚は浅く緩い所) [r11 F-04, A 未確認]。
