## 要判断(直していない)

1. 05 の T12(Stage1+2)に Webb 1976 の「主加速段階 0.07/0.10 s」を充てているが、同一区間かは資料で未確認。04 の `faststart_accel_stage1`(15.6 m/s2)も「Stage1」でなく「主加速段階」の平均。名称変更は 07 章等への波及があるため据え置き。
2. 視覚刺激潜時が 04 `startle_latency_visual_s`=0.06 s(0.03–0.15)と 05 の 50–200 ms(警戒度で 200→50 ms)で不一致。両方 [E]。どちらかに統一するか決めてください。
3. 04 `v_cruise`=1.0 BL/s(徘徊、PROXY 1–2.5 Hz)と 05 Cruise=2.5 BL/s(2–4)で語が衝突。04 側を `v_patrol` 等に改名するか注記が必要。
4. 04 の r11 F-05 を「B-」と表記(4.2.1, 4.4.1, 4.4.2)。r11 本体は B。保守側だが不一致。
5. 05 T12 の対数補間「SL=0.20 m で 0.086 s」は TL=SL として計算(TL=23 cm なら 0.089 s)。実害小。
6. 05 頭部ヨー「0.17 rad」は式どおり計算すると 0.178 rad(約10.2度)。本文「約±10度」は妥当、丸めのみ。
7. 04 `strike_dist_max_m`=0.30 は F-19 の「数インチ〜1フィート動く」解説(C)に基づく。迎撃距離ではなく移動量の可能性。
8. 05 の f_idle=0.6 Hz と softmax の定義式は未規定(smooth max の形)。実装時に固定が必要。
