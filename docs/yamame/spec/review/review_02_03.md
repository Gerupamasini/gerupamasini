## C. 要判断(直さず列挙)

1. 頭長/SL の既定方針: 02 は 0.25 [E](写真中央値0.254と文献上限0.238の間)、02 §0 は写真を一次根拠とする一方、01 §1.7 は「文献範囲を主、写真を検算」とし、文献側 0.217–0.238 の上限は台湾亜種(PROXY)の派生値を含む。r01v §4-1 は formosanus 由来 23.8% を仕様に引用しないよう指示。どちらを主にするか。
2. 03 禁止組合せ #4(河川型に雲状の桜色斑を禁止)と §3.4.2 の採用(面的な淡桃〜橙・銅の染み)の境界。r03v V1a は「黒化+淡い不定形の桜色斑」を既定にせよとしており、r04v V-09 は雲状の桜色斑の誤帰属を指摘。「桃色の面的染み」と「雲状の桜色斑」を実装上どう区別するか未定義。
3. p012/p034 は河川型か降海型か写真から判別できない(r07 F-22)が、02 の spawning_male(n=1)と 03 の婚姻色の写真根拠になっている。降海型である可能性を排除できない。
4. 02 §2.1 の 1+/2+/3+ FL(19.4/23.2/28.2 cm)は r01v V-08 が系列ごと採用不可、r03v V9b が 1+ 以降を採用で、検証側同士が割れる(02 は暫定採用と注記済み)。
5. 03 §3.1.1 ランドマーク個数の再現差: 本査読の再計算(A のみ、yamame、conf>=med、curve<1.08)は 23〜26枚・平均8.8〜9.0、adult は評価者により 8.7〜10.0 で、記載の adult 9.3(n=3)は再現できなかった(許容範囲の可能性)。
6. 03 §3.5.3 のパーマーク ΔL* は n=34・中央値 -18.1 だが §3.1.4 は n=35・-18.0、相関 r=-0.09 は n=35 で再現(記載は n=34)。1枚の扱いの差で、結論に影響しない。
7. 03 §3.2.1/3.2.2 の黒点・丸斑の個数(n=51, 54)は catalog の自由記述の正規表現抽出で、本査読の簡易再抽出は n=49、中央値30/8、平均31.8/13.4 と近いが完全一致せず。
8. 03 §3.2.3 の頭部黒点割合 0.68 は非ヤマメ13枚を含む。ヤマメ57枚で再集計すると変わりうる(spot_head_n の「0の確率0.32」の根拠)。
9. 02 §2.2.2 左列(M-all シルエット)に p031 が入ったまま。M-T 列との差は 0.006 以内なので注記のみとしたが、M-Y のシルエット再集計をするか。
