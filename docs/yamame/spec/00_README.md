## 出典タグ

`[rNN F-xx, A]` = 調査ノート `../research/rNN_*.md` の Finding と証拠ランク。ランク: **A**=査読・公的資料で要約に数値/記述が明示、**B**=図鑑・博物館・解説、**C**=釣り・ブログ等、**M**=記憶（未検証）、**P**=ユーザー提供写真 70 枚からの観察・集計。`[E: 理由]` = 資料の裏付けが無い設計値。`PROXY:種名` = ヤマメ以外の値。

## 最初に知っておくべき限界

1. 文献は **WebSearch の要約しか読めていない**（WebFetch・curl は npm と raw.githubusercontent.com 以外ほぼ遮断）。全文を読んだ論文は無い。
2. ヤマメ**成魚**の遊泳運動学・行動・体型比は、ヤマメ固有の査読値がほとんど無い。多くは写真計測（成魚 n=3）か、ニジマス等の PROXY、または [E] 設計値。
3. 写真 70 枚には他種（アマゴ疑い、イワナ類、コイ科）が混ざる。ヤマメ統計から除外している。
4. 性能・描画は SwiftShader（CPU ソフトウェア WebGL2）での確認のみ。**実 GPU は未計測**。
5. 映像資料は URL の所在調査のみ。内容は視聴していない。
