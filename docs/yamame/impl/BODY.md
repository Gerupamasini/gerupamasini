# 体表（胴・尾柄）の作り直し — 色・パーマーク・黒点・鱗・光沢

頭部アトラス（`headpaint.mjs`）が濃いオリーブ褐のキャップ・青銅の頬に作り直されたあと、胴の体表（`textures.mjs`, `generateBodyTextures`）が **灰白く粉っぽく、頭と釣り合わない**ことが分かった。
ここでは原因・方針・採用した値・検証・まだ違うところを記録する。根拠ランクは仕様書（`../spec/03_色彩模様仕様.md`）と同じ（A/B/C/M/P/E）。写真はリポジトリに入れていない。

## 1. 何が悪かったか

| 症状 | 原因 |
|---|---|
| 体側が白く、背が細い帯だけ暗い | 描画側（`viewer/dev/still.html`: ACES + RoomEnvironment + 平行光 + 体表の clearcoat 0.2）の**環境反射のベール**が、背〜体側上半（r 0.2–0.6）で表示値 +60〜+140 を足していた。旧 albedo はそのベールを無視した固定倍率（0.32–0.88）で暗くしていただけ |
| パーマークが灰色のぼやけた塊 | 地色 −24 L* でも色相は灰（青くない）、縁が柔らかすぎ、成魚係数で更に退色 |
| 色が単調 | 色は r（側面投影の高さ）の 1 次元 LUT だけ。桃色帯は白っぽい斑状の染み |
| 暗い体側のベールを AO で抑えていない | ORM の AO は 0.7–1 の弱いもの |

## 2. 方針：設計色（写真の見かけ）→ 描画校正で逆算した albedo

1. **設計色**は「写真に写る見かけの色」（sRGB）で `BODY_STOPS`（r = +1 背正中線 … −1 腹）に置く。頭部アトラスも同じ考え方（写真風 sRGB × ゲイン）。
2. ORM の **AO を背側で小さく**（r ≥ 0.45 で 0.22–0.27、体側下半 1.0）。three.js r186 は `aoMap` を間接拡散・間接鏡面・**クリアコート間接**に掛ける（`aomap_fragment`）ので、`M_Body` の clearcoat 0.2 と環境反射のベールを抑えて暗い体色を暗いまま見せられる（頭部アトラスも同じ手を使っている）。
3. **校正モデル**: シーン線形値 `S = a(r)·albedo + v(r)`、表示 = ACES(S)。`a, v` は裸の地色（斑・黒点・鱗なし）を 3 段の一様 albedo で描いて ACES の逆写像（`acesInverse`）を通した最小二乗で決めた（`CAL_KNOTS`）。albedo = (ACES⁻¹(設計色) − v) / a、上限 `ALB_MAX = 0.85`。
   チャンネルごとの倍率ではなく**加算ベール + 傾き**なので、青灰の斑や黒点でも色相が崩れない。
4. 再校正: `node tools/verify/body_calibrate.mjs fit --template assets/generated/yamame.glb --write`（ORM の LUT を変えたら必ず実行）。`check` で設計色と描画色の差を表示（現在 最大 5.6, 平均 1.4 sRGB 段）。
   `genome.photoExposure = true` は校正なし（albedo = 設計色）。`genome.debugGround = true` は斑・黒点・鱗を描かない（校正と単体テスト用）。

校正は `viewer/dev/still.html` の照明で行った。`glb.html`（暗い背景・環境 0.7・平行光 2）でも破綻しないことを確認した。照明が大きく違う実行時（水中）では、背側の AO が小さいぶん影側が暗くなる（§5）。

## 4. 検証

- 描画: `node tools/headless/render-snapshot.mjs "/viewer/dev/still.html?view=side&half=0.075&file=/assets/generated/body/yamame.glb" out.png --w 1500 --h 700`（`view=top|belly`、`half=0.03&cx=…` で拡大）。a01 を SL 合わせで並べ、p024/p033/p065/p031 と比べた。
- 数値: 裸の地色の描画色と設計色の差 最大 5.6、平均 1.4（sRGB 段）。体の albedo（線形）は背 0.10/0.08/0.05、体側上半 0.23/0.14/0.09、下半 0.56/0.49/0.33、腹 0.80/0.80/0.76（上限 0.85）。
- テスト: `tests/unit/textures.test.mjs` 20 件。更新した期待値: AO の下限（0.7 → 0.05、背は意図的に小さい）、粗さの上限（0.75 → 0.84）、尾端の斑なし判定（地色だけの生成 `debugGround` との比で判定。アルベドは背→腹で大きく変わるため）、桃色帯テスト（虹色光沢を両方オフ）。追加: ACES 逆写像、albedo ≤ 0.85、青灰のパーマーク、背の黒点の密度。
- 個体差: `build.mjs --individual --seed N` で色相・斑数・光沢が変わる（3 個体で確認）。`--stage parr --sl 0.10 --dev` も通る。
- 時間: 体表 約 5 s（負荷で 10 s）、フルビルド 約 40 s（頭部アトラス 22 s）。GLB 10.04 MB（以前 9.77 MB。albedo +0.32 MB、ORM −0.1 MB）。

## 5. まだ違うところ

- a01 は私たちの成魚より**背がさらに暗く、体側が緑がかった銀白**で鱗のきらめきが強い（個体・撮影条件の差。仕様の背 L* 28 以上を守って背をやや明るく残した）。
- 背側の AO が小さい（~0.25）ので、水中のように主光源がない照明では背が暗く沈む。根本策は `M_Body` の clearcoat を 0.2 → 0.06 程度に下げること（`write-glb.mjs` / `params.render.body`、下の依頼）で、そうすれば AO を 0.5 以上にして素直な albedo にできる。
- 鱗の細胞模様は 1 テクセル 0.093 mm（ピッチ 14 px）で十分だが、遠景では細かすぎて沈む（LOD ごとのテクスチャがないため）。
- 頭部アトラスは鰓蓋の後ろ約 4 mm（s 0.25–0.27）が滑らかな単色で、**鱗の格子が胴より少し手前で途切れる**。`headpaint.mjs` のクロスフェード（`sB1 = sEnd − 0.024`, `sB2 = sEnd − 0.008`）を鰓蓋縁（s 0.25）から始めるか、頭側にも格子を描くと連続する。
- 左右が独立なので、実写のように左右でパーマークの数・位置が違う（意図どおり）。
