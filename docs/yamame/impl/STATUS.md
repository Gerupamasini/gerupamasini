# 実装の現状（2026-10-02）

仕様書（`../spec/`）に沿って実装を進めた結果と、仕様・資料とのずれを記録する。
数値の「根拠ランク」は仕様書と同じ（A/B/C/M/P/E）。**E は資料の裏付けが無い設計値**。

## 1. 受け入れた暫定決定

| ID | 決定 | 実装での扱い |
|---|---|---|
| D1 | 基準個体は成魚（SL 0.19 m）。parr・幼魚はサイズ連動で後から | 成魚の寸法は実寸写真 a01（SL 243.2 mm、n=1）から `assets/src/stage_adult.json`。`--stage parr --sl 0.10` で parr（写真 70 枚の集計寸法、パーマーク鮮明）も同じパイプラインで生成できる |
| D2 | 婚姻期の雄は含めない | `mt_kype` / `mt_upper_jaw_ext` は作らない |
| D3 | WebGPU は並走検証のみ、本線は WebGL | **未着手**（本線は `WebGLRenderer` + `MeshPhysicalMaterial`） |

## 5. 既知の問題

- 頭部は「滑らか」すぎる。口の唇の厚み、上顎板の縁、鰓蓋の縁線が写真ほど明確でない（形状・テクスチャの両方）。
- 吻端に小さなコブ状の盛り上がり（唇の隆起 + キャップ環）が見える。
- 写真の桃色帯ほど赤みが強く出ない（仕様どおり弱め）。
- 尾柄の端が垂直に切れて見える（鰭条が付け根から始まる）。
- 行動: 脅威は「人影の球」で表現。`hide_dwell_s` はデモで 20 s に短縮（仕様既定 60 s、トレース上は E 値として表示）。
