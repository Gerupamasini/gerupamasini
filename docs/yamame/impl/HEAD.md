# 頭部の作り直し（50 枚の頭部写真に基づく）

最初の頭部は「全く似ていない」と判定されたため、写真から測った数値で作り直した。ここでは**測ったもの・使ったもの・検証方法**と、まだ違うところを記録する。
根拠ランクは仕様書と同じ（A/B/C/M/P/E）。写真そのものはリポジトリに入れていない（解析結果の JSON のみ）。

## 1. 何が悪かったか（旧頭部の診断）

| 症状 | 原因 |
|---|---|
| 口が極端に小さく、口角が眼のすぐ下にあった | 口裂の長さを一般則で置いていた（写真の口角は頭長の 0.43、眼の中心は 0.365） |
| 口裂の傾きが逆（後ろへ上がっていた） | 実際は吻端から口角へ**下がる**（口角は吻端より HL の 0.18 低い） |
| 吻端が丸い瘤状 | 吻端のキャップが大きく、唇の隆起と重なっていた |
| 鰓蓋が縦帯 | 鰓蓋縁を s 一定の帯で作っていた（実物は後ろへ凸の S 字） |
| 頭が上下対称・低コントラスト | 断面が対称な超楕円、頭部の色が 1 次元の LUT だけ |

## 2. 測定の流れ（`tools/photo/`）

1. 写真 50 枚（`ヤマメ頭部写真50枚.pdf`）を 3 群に分け、**2 人の独立した評価者**が吻端・眼・口角・鰓蓋・前鰓蓋・鼻孔など約 24 点を画素座標で読む（`docs/yamame/photo_analysis/head_landmarks_g{1,2,3}_{A,B}.json`）。
2. `head_stats.py`: 吻端→鰓蓋後縁を弦（u 軸、頭長 HL = 1）とする座標へ変換し、評価者間の差と写真間の分布を出す（`head_profile_stats.json`）。
3. `head_outlines.py`: 弦座標の事前多角形の中で GrabCut し、頭部の輪郭（背縁・腹縁）を抽出。網・手・箱縁が混ざる写真は目視で除外し、**側面のきれいな 11 枚**を採用（`head_outlines.json`）。
4. `head_profile_curves.py`: 各写真を u = 0.9 の頭高中心が水平になるよう回転（撮影ピッチの打ち消し）し、中央値と MAD を取る（`head_profile_curves.json`）。

### 測定結果の要点（弦座標、HL = 1、再配向後）

| 特徴 | 値 | 備考 |
|---|---|---|
| 眼の中心 | u 0.365, v +0.031 | 眼径（虹彩の金環込み）≈ 0.17 HL |
| 口角 | u 0.434, v −0.181 | 口裂は吻端から約 22° で下がる |
| 上顎骨の後端 | u 0.448, v −0.151 | 口角の 0.03 HL 上 |
| 鼻孔（前） | u 0.141, v +0.039 | |
| 鰓蓋縁 | 上端 (0.833, +0.144) → 最後方 (0.996, −0.059) → 下端 (0.894, −0.194) | 後ろへ凸の S 字 |
| 前鰓蓋 | (0.712, +0.078)–(0.788, −0.047)–(0.750, −0.175) | |
| 頭長 / 標準体長 | 0.254（写真 70 枚の中央値。a01 は 0.221、n = 1） | 成魚個体の a01 は頭が短いが、写真は 0.25 前後 |

GrabCut の輪郭は背景の影・ぼけで **外側に 0.02–0.03 HL** 出る傾向があり、背縁・腹縁の最終値は評価者のランドマーク（head_dorsal/ventral_25/50/75）を優先した。ひれ（胸鰭）が腹縁に混ざる u > 0.85 も同様に補正した。

## 3. 頭部仕様 → モデル（`tools/build-assets/head.mjs`, `assets/src/head_adult.json`）

- **断面**: 各 u で背縁・腹縁の高さ、最大幅の高さ、背側・腹側の指数、幅/高さを持つ区分超楕円（`surface.mjs`）。頭は左右に圧縮し（幅/高さ 0.45→0.80）、背側は平らな頭頂、腹側は丸い顎。
- **体との接続**: 頭の終端（鰓蓋後縁）から体表の表へ**エルミート補間**で滑らかにつなぐ（旧: 肩のこぶ）。
- **レリーフ**（`createHead().displacement`）: 唇（上唇・下唇・口裂）、上顎骨の板、歯骨、頬、前鰓蓋の溝、鰓蓋板（前鰓蓋線〜自由縁、縁の隆起と影）、鼻孔、眼窩。**幾何では GEO_MIN（0.03 HL）より細かい形を作らない**（ロフトの格子で折れ線にならないため）。それより細かい分は法線マップ（`ctx.fine = true`）で描く。
- **唇の格子**: 口裂の近くに列を寄せる（`col_warp`）。上顎・下顎の縫い目リングは口角まで。
- **吻端**: キャップを 0.007 SL にし、先端は閉じた扇（以前は向きが逆でキャップ中央に穴があった）。
- **リグ**: 鰓蓋は前鰓蓋線〜自由縁の板に重み、上顎骨ボーン（`maxilla_*`）は上顎骨の板に重み。ランタイムで下顎の開きの 0.18 倍だけ後端が下がる。鰓蓋の外転は呼吸 7°、摂餌 8°（以前の 15° は縁がちぎれて見えた）。
- **鰓の隙間**: 鰓蓋縁の下に暗赤色の薄いシート（`gills.mjs`）。板が持ち上がると中が見える。
- **頭部専用テクスチャ**: s < 0.27 は別アトラス（1536×2048、`M_Head`）。体のアトラスの頭部分は縮小コピーで上書き（LOD1 以降が同じ色になる）。GLB の色・ORM は JPEG（4:4:4, q93/95）、法線は PNG。

## 4. 検証（`tools/verify/`）

| ツール | 目的 |
|---|---|
| `head_overlay.py PNNN --layout cmp` | 側面写真とモデルを同じ枠（弦を再配向）で並べ・重ねる |
| `head_views.py` | 8 方向（側面・斜め上・斜め・正面・上面・斜め下・後ろ斜め）のコンタクトシート。`HV_EXTRA=tex=clay` で形状だけ、`jaw=`/`flare=` で姿勢 |
| `pose_fit.py PNNN…` | 写真と**同じ視点**をランドマークから推定（弱透視カメラ + 評価者の視角を事前分布）してモデルを同じ姿勢で描画し、写真・モデル・重ね合わせを並べる。ランドマーク再投影誤差（HL 単位）を `fit.json` に出力 |
| `pose_report.py fit.json` | 写真ごとの RMS と、特徴ごとの平均誤差（側面 / 斜め別） |

## 5. 既知の差（正直な記録）

- 写真は個体・成長段階・撮影条件がばらばら。形の個体差（頭高 ±15 %）の中央付近を採った。a01（実寸写真）の頭長 0.221 SL とは合わない（n = 1 の個体差と判断）。
- 立体（z 方向）の根拠は斜め・正面の写真が少ないため弱い。頭幅は文献的な比（頭幅 ≈ 0.55 HL）と pose_fit の残差から決めた。**E 値**。
- 口の内部（舌・口蓋）、鰓弁は簡易（暗赤色のシートと、口内テクスチャ）。歯は小さな円錐で、数・向きは写真から判別できない。
