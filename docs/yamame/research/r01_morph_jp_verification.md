## 2. 仕様書で使うべき「採用値」

(rank は検証後の再評価。PROXY は scope を必ず併記すること)

1. **サイズ（河川型ヤマメ）**: 全長 ≈30cm 以下が典型（B、複数の自治体・環境省系資料で一致）。上限 35–40cm 例外（元資料の並記）。大型河川個体は 2+歳 ≈300mm（Kato 1991, A・単一）。降海・湖沼型 60–70cm は別設定（河川型の主モデルに使わない）。
2. **パーマーク**: 体側中央に楕円形の暗色斑 **約8–10個（9前後）**。成魚にも残るが成長とともに薄くなる。根拠: 青森 8–10（A・単一、再現は要原典）、台湾亜種 9 個・生涯残存（PROXY:formosanus、B）、AI百科 9–10（C）。
3. **小黒点**: 日本のマスは背側〜側線より上に**多数の小黒点**を持つ（台湾亜種より約50個多い、との要約。絶対数は取得不能。C/B）。数を固定せず、個体ごとに変動させる設計とする。台湾亜種は側線より上に約10–30個（PROXY）。
4. **性二型・産卵期の吻**: 雄は頭長に対して吻・上顎が相対的に長く眼が相対的に小さい（PROXY:韓国産O. masou、A・単一、数値無し）。産卵期の吻の曲がりと顎歯は元F-17（C）の記述に留め、程度は写真・原典確認。
5. **スモルト（銀化個体を表現する場合）**: 閾値 FL 12cm は特定の飼育系統の値。スモルト平均 FL は 1+歳 126±9mm、2+歳 139±11mm（北海道、B）。系統・性別で閾値 108–162mm。河川型ヤマメの主モデルは parr/残留型（銀化させない）とし、スモルトは派生バリエーション。
6. **体長–体重**: FL≤21.9cm の範囲で W=0.0106·FL^3.0397（A・単一）。b≈3.0 を等成長の根拠に使えるが、21.9cm 超は外挿しない（成魚サイズでは b=3.0 と K≈1.1–1.2 を仮定する場合は「暫定」と明記）。
7. **鰭条数（暫定）**: 青森ヤマメ 背12–13・胸12–14・臀12–14（腹9）。台湾亜種は臀・胸が日本のマスより約2少ない（整合）。ただし**分枝条のみか不分枝条を含むかが不明**なので、背鰭の見た目の鰭条本数は写真(P)で決め、これらは検算にとどめる。
8. **個体差の幅**: 沢ごとに外部形態が異なる（パーマーク・小黒点の多寡、少数の朱点の有無）という F-18 は維持。仕様上「個体群プリセット」を用意する根拠にしてよい（B）。

## 4. 元ファイルの記述に関する追加の指摘

1. F-12 の英語 Wikipedia 由来の比は、台湾側の公的資料（taieol）に直接対応する記述が見つからず、**むしろ矛盾する要約**が出た。F-12 を根拠にした「ヤマメの頭長≈23.8%SL」等は仕様に引用しない（元ファイルでも PROXY・算出と明記済みだが、要約§1 の記述が採用値に見えるため注意）。
2. F-25 の 12cm 閾値と F-31 の 110–130mm は別の対象（飼育系統の駆動閾値 vs. 野外スモルトの平均 FL）で、混用すると誤る。
3. 同一論文の別URL/ミラー（koreascience.kr と .or.kr、PMC と Sci Rep、en.wikipedia と handwiki）は独立資料として数えていない。
4. 外観モデルに最も影響が大きい比（体高・頭長・眼径・尾柄高・鰭位置）は、今回の独立検索でも**文献値が得られていない**。r01 の Gap 1–5 は写真ストリーム(P)での計測を主に据える必要がある。
