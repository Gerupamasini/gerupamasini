## おまかせ分の決定（異議がなければ確定）

- Q7 レンダラー: WebGLRenderer、three 0.186（npm）。WebGL2 必須。理由はマハゼの独自シェーダーが GLSL と WebGL2 のレンダーターゲット前提で、WebGPU へ移すと全面書き直しになるため。
- Q19 アニメーション: B。ループ可能なクリップはモデル側、移動・向き・接地はコード側。観察中のヒーロー個体は手続き駆動（マハゼの Behavior.js 方式）、それ以外は AnimationMixer でクリップ再生。
- Q20 個体差: A。全長スケールと色調パラメータをインスタンス属性で渡す。データ構造はテクスチャバリアントとボーンスケールを後から足せる形にする。
- Q22 生態レベル: 個体行動 + 相互作用 1 種。AI は 2 層構成。種ごとの JSON 定義のビヘイビアツリーが意図（休む・探餌・逃走・巣穴へ入る等）を決め、種ごとのドライバが意図を姿勢に変換する。
- UI ライブラリ: Preact。
- セーブ: IndexedDB（写真画像を保存するため localStorage では容量不足）。スキーマにバージョン番号を持たせる。
- 操作: WASD 移動、マウス視点、Shift 走る、Ctrl しゃがむ、E 採集、F 観察、Tab 図鑑、Esc メニュー。
- 言語: 日本語のみ。文字列はテーブルに分離する。
- 季節変更: 「季節の潮時チケット」として仕様に入れる。レア報酬、実装は MVP 以降。
- 潮時チケット: 今週のテスト版では無制限。配布ルールは来週以降。
- リポジトリ: マハゼのブランチを履歴ごと本ブランチへマージし、種ごとのパッケージ構成に整理する。19 MB の GLB は当面通常の git で管理し、合計が大きくなったら LFS を検討する。
- 課金: 未定のため、決済やアカウントに依存する設計は入れない。
