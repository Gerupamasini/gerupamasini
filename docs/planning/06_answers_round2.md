## 解釈と補足

- 3 種の役割: マハゼ = 遊泳魚・採集可・既存ヒーローモデル。シラタエビ = 甲殻類・採集可・手網で採れる。シロチドリ = 鳥・採集不可・観察のみの図鑑登録を検証する種。
- 金曜版の実モデルはマハゼのみ。シラタエビとシロチドリは手続き生成の簡易モデルで出し、図鑑上は「仮モデル」と表示する。写実モデルは翌週以降に Claude が制作する。
- 潮位データ: この実行環境のネットワーク方針で `www.data.jma.go.jp` と `www1.kaiho.mlit.go.jp` への接続が拒否された。検索結果の抜粋から東京（TK）の主要 4 分潮を暫定値として確保した（出典: 気象庁 60 分潮一覧 2025 年）。
  - M2: 振幅 47.73 cm、遅角 153.73°
  - S2: 振幅 23.64 cm、遅角 181.77°
  - K1: 振幅 25.07 cm、遅角 178.91°
  - O1: 振幅 19.57 cm、遅角 160.28°
  - 残り 56 分潮と検証用の潮位表は、環境のネットワーク許可に `www.data.jma.go.jp` を追加してもらうか、オーナーがページを保存して渡す。
- 配布: GitHub Pages は既定で `main` ブランチからのデプロイのみ許可されることが多い。金曜の公開には Pages の有効化（Settings → Pages → Source: GitHub Actions）と、作業ブランチの `main` への反映、または github-pages 環境の許可ブランチへの追加が必要。
