# 道具の計画（7 回目）

採集の基本はタモ。道具はこの順で増やす。データは `public/data/items/tools.json`（`type` と `available` で区別）。

| 道具 | type | 使いどころ | 状態 |
|---|---|---|---|
| タモ（標準 / ショート / ロングの 3 種、ショップで CR 購入、習熟度は共通: 採集数で Lv1〜5、判定拡大・逃走率減） | capture | 浅い水中の魚・エビ。画面中央のポインターの先（視線に沿った縦長の楕円、柄の届く 1.2 m まで）にいて逃げなかった生物が入る（8 回目でバー判定を廃止、9 回目で楕円判定に） | 実装済み |
| スコップ | dig | 砂泥を掘る: アサリ（8 回目で実装: 水管の穴を狙って掘る）。ゴカイ・アナジャコは今後 | 実装済み（アサリ） |
| 釣り具 | fishing | 澪筋や満潮時の深み: ハゼ釣り（餌・合わせの小ゲーム） | 計画 |
| 望遠鏡 | optic | 遠くの鳥や干潟の広い面を観察（望遠と手ぶれ、観察記録に加点） | 計画 |

共通の設計:
- 道具は 1 つだけ手に持つ（[1][2] で持ち替え、HUD 右上に現在の道具）。持っている道具で [E] の意味が変わる（実装済み）。
- 一人称の道具モデルは `src/player/NetView.ts` と同じ作り（カメラ空間の姿勢キーフレーム → ワールドへ）。
- 結果は必ず「手元で確かめる」演出を挟む（タモ: 網の中、スコップ: 掘り返した砂の中、釣り: 竿の曲がりと取り込み）。
