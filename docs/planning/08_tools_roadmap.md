# 道具の計画（7 回目）

採集の基本はタモ。道具はこの順で増やす。データは `public/data/items/tools.json`（`type` と `available` で区別）。

| 道具 | type | 使いどころ | 状態 |
|---|---|---|---|
| タモ | capture | 浅い水中の魚・エビ。帯に合わせて振り、網を引き上げて中を確かめる | 実装済み（7 回目で一人称の振り・引き上げ・確認を追加） |
| スコップ | dig | 砂泥を掘る: アサリ・ゴカイ・アナジャコ（穴の脇を掘る）。掘った穴は潮で埋まる | 計画 |
| 釣り具 | fishing | 澪筋や満潮時の深み: ハゼ釣り（餌・合わせの小ゲーム） | 計画 |
| 望遠鏡 | optic | 遠くの鳥や干潟の広い面を観察（望遠と手ぶれ、観察記録に加点） | 計画 |

共通の設計:
- 道具は 1 つだけ手に持つ（数字キーで持ち替え、HUD 右下に現在の道具）。持っている道具で [E] の意味が変わる。
- 一人称の道具モデルは `src/player/NetView.ts` と同じ作り（カメラ空間の姿勢キーフレーム → ワールドへ）。
- 結果は必ず「手元で確かめる」演出を挟む（タモ: 網の中、スコップ: 掘り返した砂の中、釣り: 竿の曲がりと取り込み）。
