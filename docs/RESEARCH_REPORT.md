# コメット金魚 リサーチレポート（STEP 1–2）

対象：コメット（Comet goldfish, *Carassius auratus* 単尾・長尾の品種）
目的：Three.js リアルタイム・ヒーローアセットの形態・材質・運動・行動の根拠を固める。

## 1. 写真資料の分析（100 枚）

### 1.1 構成
- 更紗（赤白）が過半、次いで赤（素赤）、白、黄・黄金。混泳写真、俯瞰（洗面器・池）、正面、白背景・黒背景の商品写真を含む。
- p33_1 は AI 生成と思われる不自然な画像（口ひげ・鱗の破綻）であり形態判断から除外。
- p35_1、p10_1 等は和金寄り（短尾）の個体で、コメットとの比較に使用。

### 1.2 側面計測（SL = 吻端〜尾鰭基底）[P]

**観察された形質**
- 吻は鈍く丸い（吻端から 0.01 SL で既に半高 ≈ 0.03 SL）。上唇が厚く口は端位〜やや上向き。
- 眼は頭高のほぼ中央〜やや上、肉質の白っぽい眼窩縁（orbital rim）が眼球縁を覆う。虹彩は金〜橙で外周が暗く、瞳孔縁に明るいリング。
- 鼻孔：眼の前上方（s≈0.05）に小さな皮弁。
- 口角から眼の前下方へ走る上顎（主上顎骨）の皺。
- 鰓蓋：C 字状の後縁、前方に前鰓蓋の弱い稜。閉鎖時は細い線、開くと暗赤色の鰓が覗く。
- 鱗：側線上 ≈ 28 枚。露出部は丸い後縁の円鱗が屋根瓦状に重なる。**赤斑の境界は鱗の輪郭に沿ってギザギザ**（p06, p28, p40）。白部では鱗縁が細い灰色の網目、赤部では鱗縁がやや明るい橙黄色。
- 鰭：白鰭は青白い半透明膜に白い鰭条、遠位で鰭条が分岐。背鰭・尾鰭基部に赤が乗ることが多い。静止時は長い尾鰭がやや垂れ下がる（p41, p03）。
- 上面：頭部直後（鰓蓋付近）が最大幅。上から見た体は紡錘形。
- 行動写真：水底で頭を下げて砂利をついばむ姿勢、水面に向け口を開ける姿勢、群泳時もゆるい集団（整列しない）。

## 4. 遊泳運動学

| パラメータ | 値 | タグ | 実装 |
|---|---|---|---|
| 尾鰭拍動数と速度 | U = (L/4)(3f − 4) ⇒ f = (4/3)(U/L + 1)（f > 5 Hz で有効） | [S] Bainbridge 1958 | `Locomotion`：推力指令速度から f を算出（下限 1.25 Hz） |
| 尾端振幅 | 5 Hz 以上で ±0.1 L に飽和、それ以下は f とともに増加 | [S] | A = 0.1·clamp(0.18 + 0.82(f−1.33)/3.67) |
| 体波の包絡線 | A(ξ)/L = 0.02 − 0.0825ξ + 0.1625ξ²（最小 ξ≈0.25、頭部反動 ≈ 尾の 20 %） | [S] Videler–Hess | 正規化して体軸の角度勾配へ |
| 体波長 | 0.9–1.0 L | [S]/[E] | λ = 0.95 L（個体差 ±5 %） |
| 旋回 | 頭が先行し、曲率パルスが頭→尾へ伝播（Howe ほか 2020）。旋回角速度 88–1050 °/s（コイ） | [S] | 体節ごとに「(Δs·L)/U 秒前の頭の向き」を追従 |
| C スタート | 潜時 5–10 ms、Stage 1 ≈ 20 ms（15–40）で 30–100° 回頭、頭部角速度 ≈3500 °/s、Stage 2 反転ストローク、ピーク ≈ 15–20 BL/s、脱出方向は刺激から 90–180°、弾道的 | [S] Eaton; Domenici & Blake | 一定曲率の C 字 → 反転 → バースト遊泳のプログラム |
| バースト＆コースト | 1〜数拍のバーストと滑空 | [S] | 0.35–2.2 BL/s で 1–3 拍＋滑空（速度が 55–80 % に落ちたら再加速） |
| ホバリング | 鰭は静止しない（ホバリングは代謝の約 2 倍） | [S] | 胸鰭 1.4–2.3 Hz のスカーリング（左右交互）、尾の微小補正 |
| 制動 | 胸鰭を流れに直交して広げる | [S]（ブルーギル） | 胸鰭の制動ポーズ＋腹鰭展開＋尾鰭拡張 |
| 呼吸 | 安静時 60–120 回/分（20–25 °C）、Q10 ≈ 2.5、低酸素で頻度 +34–43 % | [E]/[S] | 1.15–1.6 Hz、運動後に上昇、口が鰓蓋に 0.3 周期先行、1–3 分に1回「咳」 |
| 吸引摂餌 | 口開口ピークまで 25–60 ms（ばらつき大）、底では頭を 30–60° 下げ、吸って選り分けて吐く | [E]/[S] | strike / peck / gulp / spit / chew のプログラム |
| 眼球運動 | 水平サッカードのみ、2–25°（平均 20.6°）、左右非共役、注視中のドリフト < 1 °/s | [S] Easter; Mensh | 左右独立のサッカード（相関 60 %）、餌への輻輳 |

## 5. 行動

| 項目 | 知見 | タグ |
|---|---|---|
| 日周・給餌 | 昼行性だが給餌時刻に同調、給餌前の予期的活動 | [S] |
| 速度 | 水槽内追跡の平均 6–36 mm/s、個体間 CV ≈ 30 %。通常遊泳 0.5–1.5 BL/s、持続最大 6.4–7.5 L/s（小型個体） | [S]（低信頼）/[E] |
| 採餌 | 砂利の上でも採餌、粗砂で最大。**採餌量の増加は回数の増加による** | [S] Smith & Gray 2011 |
| 群れ | 集まるが整列（polarization）は弱い。群れが大きいほど餌を早く見つける | [S] Pitcher ほか |
| 個性 | 大胆さの個体差は捕食リスク下で増幅。thigmotaxis と scototaxis は独立 | [S] |
| 驚愕 | 音・振動（ガラスを叩く）で < 10 ms の C スタート、ルーミング刺激は角度閾値、弱い刺激の組み合わせで確率上昇、慣れ（Mauthner 細胞の抑圧） | [S] |
| 側性 | 2/3 は偏り無し、残りは右:左 ≈ 1.5:1 | [S] |
| 壁 | 側線は約 1 BL 以内のみ有効（0.1 BL で壁を検知）→ 回避は主に視覚 | [S] |

## 6. 実装に採用した設計値（要約）

| 分類 | 値 |
|---|---|
| 個体差 | SL 7–12.5 cm（平均 9.5 cm）、体高 ±4 %、体幅 ±5 %、尾葉長 0.60–0.98 SL、鰭長 ±10–15 %、体色タイプ（更紗 55 %、赤 18 %、橙 10 %、黄 8 %、白 9 %）、更紗の模様は個体シードの 3D ノイズ |
| 性格 | activity（対数正規 CV 0.3）、boldness（Beta(2,2)）、curiosity（boldness と +相関）、sociality（−相関）、thigmotaxis（独立）、feedMotivation 0.7–1.3、preferredDepth N(0.3, 0.15)、turnBias（2/3 無偏向） |
| 驚愕 | P = sigmoid((threat − θ)/0.07)、θ = 0.38(1.4 − fearfulness)(1 + 慣れ)(休息中 ×1.4)、慣れは刺激種別ごと +0.25/回、τ 90 s、社会的伝播は 3.5 BL 以内に 60–150 ms 遅延、不応期 1.2–2 s |
