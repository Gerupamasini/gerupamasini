# トビハゼ（*Periophthalmus modestus*）— 水陸両用の写実モデルと行動

干潟の泥の上と水の中を日常的に行き来するトビハゼを、手続き生成の 3D モデルと手続きアニメーションで再現したものです。「水から出られる魚」ではなく、胸びれで体を支えて這い、尾の反動で跳び、水際を出入りし、巣穴にもぐる半陸生のハゼとして作っています。

- モデル: `src/assets/models/tobihaze/tobihaze.{hero,lod1,lod2}.glb`（`npm run model:tobihaze -- --tier hero|lod1|lod2` で再生成）
- ビルダー: `tools/models/tobihaze/`（anatomy / body / fins / eye / rig / build）
- 実行時: `src/creatures/species/tobihaze/`（`TobihazeDriver` / `Mind` / `Motor` / `pose.js` / `TobihazeMaterial` / `ContactShadow`）
- 世界側: `src/world/MudFx.ts`（泥の跡・飛沫・水面の波紋）、`src/world/Burrows.ts`（巣穴）、`src/world/Water.ts`（波紋リング）
- データ: `public/data/species/periophthalmus_modestus.json`、`public/data/behaviors/mudskipper_amphibious.json`
- 確認用: `tools/models/tobihaze/viewer/`（形の確認ビューアと行動テストベッド）、`gameshots*.mjs`（ゲーム内撮影）

## 形態（参考写真 70 枚と文献から）

全長 80 mm（標準体長 64 mm）の成魚。物体空間は m、+Y 背側、+Z 吻端、+X 魚の左。原点は胸びれの付け根（肩帯）の真下の腹側線で、陸上歩行の支点です。

| 部位 | 内容 |
|---|---|
| 頭部 | 鈍く丸い吻。吻端から眼まで額が急に立ち上がる。口は下位で幅広く、厚い上唇が下顎にかぶさる。鰓腔（鰓蓋の内側）がふくらんだ頬。鰓孔は胸びれの前の小さな切れ込みだけ。頭幅 18.7 % SL（文献 14.1–19.8 %） |
| 眼 | 頭頂の両隅に寄った左右の眼（眼径 5.5 % SL、眼間隔は 1 mm 未満）。上半分が頭の輪郭から出る丸いドーム（真皮のカップ, dermal cup）に包まれ、ドームは小さな丸いすそで頭に溶け込む。カップの窓は大きく、横・やや前・やや上を向く横長の楕円で、眼の外側の面のほとんどが見える。横長の楕円の大きな黒い瞳を細い銅色の縁が囲み、虹彩は暗いオリーブ褐色で下半分に緑金色の構造色（薄膜干渉）。虹彩の外はドームと同じ斑点のある皮膚色の組織。窓のすぐ下のカップは薄く、ややピンク |
| 胴と尾 | 前半は円筒形、後半は側扁。尾柄は細長く、体高 8.5 % SL |
| 胸びれ | 筋肉質の「腕」（伸びた射出骨を包む肉質の基部）。先は少し平たい丸い葉状で、その縁から 14 本の鰭条の扇が出る（鰭条の基部は皮膚に包まれる）。腕は体側と同じ皮膚と斑点。鰭膜は灰色がかったオリーブの半透明で、鰭条は外側で 2 回枝分かれし、節があり、先端は淡い桃白色 |
| 腹びれ | 左右 I,5。胸の下の、正中で前がつながった丸い 2 枚の貝殻状の葉（後ろに切れ込み）。合わせると体幅より広い蝶形の吸盤状の円盤になる。各葉は内側の鰭条が後ろ、外側の棘が横〜やや前を向く扇で、下面がくぼむ。淡いクリーム色で、枝分かれした細い鰭条が放射状に見える |
| 背びれ | 第 1 背びれは丸い扇形（14 棘）。灰褐色で、縁の内側に暗色帯、縁は細く白い。第 2 背びれは I,12（基底長 22 % SL）。透明で、中央に灰褐色の縞、鰭条の基部に黒点 |
| 臀びれ・尾びれ | 臀びれ I,11。尾びれはやや槍形で、下葉側の鰭条が短く太く、暗い |
| 体色 | 灰色〜明るい褐色。背中に「く」の字の暗色鞍状斑が 6 つ、体側中央に不規則な暗斑の列、細かい黒点、頬と鰓蓋に小さな白〜青白点。腹と頭の下面は白い |
| 皮膚 | 小さな円鱗（体側）、頭部の感覚乳頭と皺、胸びれ基部と後頭部のひだ、筋節の浅い溝を法線マップに焼き込んでいる |

## 濡れた皮膚（`TobihazeMaterial.ts`）

トビハゼは皮膚で呼吸します（空気中で酸素摂取の 76 %。毛細血管は表皮の 2–4 µm 内側）。乾かさないよう粘液に覆われていることを、個体ごとの状態で表しています。

- **湿り気（0–1）**: 水中では 1 に戻り、空気中では数分かけて乾く。湿った泥の上や日陰では遅く、乾いた砂や日なたでは速い。乾くのは頭頂、眼の塔、背中から（焼き込んだ「日当たり」マップ）。腹やひだは粘液が多く、最後まで濡れている
- **見え方**: 濡れた皮膚は暗く鮮やかで、透明な粘液膜（クリアコート）が鋭く光る。粘液膜は皮膚の凹凸に沿う（クリアコートにも法線マップ）。乾くと白っぽく灰色になり、つやが消える
- **水中と陸上の光沢の違い**: 水面より下では空気と粘液の境界がないので、クリアコートを切り、色を深くする。水面の直上数 mm は常に濡れていて水滴が並ぶ（水面際のメニスカス）
- **水滴**: 濡れた皮膚の上の小さな水滴（バンプとクリアコート）。水面の近くほど多い
- **泥**: 這うと腹と体側の下半分に泥がつき（底質の色）、乾くとマットに、濡れているとぬめって光る。水に入ると落ちる
- **コースティクス**: 浅い水に沈んだ部分には、干潟の底と同じ波面から計算した集光模様が当たる（`Terrain.causticUniforms()` を共有）

## 行動（`Mind.ts`）と運動（`Motor.ts`）

脳（JSON のビヘイビアツリー `mudskipper_amphibious`）が意図を決め、`Mind` が状況を見てそれを運動の指令の列に変え、`Motor` が体を動かします。

### 状態

`SWIM` / `SHALLOW_WATER` / `LAND_CRAWL` / `LAND_HOP` / `IDLE` / `FORAGE` / `BURROW` / `ESCAPE` / `WATER_ENTRY` / `WATER_EXIT`（`TobihazeDriver.state`、デバッグ表示は `driver.debug`）

### 判断に使うもの

- **潮位・水深**: 体高に対する水深で、陸・浅い水・水中を切り替える（ヒステリシスあり）。満ち潮で水が来ると、水際とともに岸へ上がる（Ikebe & Oishi 1996）。水中で休むときは水際へ戻る
- **底質**: 泥 > 泥まじりの砂 > 砂。柔らかく濡れた泥ほど尾を使い、足跡と泥はねが多い。砂の上では胸びれの鰭条を広げ、泥の上では束ねた支柱にする（Naylor & Kawano 2022、Harris 1960）
- **湿り気**: 干潟の濡れ具合（生息地の潮の履歴）と自分の皮膚の湿り気。乾いてきたら水たまりか水際へ行き、横に転がって体を濡らす（PLoS ONE 2022）。移動先は、濡れた泥、水際の近く、巣穴の近くを好み、乾いた場所や深い水を避ける。干潮時は、水際の干出したばかりの濡れた泥を、薄い水の膜よりわずかに好む（乾いた泥はどちらよりもずっと低い）
- **露出時間**: 干出してからの時間が長くなると巣穴へ戻る（Ikebe & Oishi 1997）。夜は巣穴に入る
- **脅威**: プレイヤーとの距離と向き。逃げ方は「水へ（跳ねて入り、水面を跳ね、泳ぎ去る）」「巣穴へ（跳ねる・這うで戻り、頭から飛び込む）」「その場から数回跳ぶ」の中から、近さと方向で選ぶ。逃げたあとは背びれを立て、眼で脅威を追って様子を見る

### 体の動き

- **胸びれ歩き**（Harris 1960、Pace & Gibb 2009、Kawano & Blob 2013）: 両胸びれを同時に使う。押す相（周期の約 45 %）では、鰭を地面に固定したまま後ろへ押し、体を持ち上げて鰭の上を越えるように前へ運ぶ。その間、腹びれは畳んで地面から離す。戻す相では体が腹びれと腹に乗り、胸びれは弧を描いて前の着地点へ戻る。1 周期で全長の約 24 %、毎秒約 2 回。手首の角度は押す間に開いていく。胴は硬く保ち、尾は平地ではそりのように引きずる。坂・柔らかい泥・急ぐときは、押す相の終わりに尾で横へ蹴る（McInroe et al. 2016）。つまり、胸びれ接地 → 体幹の屈曲 → 尾部の反動 → 前進
- **胸びれの IK**: 腕（肩 → 手首）は泥の上に置いた手首の位置へ向かい、その幅の広い面を体の外側へ向ける（横から見ると肉質の櫂）。鰭膜は手首から体側に沿って後ろ外側へ置き、縁の近くで泥に着ける（後縁の鰭条で押さえ、前縁を反らせる。柔らかい泥ほど立てる）。接地中は手首の位置と鰭膜の向きを世界に固定するので、体が鰭の上を越えて前へ出ると腕は前傾から後傾へ振れる。体を高く支えているときは腕が届かず、鰭膜が手首から泥へ斜めに下りる（支柱の姿勢）。腹びれは体の高さに応じて泥まで下ろし、のどを支える。体重は胸びれ・腹びれ・腹と尾で支え、後半身は地形に沿って垂れる（沈み込まない）
- **跳躍**（Swanson & Gibb 2004、Choi et al. 2025）: 体を J 字に曲げ（尾が頭の横へ、最も強い曲がりは体の 2/3 の位置。陸上では約 60–150 ms）、同時に跳ぶ方向へ向きを変える。体をまっすぐに伸ばして尾で地面を押し、27–59° で飛び出す。空中では鰭を畳み、着地では腹と広げた胸びれで受けて体をつぶし、また体を起こす。泥の跡と泥はね、水面なら飛沫と波紋。逃げるときは水面を跳ねることもある
- **遊泳**: 体の波打ち。速く泳ぐときは胸びれを体側に畳み、ゆっくり泳ぐときは胸びれで水をかく。水面では眼の塔を水から出す
- **浅い水**: 胸びれ歩きに体の波打ちを足して進む。水深が全長の約 1/4（8 cm の個体で約 2 cm）までは泳がず、胸びれで体を持ち上げて眼だけを水面上に出す（潜望鏡姿勢）。干潟の水たまりや水の膜の中にいるのはほとんどこの状態。水際の出入りは、水 → 浅い水 → 胸びれでの支持 → 陸上歩行と連続して移り、そのそれぞれの段で上陸（`WATER_EXIT`）・入水（`WATER_ENTRY`）と表示する
- **捕食**（Sponder & Lauder 1981、Michel et al. 2014/2015）: 泥の上の小さな獲物（ヨコエビ、ソコミジンコ、ゴカイ）を両眼で見つめ、向きを直し、這って近づき、止まってから短く突進する。胸びれで支えたまま頭を下げて覆いかぶさり、下顎を大きく開けて食いつく。そのあと口の水を出し入れする（頬が動く）。ときどき連続して泥の表面をついばむ。食べたあとは水へ行って水を飲む
- **巣穴**: 巣穴は泥の上にあり、口径約 1 cm、低い縁と口で運び出した泥の粒がある（Ishimatsu et al. 2007、Mai et al. 2020）。巣穴の前で向きを合わせ、尾を震わせながら頭から約 65° の角度で飛び込む。中にいる間は見えず、捕まえられない。出てくるときは、まず頭だけを出して眼で周りを見て、それから這い出る
- **眼**: 左右が別々に動く。獲物があれば両眼で見つめ、脅威があればその側の眼がゆるく追う（追従は弱い）。それ以外は空（鳥）や前の地面を見回し、サッカードと固視の揺れが入る。まばたきは眼を眼窩へ引っ込めて真皮カップを上げる動きで、約 0.56 秒。カップは 35 % の時点で上がりきる（Aiello et al. 2023）。乾燥するほど多くなり、着地や驚いたときは反射的に行う
- **呼吸**: 陸上では口と鰓腔の水をポンプして頬と喉が動き、水中では速く浅く動く
- **自然さ**: 体の部位、頭、鰭、肢はばね（臨界減衰）で目標へ追従する。休止中の重心移動と視線には滑らかなノイズを入れ、乱数は個体ごとの種から決まる

### ゲームへの組み込み

- **見えている水 = 立っている水**: 生息地の地点ごとの水位（`Habitat.waterAt` / `sample`）は、水面シェーダと同じ判定（潮だまりの水位が地面より 3 mm 以上、潮位より 1 cm 以上高い）を使う。以前は 2 cm 未満の水たまりを「陸」と扱っていたため、画面では水の中にいる個体が陸の動きをし、水たまりの縁が 2 cm の段差になっていた（区画単位の生息地タグは従来どおり 2 cm）
- **遠くの個体の更新**: LOD により 2〜4 フレームごとに更新される個体は、歩行・跳躍を 50 ms 以下の刻みに分けて進め、骨格の姿勢づけは 1 回だけ行う（ばねは陰的積分で安定）。以前は 1 回の更新を 50 ms で打ち切っていたため、遠くの個体ほど動きが遅くなっていた
- **意図の切り替え**: 脳が新しい意図を出すと、歩行・遊泳中でもすぐに新しい目標へ向かう（または止まる）。驚いたときは、食いつきや転がりの途中でも中断して逃げる
- **自分の時計**: 状態の切り替えと継続時間はゲーム時刻、体の動きはフレームの dt で進む。描画が極端に遅い環境（ソフトウェア描画）では両者がずれるので、確認には仮想時計を使う（下の `probe.mjs`）

### 痕跡と接地

- **接触影**: 腹と尾のカプセル状の影、胸の下の濃い部分、胸びれの接地点の小さな影。体が持ち上がると薄く広がり、ジャンプ中は消える
- **泥の跡**（`MudFx`）: 胸びれの跡（鰭条の溝つき）、腹と尾を引きずった跡、跳躍の着地跡、ついばんだ穴。できたては水がたまって暗く光り、数分で薄れる。泥はね・水しぶきの粒子
- **波紋**: 水面を破るとき（遊泳、入水・上陸、浅い水での歩行、転がり）に、水面パスの法線を曲げる同心円の波を出す

## 既知の限界

- 吻端は皮膚の UV が一点に集まる極です。真正面から極端に近づくと、ハイライトにわずかなすじが見えます（粘液膜をそこだけ粗くして目立たなくしている）
- 第 1 背びれの斑紋、雄の繁殖期の跳躍ディスプレイ、雌雄差は簡略化しています（「背びれを立てる」表示はあり）
- 獲物は描画せず、泥の上の位置だけを決めています。食いついた跡は残ります
- 水槽（家）の水は全体が深いので、水槽では水面に浮いて休みます
- 潮だまりの岸線は、地形の水位テクスチャ（最近傍で読む）の格子で決まるため、近づくと階段状・直線状に見えることがあります（既存の水面描画の仕様。個体の判定は同じ格子を使うので、見た目と行動は一致します）
