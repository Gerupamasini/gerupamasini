# ガザミ（*Portunus trituberculatus*）— 砂底を横歩きし、櫂で泳ぐワタリガニ

走水・葛西の砂底の浅場にすむワタリガニ科（Portunidae）のカニ。Three.js の SkinnedMesh で、図鑑の種は `portunus_trituberculatus`。甲幅（左右の側棘の先端間）1〜23 cm。横に大きく張り出した甲羅の両端に長い側棘、前側縁に 9 対の鋭い歯、長く角張った鉗脚、細長い歩脚、そして櫂のように平たい第 5 脚（遊泳脚）。砂の上で鉗脚をたたんで休み、横歩きで移動し、砂をついばみ、後ろ向きに浅く潜って眼だけを出す。脅かされると鉗脚を広げて立ち上がり、逃げるときは横に走って、深ければ遊泳脚で泳ぎ去る。

- コード: `src/creatures/species/gazami/`（`anatomy.ts` 写真で測った体の寸法（甲幅 100 mm で）、`geometry.ts` 甲羅の輪郭と歯・脚の節・眼・口器・腹部の 3 段階のジオメトリとリグの定義、`mesh.ts` ジオメトリの組み立て、`rig.ts` 骨格・姿勢の適用・歩脚の IK、`poses.ts` 鉗脚と脚の姿勢、`behavior.ts` 7 状態、`materials.ts` 外殻・剛毛のマテリアル、`clay.ts` 形の確認用の粘土マテリアル、`model.ts` 個体の組み立て、`GazamiDriver.ts` ドライバ）
- データ: `public/data/species/portunus_trituberculatus.json`、行動ツリー `public/data/behaviors/swimming_crab.json`、図鑑の静止画像 `public/data/photos/portunus_trituberculatus.jpg`
- 確認用ビューア: `reference/gazami-viewer/`（`npm run dev` → `/gerupamasini/reference/gazami-viewer/index.html`。上・正面・側面・斜め・腹面・接写・水槽・砂底の浅場、粘土と PBR、LOD、体色 4 型・幼体・雌雄、7 状態のボタン）
- 画像の再生成: `npm run render:gazami`（ビューア、このフォルダの JPEG）、`node tests/smoke/gazami.mjs`（ゲーム内、走水）
- テスト: `tests/unit/gazami.test.ts`（甲羅の縦横比と側棘、歯の数、鉗脚と歩脚の節比率、輪郭が折り返さないこと・左右が鏡像でないこと、3 段階の LOD すべてに歯・棘・はさみ・遊泳脚が残ること、面の向き、70 本の骨、IK がすべての歩脚に届くこと、7 状態に入れること、足を地面に置いたままの横歩き、遊泳脚だけで泳ぎ歩脚は横へ水平に伸ばすこと（垂らさない）、浅すぎる水では泳がないこと、眼まで潜ること・砂のない所では潜らないこと、砂から飛び出して逃げること、鉗脚を広げ指を開く威嚇、水槽から出ないこと、個体ごとの色と雌雄の腹部）、`tests/unit/keptShaders.test.ts`（保持用モデルが全マテリアルを持つ）

## 1. 調査（写真資料 70 枚から）

## 2. 形の段階: 粘土で写真に合わせてから PBR へ

質感より先に形を合わせた。順序はシルエット → 脚 → ハサミ → 遊泳脚 → 甲羅。ガザミは遊泳脚と甲羅側縁の棘を外すと別物になるので、この二つを最初から最後まで照合の中心に置いた。

1. **シルエット（上から）**: 甲羅の輪郭を 61・19・55 に重ね、側棘の先端どうしを合わせて縦横比・最大幅の位置・前側縁の角度・後側縁の凹みを合わせた。歯の間の折れ・眼窩の切れ込み・T8 と側棘の付け根の角を直した。
2. **脚**: 歩脚の節比率と太さ、関節のくびれ、自然な開き角を 6・61 に合わせた。歩脚の先が地面に届くよう IK（各脚 2 関節の平面 IK）で立たせる。
3. **ハサミ**: 長節の棘、腕節、角柱の掌部、指の歯を 49・61・67 で合わせ、たたんだ姿勢（19）、威嚇（12、64）、正面（66）を FK の探索で写真に合わせた。前方へ突き出したり左右で交差したりしていたのを、内向きの回転の自由度を足し、基節を外へ移して直した。
4. **遊泳脚**: 前節と指節を平たい楕円の櫂にし、縁の剛毛と暗い先端を 47・55・61・65 で確かめた。
5. **甲羅**: ドームの高さ（66）、膨らみと溝、顆粒線、3 つの瘤（39）。ドームの放射状の筋と正中の折れ目は、法線を解析的に求め、高さを平滑化した輪郭の半径から取って消した。

## 3. 行動（7 状態）

行動（`behavior.ts`）は描画から独立していて、ドライバ・ビューア・テストが同じものを動かす。すべて甲幅（CW）単位なので、3 cm の幼体も 20 cm の成体も同じ動きを比例した速さで行う。

- **IDLE**: 砂の上に低く休み、鉗脚を前にたたむ（19、55）。眼を起こして見回し、第 1 触角を振り、遊泳脚を平らに置く。ときどき脚の位置を直す。
- **WALK**: 横歩き。6 本の歩脚が 3 本ずつ交互（L2 R3 L4 と R2 L3 R4）に振り出され、足は着いた所に置いたまま、先導側が伸ばして引き、後ろ側が押す。遊泳脚は後ろに持ち上げ（66）、鉗脚は前に構える。
- **FORAGE**: 短くゆっくり移動しては、鉗脚で交互に砂をつまんで口へ運ぶ。第 3 顎脚が動き、歩脚の指節が砂を探る。つまむたびに砂煙。
- **BURROW**: 後ろ向きの浅い潜砂（13）。前を上げ、遊泳脚と歩脚で砂を左右にかき出し、眼と甲羅の前だけが出るまで沈む。砂が背に積もり、出るときは砂を散らして飛び出す。
- **DEFEND**: 威嚇。脅威へ向き直り、脚で体を持ち上げ、鉗脚を上げて広げ指を開く（12、47、53、58）。揺れ、はさみを鳴らし、突きかかる。
- **ESCAPE**: 脅威から横向きに速く走って逃げる。水が十分深ければそのまま泳ぎ去り、そうでなければ潜る。
- **SWIM**: 底を離れ遊泳脚で泳ぐ。第 5 脚が毎秒数回 8 の字に櫂をこぎ（ひとかきごとに板の向きを返す、後ろの角で横から後ろへ振る）、体は横へ進む。歩脚は写真 6 のとおり左右へまっすぐ束ねて甲羅と同じ高さに伸ばし（先端は基節の高さ ±8 mm、テストで確認）、羽根のように体の傾きに合わせて角度を変える。鉗脚は前の下、体の面より低くに畳む（左を少し上にして指先を重ねる）。**水中で歩行の姿勢・動きのまま移動することはない**（以前の版は脚を下へ垂らしていたのを、写真 6 との照合で直した）。泳いでいる途中で別の状態に移ったときも、高さは底まで降ろしてから歩く。
- **眼**: 眼柄は滑らかに動かず、ひとつの向きに留まってはすばやく次へ跳ぶ（左右別々、ときに揃って）。脅威に気づいた瞬間や威嚇・逃避に入るときは両眼をさっと眼窩に引き込み、ゆっくり起こす。休んでいるときはときどき片眼を眼窩に引き込んで拭う（眼窩の剛毛が角膜を掃除する）。潜るときは畳み、潜った後は眼だけを出す。

## 4. 外殻と体色

MeshPhysicalMaterial（粗さ、濡れた殻の水膜のクリアコート、角膜の虹色）に `onBeforeCompile` で色と表面を書き込み、干潟の他の動物と同じ水中の光（水柱を通る日光、コースティクス、スネルの窓、水そのものの光）で照らす。テクスチャは使わない。色は休止姿勢の位置（mm）と部位から計算するので継ぎ目がなく、個体ごとに違い（シード、左右の鏡像にしない）、近づいても崩れない。

- **眼**: 眼柄から先端まで 1 枚の面で、角膜の縁は頂点ごとの符号付き距離から描くので分割の粗さに関係なく滑らか。角膜は個体ごとに灰緑色〜黒、色素の斑、縁寄りの淡い帯、見る方向の黒い偽瞳孔（観察者について回る）、0.06 mm の六角の個眼が光を拾う（近くでだけ）、水膜の小さく鋭いハイライト。眼柄は琥珀色で光を透かし、内側が赤紫、角膜の縁が淡い。砂は付かない。
- **前面**: 前縁の陰の鈍い灰褐色、第 3 顎脚の後ろの口の窩は暗く、板のまわりと間に隙間として見える。第 3 顎脚は白く、縫合・縦溝・内縁の鋸歯、鬚と外肢の節ごとの褐色の帯。触角は半透明の淡い琥珀色で、鞭に 0.22 mm の環節、第 1 触角の外鞭は暗い嗅毛の房。
- **背甲**: 型の地色に低周波のむら、地域ごとの暗色斑（胃域・心域・鰓域前線の後ろの帯・肝域。縁はぎざぎざで、強さは個体ごと。ほぼ無地の個体もいる: 62、64）、大きな暗い斑と淡い斑（強さは個体ごと: 36、64）、鰓域前線と H 字の溝に沿う途切れた淡い顆粒の帯（61、19）、前側縁ほど密で大きい白斑と鰓域の 2 つの大きな白斑（白斑は塗った円ではなく先の白い顆粒の集まりで、近くでは顆粒に分かれ間に地色が残る: 36、61）、歯の先は淡く側棘の先は暗い。顆粒は陰影の起伏として描き、顆粒の頂は粗い。
- **鉗脚**: 上面と外面は型の色で、白く不規則な斑が密に、ところどころ網目につながる（19、49）。下面は白。指は付け根から先へ紫がかった黒褐、先端は栗色〜赤（雌は橙がかる）、切断縁は淡い。
- **歩脚**: 上は鮮やかな青（64）から灰色がかったオリーブ（66）まで個体ごと、白斑、下は白、関節は少し暖色。指節は青で先が紫赤。
- **遊泳脚**: 長節・腕節は脚と同じ斑、板は半透明で、指節の先半分が青黒〜褐色。縁は淡く剛毛の付け根。
- **腹面**: 青白く光沢、胸板の縫合線。第 3 顎脚は白く、内縁が紫、縁が褐色（66）。前面（口のまわり・眼窩の底）は前縁の陰の鈍い灰褐色で、白い顎脚が浮き立つ（66）。
- **濡れと砂**: 水中では水膜（クリアコート）。背は顆粒で反射が細かく砕け、脚は背より反射を弱くしてある（上から見たとき光沢で色が抜けないように: 19、61）。空気中では乾いて鈍くなる。溝・関節・縁の下に砂と泥、潜った後は背を砂が覆い（`uSandCoat`）、出てしばらくで落ちる。底に接する部分は底の砂の色。

## 7. ゲームへの統合

- **ドライバ**（`GazamiDriver.ts`、`src/creatures/drivers/index.ts` に `gazami` で登録）: 脳（行動ツリー `swimming_crab.json`）の意図を 7 状態に割り当てる（`rest` → IDLE か潜ったまま、`wander`/`moveTo` → 歩く・深く遠ければ泳ぐ、`forage`、`burrow`、`display` → DEFEND、`flee` → ESCAPE）。観察者に気づくと（`alert`）行動ツリーが威嚇（`display`）か逃避（`flee`）を選び、カニはそのあいだ観察者の方を向く。
- **地形・水・潮**: 底の高さと水面の高さを毎フレーム地形から取り、浅すぎる所では泳がず、水の外へは出ない（水生の個体の移動先は水際で止まる）。潮が引いて水位が下がっても同じ規則で動く。
- **砂**: アカエイと共有の SandFX で、潜るとき・出るとき・つまむときの砂煙と、潜った跡のくぼみ。底質（砂・泥・礫など）の色を殻に付く砂の色にする。砂のない所（水槽・観察ケース）では潜らない。
- **接地の影**: 底に柔らかい楕円の影。泳いで離れると薄く広がる。
- **水中の光**: 干潟の他の動物と共通の水中の光（日光の透過、コースティクス、深さによる減衰、スネルの窓）。
- **LOD**: 種の `viewDistance_m` 14 m、3 段の Shell を距離で切り替え、遠くはプレースホルダー。
- **出現**: 走水の砂・砂泥の浅場（0.08〜1.4 m、夏〜秋、甲幅 14〜120 mm）と少し深い所の大きな個体（0.3〜2.0 m、60〜230 mm）、葛西の澪筋や潮だまり。
- **図鑑**: 静止画像は `tools/photos/capture-one.mjs portunus_trituberculatus` で撮り直せる。
