# アミメハギ（*Rudarius ercodes*）— アマモ場の小さなカワハギ

走水のアマモ場にすむ全長 2〜6 cm の小さなカワハギの仲間。Three.js の SkinnedMesh で、図鑑の種は `rudarius_ercodes`。尾を振り続ける「普通の小魚」ではなく、菱形の薄い体で葉のそばに浮かび、長い背鰭と臀鰭の波と胸鰭の細かな羽ばたきだけで定位・移動し、驚いたときだけ尾鰭で一気に逃げる。

- コード: `src/creatures/species/amimehagi/`（`anatomy.ts` 体形と寸法、`geometry.ts` 3 段階のジオメトリとリグ、`materials.ts` 皮膚・眼・鰭のマテリアル、`pose.ts` 鰭と体の姿勢、`Behavior.ts` 5 状態と鰭の運動、`seagrass.ts` アマモ場との連携、`model.ts` 個体の組み立て、`AmimehagiDriver.ts` ドライバ）
- データ: `public/data/species/rudarius_ercodes.json`、行動ツリー `public/data/behaviors/fish_seagrass.json`
- 確認用ビューア: `reference/amimehagi-viewer/`（`npm run dev` → `/gerupamasini/reference/amimehagi-viewer/index.html`。側面・背面・正面・撮影ケース・アマモ場、LOD、体色、脅かす・摂餌・隠れる）
- 画像の再生成: `npm run render:amimehagi`（ビューア）、`node tools/models/amimehagi/ingame.mjs`（ゲーム内）
- テスト: `tests/unit/amimehagi.test.ts`（体形、ジオメトリと重み、鰭の波、5 状態、眼、水中に留まること）

ゲーム内ではデバッグ（F3）で日付を夏にし、走水の「アマモ場」へ飛んで「周囲に生物」で出せる（`debugSpawn('rudarius_ercodes')` でも可）。

## 1. 調査（写真資料 70 枚と種の記載から）

写真資料は側面が中心（生きた個体の撮影ケース・手のひら・水中、標本）。背面 1 枚、正面 1 枚、頭部・眼・皮膚・尾鰭・腹の拡大がある。

| 部位 | 写真で確かめたこと | モデル |
|---|---|---|
| 体型 | 菱形で非常に高い。背は軟条背鰭の起点（体の中ほど）がいちばん高く、腹は腹部の三角の突出（腰骨の先端と皮弁）がいちばん低い。そこから後ろは急に細まり、尾柄は短く低い。第一背鰭棘と軟条背鰭の間で背は浅くくぼむ | 側面 3 枚（黒背景の約 35 mm、手のひらの約 45 mm、白い板の約 65 mm）から吻端〜尾鰭基底の軸に対する背・腹の高さを全長比で測った表（Catmull-Rom 補間）。体高（軟条背鰭起点〜腹部の突出）は全長の 0.57 |
| 側扁 | 背面・正面の写真では体はごく薄く、最大幅は眼のあたりで体高の約 1/6。背と腹の縁はナイフのように鋭い | 最大幅は全長の 0.094（体高の 0.17）。断面は「幅の最大線」から上下へ `x = hw · (1 − v^p)^(1/q)`（q を 1 に近づけるほど鋭い縁）。頭は丸みのある楔、腹部の突出がいちばん薄い |
| 吻・口 | 吻は短くとがり、口は吻端に小さく開き、厚く淡い（ピンクがかった）唇がわずかに上を向く | 吻端のふくらみと唇の線。下唇から顎は骨 `J_jaw` に乗り、ついばむときに開くと唇の間の線がそのまま暗い口の開きになる |
| 眼 | 大きく、高い位置（吻から全長の約 0.2 後ろ、軸から 0.07 上）。少し突き出る。眼球の外周は体と同じ皮膚の厚い縁に覆われ、見えているのは虹彩と瞳の開口だけ。その縁に淡い輪のある個体が多い。虹彩は淡い銀色〜クリーム色、または金色で、細い放射状の筋、瞳のまわりの明るい輪、外側の橙褐色の帯。瞳は丸く黒く、光を受けると奥から濃い青〜青緑に光る（網膜の反射層） | 球の眼（`Eye_L` / `Eye_R`、半径 0.052 TL）を眼窩に沈め、それぞれ自分の骨で回す。その外周に、頭に固定された肉厚の皮膚の輪（開口の半径 0.036 TL から頬まで。わずかに縦長）を重ね、眼球はその下で動く。輪は頬と同じ模様で、開口の際は薄く暗く湿って光を通す。虹彩は個体の色（金色系か銀色系）で、放射状の筋・小さな暗点・瞳の縁の暗い輪、角膜はクリアコートと薄膜干渉。瞳は濃紺で、正面ほど・縁ほど青く光る（自己発光ではなく水中の光の反射として） |
| 第一背鰭棘 | 眼の後端の真上から立つ太い棘。後ろへ反り、後縁に下向きの小さな棘（かえし）が 2 列並ぶ。根元の後ろに暗色の膜。立てたり、背の溝に倒したりする | 棘（`DorsalSpine`）は前後に厚く左右に薄い反った管で、後縁にかえし 7 対、前縁の先に小突起。根元の後ろに膜。骨 `J_spine` で立てる・倒す（倒すと背に沿って寝る） |
| 軟条背鰭・臀鰭 | 体の後半に長く低い鰭が背と腹に対になる（背鰭 26 軟条前後、臀鰭 24 前後）。透明で鰭条が淡く黄褐色。付け根に暗い線 | 鰭条単位の膜（`DorsalFin` / `AnalFin`）。付け根に沿った 7 本ずつの骨（`J_dor0..6`、`J_ana0..6`）が鰭条を左右に振り、波が前から後ろへ走る |
| 胸鰭 | 鰓孔のすぐ後ろ、眼の下端の高さに小さな丸い胸鰭。透明 | 斜めの付け根から上の鰭条ほど長い丸い扇（`PectoralFin_L` / `_R`）。付け根と中ほどの 2 本の骨で、羽ばたきの波が外へ伝わる |
| 尾鰭 | 丸い扇形、12 軟条。鰭条に暗褐色の帯が 3〜4 列横切る。ふだんは畳み気味、泳ぎ出すと広げる | 丸い扇（`CaudalFin`）。上下 2 本の骨（`J_cau_U` / `_L`）で開閉。暗い帯は鰭条の上で濃く、膜で淡い |
| 鰓孔 | 胸鰭の付け根の前上に短い斜めの切れ込み | 暗い斜めの線と淡い縁を描く |
| 網目模様 | 淡い丸い斑点が暗い網目に囲まれて並ぶ。頭では細かく、体では大きい。網目の太さ・斑点の大きさと数・地色は個体ごとに大きく違う（橙に白斑、褐色の網目、オリーブ、灰褐に青白い点、黄、暗色にまだら、さび色、淡色に褐色の鞍状斑）。腹部の突出の先は暗色 | セル雑音（Voronoi）で斑点と網目を生成。斑点のあいだを暗色が埋め、境目に細い暗線。頭ほど細かい。鞍状斑 3 本とまだら、細かな黒色素胞。個体ごとのマテリアルで 8 系統の体色＋明るさ・色味のずれ＋斑点の位置が全部違う |
| 体表 | 細かいざらざらの鱗（棘のある顆粒）。つやは弱い半光沢で、顆粒が光を拾って細かくきらめく。白い糸状の小さな皮弁が散る。生きた小さな個体は体全体がやや透け、白斑は皮膚の下からにじむように見える。細かな黒点と、斑点の間の小さな淡点が密にある | 顆粒（約 0.15 mm）を法線の凹凸と淡い点描で描き（画面で 1 画素より細かくなる距離で消える）、粗さ 0.6、シーン（ビロードの艶）、薄いクリアコート（粘液）。白斑は縁がぼけ（皮膚の厚い所ほど）、中心が明るい。斑点の間に小さな淡点、黒色素胞は星形の小点で背と暗い気分のときに増える。皮弁は小さな円錐 76 本 |
| 色の変化 | 驚いたときや夜は暗くなり、鞍状斑とまだらが濃く出る | `dark`（0〜1）が 1〜2 秒で追従。隠れるとき 0.6、眠るとき 0.85 |
| 生息 | アマモ場・ガラモ場・海藻のある岩礁の浅所。群れずに数尾がゆるく集まる。葉や海藻のそば、頭を下げた姿勢で静止していることが多い | 走水のアマモ場（`eelgrass` と `eelgrass_edge`）に春〜秋、1〜4 尾 |
| 動き | 尾鰭を畳んだまま背鰭・臀鰭を波打たせ、胸鰭を細かく動かして、ほとんど同じ場所に浮かぶ。向きを変えるのも体を曲げずに鰭で。急ぐときだけ尾を振る | 下記 2 章 |

寸法: 全長 14〜65 mm（平均 36 mm）。モデルは全長 40 mm で作り、個体の全長で拡大縮小する。

## 2. 行動

| 状態 | 内容 | 脳の意図 |
|---|---|---|
| `HOVER` | 葉の 2〜3 cm 脇で定位。頭を少し下げ、背鰭・臀鰭の小さな波と胸鰭の羽ばたき（毎秒 5〜8 回）で姿勢を保つ。尾は畳んで舵。ときどきその場でゆっくり向きを変える | `rest`、`special`（hide 以外） |
| `SLOW_SWIM` | 目的地へ向かって葉から葉へ。1 区間 10〜28 cm、各葉で 0.3〜1.4 秒止まる。速さは毎秒体長の 1〜2 倍まで、尾は振らない | `wander`、`moveTo` |
| `FORAGE` | 近くの葉の表面（付着生物）か砂の上（小さな底生生物）を選び、眼を向けて近づく → 両眼で狙って止まる → 0.11 秒で突進して口を開く（吸い込み）→ 下がる → 噛む。1 か所で 1〜3 回 | `forage` |
| `SEAGRASS_HIDE` | いちばん近い株を選び、株を脅威との間に挟む位置で、葉に沿って頭を下げて（約 −60°）止まる。棘を立て、腹部の突出を下げ、体色を暗くする。脅威が回り込むと株の反対側へ回る。夜は葉を口にくわえて眠る（鰭の動きも遅い） | `display`（警戒）、`burrow`、`special: hide`、`special: sleep`（夜） |
| `ESCAPE` | 0.12 秒で向きを変え（体が C 字に曲がる）、尾鰭を広げて 0.6 秒ほど強く打ち（毎秒体長の約 10 倍）、鰭で滑走しながら近くのいちばん濃い茂みへ。止まるとそのまま `SEAGRASS_HIDE` | `flee`（割り込み可） |

- 鰭の運動は動きから決める: 背鰭・臀鰭の波の振動数と振幅は前後の速さ・横の速さ・旋回の速さで増え、後ずさりでは波が逆向きに走る。両鰭は同じ側へ振れる（ロールが打ち消し合う）。旋回では背鰭・臀鰭が少し片側へ寄り、外側の胸鰭が強く打つ。尾は `ESCAPE` の突進のときだけ振る（毎秒 11〜14 回）。
- 眼は左右それぞれ独立に動く（フグ目の魚の特徴）。0.35〜1.8 秒ごとの速い視線移動（サッカード）で周りを見回し、警戒中や隠れているときは脅威へ、摂餌では両眼をついばむ点へ向ける。左右の眼はそれぞれ自分の側しか見ない。
- 第一背鰭棘はふだん半ば立て、ゆっくり上下する。隠れる・逃げるときは立てる。腹部の突出は警戒で下がる。
- アマモ場との関わり（`seagrass.ts`）: 定位・移動・隠れる場所は実際の株の位置から選ぶ（`AmamoMeadow` が育てたパッチの株を 25 cm の格子で引く）。株の軸に近づきすぎると押し返され、葉の間を縫う。株の葉が潮流でどれだけ傾くかはアマモのシェーダーと同じ式で求める。潮流にはわずかに流される。
- 葉を押しのける: 近い段階（LOD0・1）の魚は位置と半径をアマモのシェーダーへ渡し（同時に 8 尾まで）、その近くを通る葉の中心線を魚から遠ざかる向きへ曲げる。魚の近くに葉がある株だけが計算する。
- 水の中に留まる: 頭を下げた姿勢でも吻が砂に、頭を上げても水面に出ないように高さを保つ。観察ケースと水槽では枠の中に留まり、葉はない（定位と隠れる場所は底）。

行動ツリー `fish_seagrass`: 近すぎれば逃避 → 浅すぎれば深みへ → 警戒が高ければ隠れる → 夜は葉をくわえて眠る（85 %）→ 定位 34 %・摂餌 32 %・移動 22 %・隠れる 12 %（25 秒に 1 回まで）。逃避距離は 0.75 m（ハクより近くまで寄れる。逃げるより隠れる魚）。

| 段階 | 距離（40 mm 個体） | 三角形 | 内容 |
|---|---|---|---|
| LOD0 | 0.75 m まで、観察中は常に | 17,450 | 名前の付いた 10 メッシュ（`Head` `Body` `Eye_L` `Eye_R` `DorsalSpine` `DorsalFin` `AnalFin` `PectoralFin_L` `PectoralFin_R` `CaudalFin`）。体は 64 周 × 88 輪、皮弁、眼を覆う皮膚の縁、眼球、かえしのある棘、鰭条単位の膜 |
| LOD1 | 0.75〜3.6 m | 1,781 | `Body`（24 周の体、小さな眼、棘）と `Fins`（5 枚の鰭）の 2 メッシュ |
| LOD2 | 3.6 m〜表示距離 12 m | 270 | `Body` 1 メッシュ（10 周の体と不透明の尾。模様は平均の色、眼は描き込み） |

```
AmimehagiRoot
├── J_root（骨格: 背骨 5、顎、眼 2、棘、腹部の突出、胸鰭 4、尾鰭 2、背鰭 7、臀鰭 7 の 31 本）
└── AmimehagiLOD
    ├── LOD0: Body / Head / Eye_L / Eye_R / DorsalFin / AnalFin / PectoralFin_L / PectoralFin_R / CaudalFin / DorsalSpine
    ├── LOD1: Body / Fins
    └── LOD2: Body
```

- ジオメトリは段階ごとに 1 つだけ作って全個体で共有。個体は自分の骨格とマテリアル（皮膚 2・鰭 1）だけを持つ。マテリアルは同じシェーダープログラムを共有するので、個体が増えてもシェーダーは増えない。眼のマテリアルは全個体で 1 つ。
- 段階の切り替えは `THREE.LOD`（カメラごと、ヒステリシス 12 %）。遠い段階ほど姿勢の計算も省く（LOD1 は胸鰭の波と眼、LOD2 は鰭を省く）。ドライバの更新は既存の `CreatureSystem` の間引き（4 m 以内は毎フレーム、`DRIVERS.amimehagi.nearDistance`）。接地影は遠い段階で半分の頻度。
- PBR: `MeshPhysicalMaterial`（粗さ、シーン、クリアコート）を `onBeforeCompile` で拡張。トーンマップは既存のレンダラーの ACES Filmic。
- 水中の光: 皮膚・鰭・眼の反射と環境光は、アマモ場の澄んだ緑の水の光の場（真上はスネルの窓に押し込まれた空、横は水の散乱光、下は日の当たる砂）。太陽の直射光は水面から魚までの道のりで色ごとに減衰し（赤が早く消える: 1 m あたり 0.42 / 0.075 / 0.11）、波の焦線が上を向いた面に揺れる（深いほど弱い）。
- 透過（subtle translucency）: 頂点ごとに体の厚み（その点の左右の幅）から光の通りやすさを求め（`exp(−厚み / 0.028 TL)`）、(1) 魚の後ろの水の光が体を透けて見える分、(2) 日差しが後ろから来るときの輝き、(3) 光の当たる側から陰の側への回り込み（明暗の境がやわらかい）、(4) 視線がかすめる縁の乳白色の散乱、を足す。透けた光は血と色素を通った暖色になる。腹部の突出、背と腹のナイフ状の縁、鰭の付け根、眼の縁の皮膚、棘の膜、皮弁がいちばん透ける。
- 水中の視線の減衰: カメラが水面より上なら既存の `WaterPass` が屈折・濁り・水面反射を重ねる。観察カメラがアマモ場で水面下に入ったときのために、`WaterPass` に水中のカメラの分岐を足した（視線の道のりで水の散乱光へ溶け、水面を下から見ると窓の中に空、外は水の鏡）。
- 太陽のシャドウマップは小魚には粗いので、魚は影を落とさない。代わりにハクと同じ接地影（`ContactShadows`。親グループごとに 1 つの `InstancedMesh`）を、薄く高い体に合わせた大きさで描く。

## 4. ゲームへの組み込み

- `src/creatures/drivers/index.ts` に `amimehagi` を登録（モデルはドライバが作るので GLB なし）。
- `World` は走水のアマモ場を作ったあと `seagrass.bind(meadow)` で魚に渡し、離れるときに外す。
- アマモのシェーダー（`src/world/amamo/shader.ts`）に押しのけの項（`uAmPush`、8 個）を足した。`AmamoKit.uniforms.uAmPush` に書くだけで、魚以外も使える。
- `WaterPass` に水中のカメラの分岐を足した（上記）。水面より上のカメラの描画は変わらない。

## 6. 既知の制限

- 鰭条は付け根で回る剛い線で、鰭条そのものはしならない（波は隣り合う鰭条の位相差で表す）。
- 魚が葉を押しのけるのは同時に 8 尾まで（近い順ではなく、近い段階に入った順）。葉が魚の体を貫くことは押しのけで減るが、密な株の中を突進するときは残る。
- 株の位置は育った（描かれている）パッチからしか分からない。遠くの魚は葉のない場所と同じように振る舞う（見えないので差はない）。
- 雌が卵を守る繁殖行動（夏、海藻に産みつけた卵の世話）はまだない。
