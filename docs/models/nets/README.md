# 干潟採集用タモ網 6 種 — 写実 3D モデル（Three.js / GLB）

`src/assets/models/nets/` に 6 種 × 3 LOD（hero / lod1 / lod2）の GLB、実行時ヘルパー `netMaterials.ts`、寸法と重量をまとめた `manifest.json` があります。形状とテクスチャはすべて `tools/models/nets/` の手続き生成で、写真テクスチャは使っていません。

```bash
npm run model:nets                      # 18 個の GLB と manifest.json を作り直す（約 80 秒）
npm run model:nets -- --net net_deep --tier hero
npm run render:nets                     # この文書の画像を作り直す（ヘッドレス Chromium、約 2 分）
npm run dev  →  http://localhost:5173/gerupamasini/reference/nets-viewer/   # ビューア（濡れ・泥・モーフ・クリップ）
```

- 重量は各部品の体積（パイプは肉厚から）× 材料密度、網と布は面積 × 目付で積算した推定値です。重心は柄の軸上の位置で、振りの重さ（慣性）の目安になります。いずれも GLB の `extras.higataNet` と `manifest.json` に入っています。
- 柄の長さは石突きから柄先（口金の付け根）まで。全長は枠の先端まで。

## 3. GLB の構造（ゲームから使う前提）

座標は glTF 標準の **メートル、+Y 上**。柄は **+Z（グリップ → 網口）** に伸び、+X が右。**原点 = 利き手のグリップの中心** なので、手のボーンにそのまま付ければ持たせられます。

```
net_xxx                  (extras.higataNet: 寸法・重量・重心・材料・クリップ一覧)
├─ Handle                柄（伸縮・継ぎ柄は Handle_Inner / Handle_Mid / Handle_Tip が子として連なり、-Z へ動かすと縮む）
│   └─ … └─ Frame_Pivot  柄先。枠のしなり・折りたたみ（カーボン網は Frame_Fold クリップ）の回転軸。D 網はここで 34° 曲がる
│              ├─ Frame  枠・口金・縁（テープ／縁布／ロープ）
│              ├─ Bag    網袋（モーフ 4 種）
│              └─ Mouth  網口の中心。ローカル +Y が開口の向き（捕獲判定・着水判定に）
├─ Grip_Main             利き手（原点）
└─ Grip_Support          添え手
```

**網袋のモーフターゲット**（`Bag`、法線モーフ付き）

| 名前 | 状態 | 使いどころ |
|---|---|---|
| `Stream` | 袋が開口と逆向き（-Y）にピンと伸びる | すくい上げる、D 網を押し進める |
| `Invert` | 袋が枠を通って上（+Y）へ吹き返す | 網口から水へ突っ込む |
| `Trail` | 袋が柄の側（-Z）へ流れる | 水中で前へ振る |
| `Wet` | 水を含んで細くなり、しわが張りつく | 水から上げた直後 |

![網袋のモーフ（左から 通常・Stream・Invert・Trail・Wet）](bag_states.jpg)

**クリップ**（モーフだけを動かすので、手の動きと自由に重ねられます）: `Bag_Scoop`（振る→すくい上げる→垂れる）、`Bag_Dip`（突っ込む→上げる→水を含む）、`Bag_Shake`（濡れた網を振る）、カーボン網のみ `Frame_Fold`。

## 4. マテリアルと濡れ・泥

- 全マテリアル PBR（ベースカラー・法線・ORM＝AO/粗さ/金属）。テクスチャは実寸で繰り返すタイル（UV はメートル ÷ タイル寸法、`extras.higataNet.tileMetres`）なので、柄の長さに関係なく近接でも解像度が落ちません。追加の拡張は `KHR_materials_clearcoat`（カーボン、ラバー網）と `KHR_materials_sheen`（布・撚り糸・マルチフィラメント網）。
- 網袋は **アルファブレンド** です。近くでは糸がくっきり（フル解像度ではアルファがほぼ 0 か 1）、離れるとミップで平均されて実物どおりの「透けた網」に見えます。アルファテストにすると遠目で網が消えるため使っていません。影は糸の被覆率でディザした部分的な影になります（`netMaterials.ts`）。
- 頂点属性 `COLOR_0` は焼き込んだ遮蔽（袋の奥ほど暗い）、`_DIRT` は泥のたまりやすさ（袋の底、枠の下側、口金まわり）です。
- `prepareNet(root)` が各マテリアルに濡れ・泥のシェーダーを足します。

```ts
import { prepareNet, createNetLOD } from '@/assets/models/nets/netMaterials';
const net = prepareNet(createNetLOD({ hero, lod1, lod2 }));   // GLB の scene を 3 つ
handBone.add(net.root);
net.setSurface({ wet: 1, mud: 0.6, waterline: waterY });     // 水面より下はずぶ濡れ、袋は水の色に沈む
net.setBag({ Trail: 0.8 });                                  // 振っている間
net.update(dt);                                              // 水が抜けて乾いていく
```

濡れは素材の吸水性（`porosity`: 金属 0 … 綿帆布 1）に応じて暗くし、すべてを艶っぽくします。泥は `_DIRT` と位置ノイズで斑に乗り、細かい網目は泥で目詰まりします。

## 7. 既知の制限

- ゲーム本体の `NetView.ts`（一人称のタモ）と `ToolShelf.ts`（棚）はまだ従来の手続きメッシュのままで、この GLB には差し替えていません。道具データ（`public/data/items/tools.json`）の 3 種とこの 6 種の対応づけも未定です。
- 網袋の揺れはモーフの重ね合わせなので、魚が入って膨らむ・岩に引っかかるといった個別の変形はできません。必要なら `Bag` をボーン数本でスキニングする拡張が次の段階です。
- 画像はヘッドレス Chromium のソフトウェア WebGL（SwiftShader）で描いたもので、ポストプロセス（被写界深度・ブルーム・SSAO）はかけていません。
