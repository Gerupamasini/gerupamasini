# ミミイカ（*Euprymna morsei*）— 砂底に潜む小さなダンゴイカ

走水の浅い砂底にすむダンゴイカ科（Sepiolidae）の小型イカ。Three.js の SkinnedMesh で、図鑑の種は `euprymna_morsei`。外套長（胴の長さ）2〜4 cm。丸い袋のような胴、耳のような丸いヒレ、頭の両側を占める大きな眼、短い 8 本の腕と収納式の 2 本の触腕。昼は砂に潜って眼だけを出し、夜に出てヒレを波打たせて底近くに浮かび、アミなどの小さな甲殻類を触腕で捕らえる。驚くと墨を吐き、漏斗のジェットで胴を先にして逃げ、降りた所でまた潜る。

- コード: `src/creatures/species/mimiika/`（`anatomy.ts` 体形・眼・腕・触腕・ヒレ・漏斗の寸法、`geometry.ts` 3 段階のジオメトリとリグの定義、`rig.ts` 骨格と姿勢の適用、`behavior.ts` 7 状態、`materials.ts` 皮膚（色素胞）・ヒレ・眼のマテリアル、`prey.ts` 餌のアミ、`model.ts` 個体の組み立て、`MimiikaDriver.ts` ドライバ）
- データ: `public/data/species/euprymna_morsei.json`、行動ツリー `public/data/behaviors/squid_sand.json`、図鑑の静止画像 `public/data/photos/euprymna_morsei.jpg`
- 確認用ビューア: `reference/mimiika-viewer/`（`npm run dev` → `/gerupamasini/reference/mimiika-viewer/index.html`。側面・背面・正面・斜め・水槽・砂底の浅場、LOD、体色（淡色・中間・濃色）、7 状態のボタン）
- 画像の再生成: `npm run render:mimiika`（ビューア、このフォルダの JPEG）、`node tests/smoke/mimiika.mjs`（ゲーム内、走水）
- テスト: `tests/unit/mimiika.test.ts`（体の比率、眼・腕・触腕・ヒレの寸法、皮膚の向き、階層名と LOD、7 状態に入れること、ヒレの波と遊泳、潜砂で腕が頭越しに砂をかけ眼だけ出ること、墨と胴先行のジェット逃避、狩りの成功、砂からの待ち伏せ、水面と砂の間に留まること・砂のない所で潜らないこと、体色の変化）、`tests/unit/keptShaders.test.ts`（保持用モデルが全マテリアルを持つ）

## 1. 調査（写真資料 70 枚と一般的な知見から）

写真資料（`ミミイカ 写真資料 70 枚`）は水中写真・水族館・飼育水槽・網やバケツの中の個体。**確認** は写真で直接確かめたこと、**推定** は写真から読み取れないため近縁の *Euprymna scolopes* などの文献と一般知見から決めたこと。写真 23 はミミイカではなくギンポの仲間（同定の誤り）なので使っていない。

## 2. 行動（`behavior.ts`）

脳の意図（`squid_sand`）がどれをするかを決め、行動がそれを実行して姿勢（根の位置と向き、頭、腕 40 関節、触腕、ヒレ、外套膜、漏斗、両眼、埋没と砂、色素胞）と視覚効果（砂煙・墨）を書き出す。描画なしで動くので単体テストで確かめている。

| 状態 | 内容 |
|---|---|
| REST | 腹と腹側の腕を砂に下ろして頭を上げ、ヒレを胴に沿って下げる。外套膜が呼吸で毎秒 1.4 回ふくらみ（±2.2 %）、ときどきヒレの縁が波打ち、眼が見回す。警戒（`display`）すると濃くまだらになって動かず、眼で相手を追う |
| HOVER | 砂の 0.5〜1 外套長上で、両ヒレの細かな進行波（毎秒 2.5 回）でとどまる。頭はやや下、腕は前へゆるく束ねる。漏斗の弱い一吹きで位置を直す。体色は淡く透明に、点が散り、虹色素胞が見える |
| SWIM | 漏斗の一吹き（と砂の小さな煙）で底を離れ、ヒレの波（毎秒 2.6〜4.2 回、速いほど速く大きく、少し羽ばたく）で腕の方へ進み、旋回では外側のヒレを強く打って体を傾ける。ときどき弱いジェットを足す。着く前に減速し、沈んで小さな砂煙とともに降りる |
| CRAWL | 底の上の短い移動。腹側の腕を伸ばしては引き寄せ（0.9 秒周期）、引く間だけ体が進む。ヒレはこまかく震える |
| BURROW | 着底 → 漏斗を下へ向けた強いジェットで胴の下の砂を吹き飛ばし（0.38 秒ごと、砂が胴の縁の左右と前から飛ぶ）、体を揺すって沈む → 第 1・第 2 腕を頭の上から後ろへ巻き上げて砂を投げ、左・右・両方と 5 回かけ、頭と背に砂がかかる → 眼と頭頂だけを出して潜む（体は頭をわずかに上げ、背の高い胴の上に投げた砂が薄く乗る）。出るときは上へ一吹きして砂を落とすが、粘液に付いた砂はしばらく残り、泳ぐと早く落ちる |
| HUNT | アミを見つけて両眼で見つめ、向き直る（腕を円錐に閉じ、淡い体色に暗いちらつき）→ ヒレで近づく → 届く距離（触腕の 0.85 倍）で 0.1 秒で触腕を撃ち出し、腕を開いて少し突進 → 8 割で掌部に捕らえ、触腕を縮めて腕で抱え、3〜6 秒で食べる（腕が拍動し、アミが小さくなる）。逃したアミは尾扇で跳んで逃げ、1 回だけ追い直す。砂に潜っているときは待ち伏せで、そばを流れてきたアミを砂の中から撃つ（体は半分しか出ない）|
| ESCAPE | 一瞬で濃くなり（0.1 秒）、ヒレを胴に巻き付けて外套膜をふくらませる → 漏斗の先に墨を吐き、白くなる → 腕を危険の方へ向けたまま、胴を先にして 3 回のジェット（毎回弱く、外套膜は 0.8 倍まで縮む）で斜め上へ逃げる → 開いたヒレで滑空 → 着底し、7〜8 割はその場ですぐ潜る（ほかは動かず固まる）。潜っていたときは砂を噴き上げて飛び出す |

意図との対応（`MimiikaDriver.setIntent`）: `rest` → REST（夜は 4 割で HOVER）、`wander`/`moveTo` → 12 cm（外套長に比例）までは CRAWL、それより遠ければ SWIM、目標なしは HOVER、`forage` → HUNT（潜っていれば待ち伏せ）、`burrow` → BURROW、`flee` → ESCAPE、`display` → 固まる、`special`（`hide`/`sleep`、水槽・ケース）→ BURROW。砂のない水槽やケースでは潜らず、埋まって生まれた個体は出てくる。網は砂に半分以上潜っている間は入らない（`canNetCapture`）。

行動ツリー `squid_sand`: プレイヤーが近い（0.7 m × 警戒）と逃避、水深 6 cm 未満で深みへ、警戒 0.45 以上で固まる。**昼**（`time_is day`）は 72 % 潜砂（60〜240 秒）・12 % 休息・6 % 短い移動・10 % 狩り（ほぼ待ち伏せ）、**夜明け・夕方・夜**は 18 % 休息・32 % 移動・36 % 狩り・14 % 潜砂。

## 3. 皮膚と体色（`materials.ts`）

標準の PBR（`MeshPhysicalMaterial`: 濡れた粘液のクリアコート、虹色素胞の iridescence）に `onBeforeCompile` で皮膚を組み込み、アミメハギと共有の水中の光（水柱を通った太陽光の減衰とコースティクス、スネルの窓、水の散乱光）で照らす。模様はテクスチャを使わず、静止姿勢での位置（mm）で計算するので継ぎ目がなく、個体ごとに違う。

- **色素胞（網目）**: 写真 7・12・26・29 の休息時の模様は、暗褐〜黒の多角形の器官が細い淡色（黄の組が広がると金色）の線で区切られた網目。暗い組は皮膚の上のボロノイのセル（3 次元のずらした格子の近い 8 点、皮膚面に沿った距離）1 つに 1 器官で、縮むと丸い点、広がるとセルいっぱいの多角形になって隣と細い線で接する（`mmReticle`）。背は大きめ（0.6 mm）、脇腹から腹は小さく密（0.34 mm）。器官ごとにしきい値・脈動・色（赤褐〜黒、ときに赤）が違い、縮んだ器官は赤褐の点になる。黄（0.3 mm）と赤（0.55 mm）の組は別の器官で、黄の組は淡い体色では地全体を黄橙にする（写真 17、34）。広がり方は背・頭・腕の外側に強く腹に弱い分布と、ゆっくり流れる斑（`uChroma.w`）で決まり、最大に近いと黒紫の地になる。画面で小さすぎる器官はその平均の被覆に置き換わり、ちらつかない
- **虹色素胞**: 眼の上の青緑の斑（左右の眼の上にモザイク状、写真 3・6・7・22）、外套膜の側面前寄りの金緑の面（写真 12）、背の網目の中の青・紫のきらめき、腹の銀。暗い色素胞の下に隠れる。`material.iridescence`（鏡面の薄膜干渉）に加え、板の積み重ねが広い角度に色を返すぶんを自分の色として出す（見る角度で虹色が流れる）
- **半透明**: 生きたミミイカの体はガラスのように透ける。色素胞のない組織は背景を透かし（休息のまだらでは色素が覆うので控えめ、浮かぶ・狩りの淡い体色ではほとんど透明）、正面では薄い壁 1 枚ぶんしか光を遮らず、輪郭へ向かうほど組織を長く通るので乳白になる（視線と法線の角度で不透明度を変える）。外套膜の中には `Viscera`（銀の膜に包まれた暗い墨袋、橙褐色の消化腺、左右の淡い鰓）があり、組織越しに輪郭のぼけた影として見える（写真 17、24、62）。水中の光が組織を通って赤みを帯びて出てくる
- **吸盤**: 立体の杯（淡く半透明、縁が明るく、くぼみが暗い）。遠い段では口側 2 列の模様
- **外套腔**: 襟の内側の内壁は色素胞がなく淡く濡れ、奥ほど暗い（外套の口からの光だけが届く）。襟の丸い縁は色素が薄い
- **砂**: 潜ると背と頭に砂粒（ずらした点と細かいノイズ、白い石英と黒い粒が少し）がかかり、眼にはかからない。砂の部分は周りの砂底と同じ光で照らし（水中の環境光を落とす）、砂底に接する所で透明にして砂底に溶け込ませる
- **ヒレ**: 半透明の膜、付け根ほど色素胞が多く、縁は澄む。前から後ろへの進行波（振幅・位相・波数は行動から）を頂点シェーダーで作り、法線も波の傾きから直す。外套膜のふくらみにも付け根が付いていく
- **外套膜**: 呼吸とジェットの半径方向の伸縮を頂点シェーダーで（体積を保つようにわずかに伸びる）。首から前の頭・腕は動かない
- **遠景（LOD2）**: `MM_LOW` で器官・起伏・虹色を消し、器官の平均の色だけを残す（LOD0 の平均色と合わせてある）

## 4. モデルの構成（`model.ts`、`geometry.ts`）

```
MimiIkaRoot
├── Armature
│   └── J_root ─ J_head ─ J_eye_L ─ Eye_L
│               │       ├ J_eye_R ─ Eye_R
│               │       ├ J_funnel
│               │       ├ J_arm{I,II,III,IV}{L,R}_0…4   （腕 8 本 × 5 関節）
│               │       └ J_ten{L,R}_0…5                （触腕 2 本 × 6 関節）
│               ├ J_fin_L
│               └ J_fin_R
└── MimiIkaLOD
    ├── LOD0: Viscera（透けて見える内臓、外套腔の鰓）, Mantle（外面・襟・内壁）, Head（内臓塊の袋〜頭）, Funnel, Fin_L, Fin_R, Arms（吸盤つき）, Tentacles（掌部の吸盤つき）
    ├── LOD1: 同じ部位を粗く
    └── LOD2: Mantle, Head, Fin_L, Fin_R, Arms（内臓・漏斗・触腕なし）
```

## 6. ゲームへの統合

変更は最小限: ドライバの登録 1 行（`src/creatures/drivers/index.ts`）と、種データ・行動ツリー・マニフェスト・図鑑の静止画像の追加だけで、水・地形・潮汐・生物管理（`CreatureSystem`）は変えていない。

- **出現**: 走水の裸地・アマモ場の縁・浅瀬の砂と砂泥（水深 12 cm〜1 m、春〜秋、0.5/100 m²、1〜2 個体、最大 10）、冬は大きめの個体が少なく（0.2/100 m²）。葛西は夏〜秋の夕方〜夜の上げ潮に砂の浅瀬でまれに（0.12/100 m²）。昼はたいてい潜っていて、生まれたときも 3 個体に 2 個体は潜っている。見つけるには偏光サングラス（G）と低い視点（C）で砂から出た二つの眼を探すか、夜に来る
- **水・潮**: 水中の光は共有の uniform（水面の高さ `uSurfaceY` をドライバが入れる）、水の減衰と霧はゲームの水のパスがかける。浮かぶ高さは水面の下に抑え、浅くなると脳が深みへ動かす（最小水深は外套長の 0.9 倍）
- **底質**: 足元の底質の色（`SUBSTRATE_TINT`）が砂の被膜と砂煙の色になり、暗い底ほど褐色の色素胞が広がる
- **昼夜**: 太陽が水中に影を落とさない明るさになると夜とみなし、瞳孔が開き、休息の意図の一部が浮遊になる。行動ツリーは `time_is` で昼と夜を分ける
- **砂煙・墨**: アカエイの `SandFX` を個体ごとに 2 つ（砂の色と墨の色）。遠景（LOD2）では出さない
- **接地影**: ハクの `ContactShadows` の板。座っていると小さく濃く、浮かぶと広く淡く、潜ると消える。超軽量では出ない
- **LOD と更新**: ドライバ自前の 3 段（`nearDistance` 2.5 m 以内は近い個体として毎フレーム更新）。観察中は LOD0 に固定。シェーダは読み込み中に保持用モデル（全段の皮膚・ヒレ・眼、アミ、砂煙）でコンパイルし、その浜にいる間は保持する
- **図鑑**: 7 つの行動（底に伏せる・浮かぶ・泳ぐ・腕で這う・砂に潜る・狩り・墨を吐いて逃げる）がドライバのイベントで記録される

確認: F3 の「出す生物」でミミイカだけにして「周囲に生物」、またはコンソールで `__higata.debugSpawn('euprymna_morsei')`。昼は潜っているので、観察（F）で寄るか、夜の時刻（デバッグの時刻）にすると浮かんで狩りをする。`node tests/smoke/mimiika.mjs` は走水の水際に 3 個体を置き、昼の潜砂と休息、夜の狩り、観察の接写を撮る。

## 7. 限界と今後

- 発光器（腹側の共生発光）と、夜に月明かりの下で影を消すカウンターイルミネーションは形にも光にもしていない
- 墨は砂煙と同じ粒子の雲で、墨の「偽体」（体の形にまとまった墨）はない
- 交接・産卵（卵塊を岩の下に産む）、雌雄差は入れていない
- 砂の被膜は皮膚の色で表しており、地形の高さは変えない（潜った跡の盛り上がりは体そのもの）
