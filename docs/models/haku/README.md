# ハク（ボラ *Mugil cephalus* の稚魚）

汽水域・干潟の浅場で群れて泳ぐボラの稚魚「ハク」の 3D モデルと行動。Three.js の SkinnedMesh で、図鑑の種は `mugil_cephalus`（ボラ）、成長段階 `haku`（ハク、全長 35 mm 以下）。

- コード: `src/creatures/species/haku/`（`anatomy.ts` 体形、`geometry.ts` 3 段階のジオメトリとリグ、`materials.ts` 共有マテリアル、`swim.ts` 遊泳波、`School.ts` 群れと 5 状態、`ContactShadows.ts` 底の影、`HakuDriver.ts` ドライバ）
- データ: `public/data/species/mugil_cephalus.json`、行動ツリー `public/data/behaviors/fish_school.json`
- 確認用ビューア: `reference/haku-viewer/`（`npm run dev` → `/gerupamasini/reference/haku-viewer/index.html`）、静止画は `node tools/models/haku/render.mjs`
- テスト: `tests/unit/haku.test.ts`（ジオメトリ、遊泳波、群れ、逃避、水際、流れへの定位）

## 調査（写真資料 70 枚から）

| 部位 | ハクの特徴 | モデル |
|---|---|---|
| 体型 | 細長くほぼ円筒形。体高は全長の約 0.18、頭のすぐ後ろが最も高い。尾柄が長い | 断面は上下で指数の違う超楕円。体高・体幅・背側比を表で与え、Catmull-Rom で補間 |
| 頭部 | 幅広で上が平たい。吻は短く鈍いくさび形で、背の輪郭が吻へ下がる | 吻は深さと幅で別の指数で閉じる（ドーム状にしない） |
| 眼 | 大きい（全長の約 0.06、頭長の 1/3）。銀白の虹彩、外縁に真鍮色、細い暗色の縁、大きな黒い瞳 | 頭から少しだけ膨らむ扁平楕円体。角膜は clearcoat |
| 口 | 小さく端位で、やや下向き | 吻端の暗い切れ込み。顎の骨 `J_jaw` で下顎が下がる |
| 体色 | 背は細かな黒点（メラノフォア）が散るオリーブ灰色で半透明、体側は鏡のような銀、腹は白。胸びれの付け根に黒い腋斑 | 背→銀→腹のカウンターシェーディング、星形の黒点、腋斑 |
| 銀色 | グアニン結晶の反射層。体側は鏡で、ひとつひとつの鱗の向きが少しずつ違う | 金属度 0.95・粗さ 0.17 前後、鱗ごとの法線の傾き、筋節の「<」形、鰓蓋の虹色（薄膜干渉） |
| 透明感 | 稚魚は尾柄と背が薄く、底が透ける | 薄い部位に背後（底）の光を足す（subtle translucency） |
| 背びれ | 2 基が大きく離れる。第 1 背びれは体の中ほどの小さな棘 4 本、第 2 背びれは臀びれの上 | 棘の間で切れ込む膜。第 1 背びれは高速時に倒れる（`J_d1`） |
| 胸びれ | 鰓蓋のすぐ後ろ、体側の高い位置 | 停止時は小刻みに煽ぎ、高速では体に沿う（`J_pec_L/R`） |
| 腹びれ | 腹位で小さい | 対の小さな膜 |
| 尾びれ | 二叉。付け根に黒点が集まる個体が多い | 二叉の輪郭、分岐する鰭条と節 |

## 行動

| 状態 | 内容 | 脳の意図 |
|---|---|---|
| `IDLE` | 中層で流れに向かって定位。胸びれで煽ぎ、尾は数回打っては滑る | `rest` |
| `SCHOOL_SWIM` | 水面下数 cm を、向きのそろった群れで巡航（体長の 3〜4 倍/秒） | `wander`、`moveTo`、`display`（警戒時は群れを詰めて離れる） |
| `FORAGE` | 群れがゆるみ、各個体が浅場では底の珪藻膜を、深いところでは水面の浮遊物をついばむ。ついばむ瞬間に口が開き、体側がきらりと光る | `forage` |
| `ESCAPE` | 脅威を見た個体から「驚きの波」が 2.5 m/s で群れを伝わり、各個体が自分の反応遅れ（10〜50 ms）を足して C スタート（頭が逃避方向へ回り込み体が C 字に曲がる → 尾の一打ち）で体長の 22 倍/秒まで加速。いったん放射状に散り、詰まった速い群れにまとまって逃げ続ける | `flee`（割り込み可） |
| `SURFACE_SWIM` | 群れ全体が水面のすぐ下へ。背は水面から数 mm 下、ときどき吻が水面に触れる | `special: surface` |

- 群れの状態は群れのメンバーの脳が決める。状態が終わると最初に意図を出した個体の案が採用され、残りは従う。逃避だけは誰の意図でも群れ全体に伝わる。
- 群れの基本は軽量な boids: 最も近い 7 尾（位相的近傍）からの分離・整列・凝集、群れ中心へのばね、遅れた個体の加速。状態ごとに重みと間隔が変わる（逃避中は詰まり、摂餌中はゆるむ）。
- 個体差: 速さ、反応遅れ、間隔、泳ぐ深さ、尾の振幅、ゆらぎ（向きの小さなぶれ）を個体ごとに持つ。
- 遊泳波: 体側の中心線を `A·e(s)·sin(2πs/λ − φ) + ½κ(s − 0.38)²` で与え、`e(s) = 0.18 − 0.62s + 1.44s²`（頭 0.18、尾端 1）、`λ = 0.95 TL`。頭はほとんど振れず、尾ほど大きく、波は頭から尾へ進む。尾の振動数は速さから（Bainbridge: `U = L(0.75f − 1)`）、遅いときは打っては滑る。旋回の曲率 κ は角速度と速さから。
- 水深の層: `SURFACE_SWIM` は水面直下、`SCHOOL_SWIM` は水面下 1.2〜7 cm（浅いほど上）、`IDLE` はやや深め、逃避は少し潜る。常に背は水面下、腹は底から離れる。
- 流れ: 群れの位置の水位の変化率から潮流を出す（上げ潮は斜面を岸へ、下げ潮は沖へ。水位 1 m/h でおよそ 10 cm/s を上限 5 cm/s で）。潮だまりと水槽では止まり、弱い風の吹送流だけが残る。魚は流れに流され、`IDLE` では流れに向かって定位する。
- 水際: 先読みで浅い側を避け、それでも乾く一歩は打ち消す。引き潮で取り残されそうなときは既存の `keepInWater` が群れを深みへ戻す。

## 描画

| 段階 | 距離（30 mm 個体） | 三角形 | 内容 |
|---|---|---|---|
| LOD0 | 0.9 m まで、観察中は常に | 8,704（体と眼 7,216、ひれ 1,488） | 体 74×40、眼、ひれ 7 種（鰭条の分解能） |
| LOD1 | 0.9〜4.5 m | 1,200 | 体 26×16、小さな眼、尾・背・臀・胸びれ |
| LOD2 | 4.5 m〜表示距離 14 m | 192 | 体 11×8 と尾を 1 メッシュに（1 ドローコール、不透明） |

- ジオメトリは段階ごとに 1 つだけ作って全個体で共有。個体は自分の骨格（15 本）だけを持ち、3 段階が同じ骨格を使う。段階の切り替えは `THREE.LOD`（カメラごと、ヒステリシス 12 %）。
- マテリアルは `MeshPhysicalMaterial`（PBR、clearcoat、虹色）を `onBeforeCompile` で拡張し、個体の見た目 4 種 × 体（LOD0/1）・体（LOD2）・ひれ の 9 個を全個体で共有。シェーダーは段階ごとに 1 本。
- 銀色の反射は水中の光場を映す: 真上はスネルの窓（48.6°）に押し込まれた空（環境マップ）、横は濁った水のオリーブ色の散乱光、下は日の当たる底。上から見るとオリーブ灰色の細い影に淡い縁、体を傾けたときに窓が映ってきらりと光る。鱗ごとに鏡の向きが違うので、泳ぐと細かくきらめく。
- 水面直下の魚は既存の画面空間の水（`WaterPass`）が屈折・濁り・水面反射・ぎらつきを重ねるので、水面の反射と一致する。ひれは深度を書かない半透明。
- 太陽のシャドウマップは 1 テクセルが数 cm で稚魚には粗すぎるため、魚は影を落とさない。代わりに底に「接地影」: 屈折した太陽の方向に投影した魚形のぼかし影を、親グループごとに 1 つの `InstancedMesh`（1 ドローコール）で描く。底に近いほど濃く小さく、高いほど淡く大きい。曇りと夜は消える。
- 更新頻度: 5 m 以内は毎フレーム（`DRIVERS.haku.nearLod_m`）、それより遠くは 2 フレームに 1 回（既存の CreatureSystem の間引き）。LOD1 では胸びれの細かい動き、LOD2 では体軸の波以外を省き、LOD2 の影は半分の頻度。群れの近傍探索は群れの中だけ（20〜30 尾）。
- 汽水・干潟への馴染み: 濁った水のオリーブ色の散乱光（`WaterPass` と同じ色）、底の砂の反射、浅い水深での層、潮流、波の焦線（コースティクス）が背に揺れる。
