# ヤマトオサガニ（*Macrophthalmus japonicus*）— 泥干潟の巣穴のまわりで暮らすオサガニ

葛西の泥・砂泥の干潟にすむオサガニ科（Macrophthalmidae）のカニ。Three.js の SkinnedMesh で、図鑑の種は `macrophthalmus_japonicus`。甲幅 8〜40 mm（雄は 40 mm、雌は 38 mm まで: Wada 2018）。横長の長方形の甲、甲の前縁の溝から高く立つ細長い眼柄、成熟した雄の大きく白いはさみ、平たく幅広い長節の歩脚。巣穴のそばで眼柄を立てて見張り、横歩きで泥の表面をすくって食べ、危ないと巣穴に駆け込み、しばらくすると眼柄だけを出してから出てくる。

- コード: `src/creatures/species/osagani/`（`anatomy.ts` 写真で測った体の寸法（甲幅 35 mm で）、`geometry.ts` 甲羅の輪郭・溝・脚の節・眼柄・顎脚・腹部の 3 段階のジオメトリとリグ、`rig.ts` 骨格・姿勢の適用・歩脚の IK、`poses.ts` はさみと脚の姿勢、`behavior.ts` 7 状態、`materials.ts` 殻・剛毛のマテリアル、`clay.ts` 形の確認用の粘土マテリアル、`model.ts` 個体の組み立て、`burrows.ts` 巣穴の描画、`OsaganiDriver.ts` ドライバ）
- データ: `public/data/species/macrophthalmus_japonicus.json`、行動ツリー `public/data/behaviors/mud_crab_burrow.json`、図鑑の静止画像 `public/data/photos/macrophthalmus_japonicus.jpg`
- 確認用ビューア: `reference/osagani-viewer/`（`npm run dev` → `/gerupamasini/reference/osagani-viewer/index.html`。上・正面・側面・斜め・腹面・接写、粘土と PBR、LOD、雌雄、7 状態のボタン）
- 画像の再生成: `npm run render:osagani`（このフォルダの JPEG、構図は `tools/models/osagani/shots.mjs`）、`node tests/smoke/osagani.mjs`（ゲーム内、葛西）
- テスト: `tests/unit/osagani.test.ts`

## 1. 調査

依頼に添付された 2 つの写真資料と、文献の比率で決めた。写真は利用条件がまちまち（CC BY-NC、著作権留保を含む）なので、写真そのものはリポジトリに入れていない（照合は同じ構図のレンダリングで示す）。

- **A**（51 枚: Wikimedia Commons 5、iNaturalist 46）: 野外の個体、手に持った個体、巣穴、威嚇
- **B**（70 枚: iNaturalist 58、実体顕微鏡写真 12 = B59〜B70）: 真上・腹面・眼柄・はさみの接写
- **CC0 の 3D スキャン**（ffish.asia / floraZia.com、Sketchfab の雄 1 個体）: 断面を切り出して、甲の深さ・側壁・脚の断面を測った。参照のみでゲームには入れていない（ビューアに置けば重ねて表示できる: `reference/osagani-viewer/scan.glb`）
- **文献**: Wada (2018, Crustacean Research 47) の回帰式（雄の甲長 CL = 0.451 + 0.663 CW、成熟雄のはさみの前節長 log PL = −1.719 + 2.105 log CW）

## 2. 形の段階: 粘土で写真に合わせてから PBR へ

形が写真と合うまでは質感に進まなかった。比べたのは粘土のレンダリングと、同じ構図の写真（正面 A45・A47、上 B24・B63、側面 B7、3/4 B29・A28、接写 B59・B34）。直したこと:

1. **甲が浅すぎた**: 最初の版は甲の厚さが 0.32 CW で平たかった。スキャンの断面（中央・横・水平）を切り出すと 0.44 CW の深い箱で、側壁はほぼ垂直、背は後ろへ卵形に落ちる。体の側壁・前面・胸板を作り直し、歩脚の付け根を側壁の下に移した。
2. **側縁が後ろへすぼまりすぎた**: 輪郭を、側縁がほぼ平行で後側縁が丸い形に直した（スキャンの水平断面、B65）。外眼窩歯と 2 つの前側縁歯の切れ込みを深くし、上から歯が見えるように（B63）。
3. **雄のはさみが小さかった**: 0.75 CW → Wada (2018) の式の 0.97 CW に合わせて掌部と指を大きくし、指を 50° → 60° 曲げた（B33、B34）。立ち姿の構えを、正面 A45 の位置（顔の前に下げ、指先を正中の泥に）に順運動学の探索で合わせた。
4. **歩脚の膝が低かった**: 長節が下を向いていた。立ち位置を内へ寄せ、指節を立てて、長節が甲の縁より上へ上がり膝から先がほぼ垂直に下りるようにした（A45、A47、B7）。
5. **脚が放射状の等間隔だった**: 上から（B24）脚が車輪のスポークのように見えた。膝のひねり（前脚は前へ、後脚は後ろへ）を加え、IK もそれを含めて解く（`swungTip`）。
6. **節の端が丸く、ソーセージのようだった**: 端を短い縁で切り、首のくびれを強く。長節を幅広い傾いた板に（スキャンの脚の断面）。
7. **雄のはさみが正面から細長い紡錘形に見えた**: 掌部が先で細くなり、指が掌部の先から細い V 字で真下へ出ていた。正面 A45 で外側の面の輪郭を測り直すと、掌部は先端で最も高く、不動指は掌部の下半分全体から下縁に続いて出て、指は掌部の軸から約 40° 下（これまでの 60° は斜めの写真の見かけ）、閉じた指先は掌部の 1.6 倍先。掌部の断面を下へずらして上縁をまっすぐに、指を太く長く浅い角度に作り直し、立ち姿の構えを順運動学の探索で合わせ直した（外側の面を前へ、指先を正中の泥の上 0.4 mm に）。体を低くする姿勢（巣穴の口・採餌）でも指先が泥に潜らないよう、体の高さに応じて腕を上げる。

## 3. 外殻と体色

MeshPhysicalMaterial（粗さ、濡れた殻の水膜のクリアコート）に `onBeforeCompile` で色と表面を書き込む。テクスチャは使わない。色は休止姿勢の位置（mm）と部位から計算するので継ぎ目がなく、個体ごとに違い（シード、左右の鏡像にしない）、近づいても崩れない。泥干潟の干潮時に暮らす種なので、照明は場の光のまま（水中の光の特別扱いはしない: 水の描画が上にかかる）。

- **体色**: 泥色〜灰褐色の 3 型（泥褐色 45 %、灰褐色 35 %、暗いオリーブ灰 20 %: A45、A13、B7、B41、A28、B49）と、淡く砂色の若い個体（B24、B52）
- **微細な色ムラ**: 低い周波数のまだら、細かく密な暗色の点（B63、B65、B69）、溝は暗く、顆粒線と眼窩の数珠は淡い
- **甲羅の粒状感**: 0.3 mm の顆粒を陰影の起伏として描く（遠くでは自然に消える）
- **粗さのむら**: 顆粒の頂は粗く、溝と泥膜は艶がない
- **薄い泥汚れ**: 溝・縁の下・体・足先に泥、個体ごとの泥の多さ（B56、B57）、巣穴に入ると増え、外で少しずつ乾いて落ちる。泥の色は足元の底質
- **関節部の色差**: 関節の縁と関節膜は黄褐色（A45、B29）、長節に暗い帯（B65、B70）、下面は淡い
- **はさみ**: 雄の掌部はクリーム色〜青白く（B12、B14）、細かい網目、上縁は褐色、切断縁は暗褐色、指先は橙色（B29、A45）。雌は褐色〜青灰で指先が淡紅色（B62、B68）
- **極細の剛毛**: 甲の側縁、長節の後縁、前節の下面、指節の縁、雄の鉗脚長節、雌のはさみの指（1 本ずつ描いた半透明の毛のカード）
- **湿った殻**: 水の中・巣穴の中では濡れて艶やか、干潟の上ではゆっくり乾いて鈍くなる（干潮のあいだは湿ったまま）

## 4. 行動（7 状態）

行動（`behavior.ts`）は描画から独立していて、ドライバ・ビューア・テストが同じものを動かす。すべて甲幅（CW）単位。

- **IDLE**: 巣穴のそばで眼柄を立てて見張る。眼柄は向きを保ってはすばやく次へ移り（左右別々、ときに揃って）、危険があればそちらを向く。はさみは顔の前に構え、ときどき脚の位置を直す。巣穴の口では低く構える。
- **WALK**: 横歩き。8 本の歩脚が 4 本ずつ交互（L2 R3 L4 R5 と R2 L3 R4 L5）に、持ち上げ → 送り → 再接地。足は着いた所に留まり、体がその上を過ぎる（足先は地形の高さに IK で合わせる）。届かなくなった脚はその場で踏み出す。体は一歩ごとにわずかに上下し、進む側へ少し傾く。
- **FORAGE**: はさみで交互に泥の表面をすくい（下ろして開く → 閉じる → 口へ）、第 3 顎脚が動く。ときどき横に少しずれて次の場所へ。
- **BURROW_ENTRY**: 巣穴へ戻り（危ないときは走って）、口の上で進む側を穴の傾く方へ向け、横向きに沈み、眼柄だけになったところから斜めの穴を滑り下りる。脚とはさみを体に引き寄せ、眼柄は最後に畳む。
- **BURROW_EXIT**: 眼柄から先に出て、眼柄だけの状態でしばらく見回し（危険があればすぐ戻る）、それから這い出て脚を泥に着く。
- **DEFEND**: 危険の方へ向き直り、脚を伸ばして体を起こし、はさみを高く上げて開き、揺らしながら上下に振る。
- **ESCAPE**: 巣穴が近ければ横走りで駆け戻ってそのまま潜る（BURROW_ENTRY へ）。遠ければ危険から離れる方へ走る。

## 6. ゲームへの統合

- **ドライバ**（`OsaganiDriver.ts`、`src/creatures/drivers/index.ts` に `osagani` で登録）: 脳（行動ツリー `mud_crab_burrow.json`）の意図を 7 状態に割り当てる（`flee` → ESCAPE、`rest` → IDLE か巣穴の中で待つ・顔を出す、`wander`/`moveTo` → WALK、`forage` → FORAGE、`burrow` → BURROW_ENTRY、`display` → DEFEND）。観察者に気づくと（`alert`）威嚇か巣穴への逃避を選ぶ。
- **地形**: 足先・体の高さ・傾きは毎フレーム地形（`floor.heightAt`）から取る。凸凹の泥でも足は地面に着き、貫通しない（テストで確認）。
- **潮**: 巣穴の上の水が 10 cm を超えると巣穴に入って出てこない（行動ツリーの `depth_above` とドライバの両方）。泥の上では殻は湿ったまま、水の中・巣穴の中では濡れる。
- **巣穴**: 個体の住みか（発生した場所）に、それぞれの向きに傾いた巣穴。コメツキガニの巣穴描画（`kometsukigani/Burrows.js`）を地図ごとに 1 つ共有し、近くは本物の穴（斜めの坑道と深度の蓋: 穴の中のカニが見える）、遠くは暗い口と掘り出した泥の縁のデカール。カニの接地影も同じ描画で。
- **衝突**: 動物どうしの押し合い（`body: { width: 1.6, height: 0.45 }`、`nudge`）。巣穴の中では押されず（`away`）、網でもすくえない（`canNetCapture`、`hidden`）。水槽・観察ケースでは巣穴を掘らない。
- **出現**: 葛西の泥・砂泥の干出域と水際・浅い所（春〜秋、甲幅 10〜40 mm、最大 22 匹）、冬は少なく大きい個体だけ。
- **図鑑**: 静止画像は `node tools/photos/capture-one.mjs macrophthalmus_japonicus`。
