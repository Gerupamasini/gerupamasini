# 図鑑の画面改善

分類ごとの索引と生物の詳細を分け、名前検索・分類・干潟・発見状況を組み合わせて絞り込めます。名前検索は、ひらがな・全角／半角カタカナに対応します。発見済みの種は学名・英名でも検索できます。

未発見種は和名だけを表示し、画像・3Dモデル・学名・性差・生態・生息環境・行動名・採集記録を表示しません。干潟の絞り込みはゲームの出現設定に基づき、季節や潮位を問わず一覧を探せます。生物無効のマップ（現在の漫湖）には該当種を表示しません。マガキの出現データも実際に牡蠣礁がある葛西だけに合わせ、走水に誤表示しないようにしました。

PCは索引と詳細の2ペイン、スマホは一覧から詳細への切り替えです。一覧に戻ると絞り込み条件を維持します。詳細は「生態」「行動」「採集」「履歴」を切り替え、長い情報を一度に並べません。分類見出しに発見数、上部に全体の進捗を表示します。超軽量画質は既存モデルの静止画像、その他の画質は回転・拡縮できる既存の3Dプレビューです。スマホの一覧ではプレビュー用のWebGLコンテキストを作りません。履歴・採集でもモデルを非表示にして記録を広く表示し、プレビューのWebGLコンテキストを解放します。

Esc／閉じるボタンで元の画面に戻ります。図鑑内のTabはフォームやボタンの移動に使い、ゲームの図鑑切り替え操作と競合しないようにしました。しおりと観察履歴は既存セーブに追加できる任意項目として保存します。

## しおり・条件・観察履歴

- **しおり**：切り込みとステッチのある紙のリボン形タブから、登録した生物だけを表示します。各生物の名前の横で挟む・外す操作ができ、未発見種も登録できます。しおりでは発見扱いにせず、研究PやCRも付与しません。スマホで最後のしおりを外した場合は空の一覧に戻ります。
- **出会いやすい条件**：「生態」の折りたたみ欄で、干潟ごとの季節・時間帯・潮を確認できます。実際の出現設定に基づき、異なる条件の組み合わせを混ぜません。場所や水深による制約は引き続きあるため、表示は目安です。
- **観察履歴**：「履歴」に初登録日と、干潟別の最初／最後の記録、観察回数、採集回数を表示します。実際の観察開始・採集成功時に記録し、毎フレームや水槽内の行動では増やしません。日時はゲーム内の日本時間で、潮時チケットで過去・未来へ移動した場合も選んだ日付を保ちます。最初／最後は操作順なので、最後の記録の日付が過去に戻る場合もあります。
- **自分が出会った生物**：干潟を絞ると「出現する生物」「出会った生物」を切り替えられます。後者は実際に記録された干潟を使い、他の干潟での発見だけでは表示しません。「行動未完了」で、発見済みかつ観察していない行動が残る種も探せます。
- **採集個体**：日時と干潟を個体表に追加しました。古い記録は座標から干潟を推測せず「干潟不明」として維持します。

しおり、干潟別履歴、個体の採集干潟はセーブ・読み込み・JSONエクスポート／インポートに対応しています。既存セーブにない場所履歴は作りません。履歴は種×干潟で集約するため、プレイ時間に応じた無制限のログ増加もありません。

## 検証

`npm run check`、`npm run build`、`npm run smoke:zukan -- --field`、`npm run smoke:recovery`。

新しい図鑑のブラウザ検証は分類・干潟・発見状態・検索の組み合わせ、未発見情報の非表示、行動記録、採集個体、Tab／Esc、静止画像と3D表示の切り替えを扱います。スマホは390×844、320×568、844×390、768×1024で、一覧／詳細の往復と画面内への収まりを確認します。Chromiumで検証し、スクリーンショットはテスト用の発見記録で撮影しています。スマホの3D表示は端末回転後のアスペクト比も確認します。`--field`では実際に干潟へ入り、観察・採集のアプリ側処理が現在の干潟を記録することを確認します。
