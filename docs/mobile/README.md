# スマホ・タブレットの操作

タッチ端末では操作ボタンが表示されます。ブラウザの開発者ツールでも、モバイル表示を有効にして再読み込みすると確認できます。スマホではデバッグ画面・生物のデバッグラベル・F3の案内を表示せず、`?debug=1` やF3でもデバッグモードを開きません。

| 画面 | 操作 |
| --- | --- |
| ホーム | 下部に図鑑・ショップ・ガチャ・干潟へ・道具・水槽・潮見表の７ボタンを一列に表示。一段上の右下に「視点移動」「UI非表示」「設定」。「視点移動」で左スティックと上下移動・リセットを開き、１本指で回転、２本指で拡大・移動。「UI表示」で非表示から戻る。通常時は画角を固定。 |
| 水槽・観察・ケース | 1本指で回転、2本指で拡大。水槽では2本指の移動で視点を平行移動。 |
| 水槽編集 | 水槽がパネルの上（横画面では左）に収まる配置。生物を選んで操作し、設備は種類を絞って「位置・向き」「デザイン」を切り替える。「水槽を見る」でパネルを小さくし、「編集を表示」で戻す。飾りはドラッグ、設備は数値入力で配置。 |
| 干潟 | 左スティックで移動、空いている画面をドラッグして視点変更。同時に操作でき、スティックの倒し量で移動速度を調整。 |
| 採集・観察 | 右下の道具名を押して選び、「採集」「観察」を押す。その下に立つ／しゃがむ・走る・ジャンプを常時表示。望遠はメニューから長押し。双眼鏡・走るも長押し。採集中は「次へ」、観察中は「観察を終了」で戻る。 |
| 干潟のメニュー | 「メニュー」から地図・ケース・図鑑・潮時チケット・サングラス・自宅へアクセス。「設定」から感度・画質・セーブの入出力を行う。感度は0.3〜10。 |
| ガチャ | ホーム下部の「ガチャ」から引く。専用チケット初期10枚、1回1枚。獲得した設備を水槽編集で選択。 |
| ケース | ６個体を小さな選択ボタンで表示。選んだ個体を逃がす／研究に送る。ケースの3D表示はパネルに隠れない位置へ配置。 |
| 潮見表 | 日付を押してカレンダーを開き、年月・日を選ぶ。その日のグラフや満潮・干潮の時刻から潮時チケットを使う。日付制限はなく、７月の大潮のおすすめから干潮時刻を直接選べる。 |

初回起動時のタッチ端末の画質は「軽い」です。保存済みの設定を優先し、設定画面から変更できます。PCのキーボード・マウス操作も利用できます。

導入以外は画面中央に操作案内を重ねず、採集結果は画面の端に表示します。「網を振る」の案内はPCでも表示しません。殻が地表に出ているアサリ・ハマグリは網で採集でき、潜った貝はスコップで掘ります。

地図・潮位グラフ・月・図鑑の3Dプレビューは、スマホ向けの小さい表示で残しています。行き先選択は日本・東京湾の地図と２地点をコンパクトに表示し、縦横ともスクロール不要です。干潟メニューは右下の操作ボタンを避けて開きます。縦・横画面、ノッチ周辺の余白、ブラウザの高さ変更に対応しています。

## 確認

```sh
npm run check
npm run build
node tests/smoke/mobile.mjs
node tests/smoke/tide-calendar.mjs
node tests/smoke/home-camera.mjs
```

モバイル確認はChromiumのタッチ端末エミュレーションとソフトウェアWebGLを使用し、390×844・320×568・568×320・844×390で実際の複数指入力・画面内のボタン配置・行き先選択のスクロール不要を検証します。露出したハマグリの網採集、潜ったハマグリの除外、ケースへの追加も実際のゲーム処理で確認します。実機での速度・発熱は端末ごとに別途確認が必要です。
