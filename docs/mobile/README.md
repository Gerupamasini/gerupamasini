# スマホ・タブレットの操作

タッチ端末では操作ボタンが表示されます。ブラウザの開発者ツールでも、モバイル表示を有効にして再読み込みすると確認できます。スマホではデバッグ画面・生物のデバッグラベル・F3の案内を表示せず、`?debug=1` やF3でもデバッグモードを開きません。

| 画面 | 操作 |
| --- | --- |
| ホーム | 左スティックで視点位置を移動。右側の「上へ」「下へ」で高さを変更。「視点リセット」で初期位置へ戻る。 |
| 水槽・観察・ケース | 1本指で回転、2本指で拡大。水槽では2本指の移動で視点を平行移動。 |
| 水槽編集 | 下部の編集パネルで生物・レイアウト・設備を選択。「水槽を見る」でパネルを小さくし、「編集を表示」で戻す。飾りは水槽内でドラッグして配置。設備は数値入力で位置を変更。 |
| 干潟 | 左スティックで移動、空いている画面をドラッグして視点変更。同時に操作でき、スティックの倒し量で移動速度を調整。 |
| 採集・観察 | 画面上部で道具を選び、右側の「採集」「観察」を押す。双眼鏡・望遠・走るは長押し。「立つ／低い視点」「ジャンプ」も右側から操作。採集中は「次へ」、観察中は「観察を終了」で戻る。 |
| 干潟のメニュー | 「その他」から地図・ケース・図鑑・潮時チケット・サングラス・自宅へアクセス。「メニュー」から設定とセーブの入出力を行う。 |
| ガチャ | ホームの「ガチャ」から引く。専用チケット初期10枚、1回1枚。獲得した設備を水槽編集で選択。 |

初回起動時のタッチ端末の画質は「軽い」です。保存済みの設定を優先し、設定画面から変更できます。PCのキーボード・マウス操作も利用できます。

縦・横画面、ノッチ周辺の余白、ブラウザの高さ変更に対応しています。スクロールするパネルの外側で視点を操作してください。

## 確認

```sh
npm run check
npm run build
node tests/smoke/mobile.mjs
node tests/smoke/home-camera.mjs
```

モバイル確認はChromiumのタッチ端末エミュレーションとソフトウェアWebGLを使用し、390×844・320×568・568×320・844×390で実際の複数指入力と画面内のボタン配置を検証します。実機での速度・発熱は端末ごとに別途確認が必要です。
