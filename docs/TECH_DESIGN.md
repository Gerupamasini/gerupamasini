## 2. モデル構造

### 2.1 胴体（BodyGeometry）
- 軸方向パラメータ s（吻端 0 → 尾鰭基底 1、尾鰭内部へ 1.035 まで延長）と周方向 θ（腹中線 0 → 左体側 → 背中線 π）のシート。
- 断面：上下別指数のスーパー楕円。上端・下端・半幅・最大幅の高さ・指数はそれぞれ `monotoneCubic` による単調 3 次補間（計測点をオーバーシュートしない）。
- 行分布は頭部・鰓蓋・口唇に密（CDF 反転）、列分布は眼の周囲に密（左右対称を強制）。
- 口：口腔（奥の袋）→唇の縁→体表 と連続した 1 枚のシート。閉口状態（横長のスリット）を基本形状とし、開口（突出した O 字の唇＋口腔）との差分を `aMorphMouth`/`aMorphMouthN` に格納。
- 頭部ディテール（法線方向変位）：厚い唇、口角〜眼前下方の上顎の皺、鼻孔と皮弁、C 字の鰓蓋後縁・鰓孔の溝・鰓蓋板の段差、前鰓蓋の弱い稜、頭頂の窪み、**左右で異なる微小ノイズ（±0.1 % SL）による非対称性**。
- 眼窩：眼球の露出 50 % を想定し、眼球下に皮膚を押し込み、縁に肉質の襞を盛る。
- 鰓蓋外転：蝶番（前方）で 0、自由縁で最大となる外側変位 `aMorphOperc`。溝の三角形が引き伸ばされ暗赤色の鰓が見える。
- 属性：鱗マスク・鰓マスク・唇/口腔マスク・局所厚み（SSS 用）、鰓蓋マスク・背腹座標・左右・眼窩マスク、接線、鱗 UV。
- **鱗 UV は断面の弧長**に基づく（U：体軸方向の鱗単位、V：側線から背腹方向）。鱗の大きさは頭側・尾柄で小さく、列数は尾柄に向かって自然に減る（周尾柄鱗数 < 体中央）。

### 2.2 鰭（FinGeometry）
- 鰭ごとに鰭条定義（基部位置・角度・長さ）を持ち、全鰭条に頂点列＋鰭条間に膜列（LOD0:2 列、LOD1:1 列、LOD2:0 列かつ 1 本おき）。
- **2 層の閉じたシェル**：法線 ±方向に厚み（肉質の基部 ≈1 % SL → 縁 2 µm 相当、鰭条に稜）を持たせ、第一・最終鰭条と基部を帯で閉じる。
- 頂点は形状を持たず（位相座標のみ）、形はリグテクスチャのチェーンから GPU で復元。

### 2.3 眼
- 単位球（光軸 +Z）を InstancedMesh で配置。背骨フレーム × 眼の基準姿勢 × サッカード回転。
- 瞳孔（円形・固定）、虹彩（金〜赤〜銀の個体差、放射状の線維、瞳孔縁の明るい輪、暗い角膜縁）、角膜の clearcoat。

## 3. スケルトン（リグ）

| 要素 | 内容 |
|---|---|
| 背骨 | 24 サンプル（位置＋四元数、ワールド）。GPU で Catmull-Rom 補間＋ nlerp。連続曲線に沿った変形なので線形ブレンドスキニング特有の潰れが出ない。 |
| 鰭条チェーン | 尾鰭 9 本×10 節、背鰭 5×7、臀鰭 4×6、胸鰭 2×(4×7)、腹鰭 2×(3×6) = 1 尾あたり 241 節（位置＋膜法線）。膜は鰭条間・鰭条方向の双 Catmull-Rom で再構成。 |
| その他 | 口開度、左右の鰓蓋、SL、体形スケール、体色タイプ・シード・赤の被覆率、色相、鰭の赤の範囲、虹彩色 |

リグテクスチャ：RGBA32F、幅 = 2·24 + 241·2 + 4 = 534 texel、高さ = 最大尾数（48）。1 フレーム 1 回の `texSubImage` で全個体を更新。

### 3.1 鰭の物理（FishRig）
位置ベース動力学（PBD）、1 フレーム 2 サブステップ × 2 反復：
1. 速度に重力（鰭はわずかに重い → 静止時に長い尾が垂れる）と**異方性の流体抵抗**（膜法線方向は 2 次抵抗、接線方向は線形減衰）。水流（フィルターの流れ・フルーム）との相対速度で計算。
2. 各節の拘束：伸びない鰭条（距離拘束）＋曲げ剛性（基部 0.97 → 先端 0.2–0.42、先頭鰭条は ×1.25）＋能動的な基準姿勢への弱い復元（筋肉による鰭の起立・展開・漕ぎ）。
3. 隣接チェーン間の膜拘束（0.72–1.12 倍の範囲に保つ）。
結果として尾鰭の先端は尾柄から遅れて追従し、旋回時には外に振られ、C スタートでは大きく畳まれ、静止時には垂れる（キーフレームなし）。

## 4. シェーダ

three.js の `MeshPhysicalMaterial` に `onBeforeCompile` で注入（標準の PBR ライト・影・PMREM 環境・薄膜干渉・clearcoat をそのまま利用）。

### 4.1 頂点
- 胴：モーフ（口・鰓蓋）→ 体形スケール（法線は逆転置）→ 背骨曲線に沿った変形。
- 鰭：チェーン格子の双 Catmull-Rom で位置、法線は双線形、厚み分を法線方向へ。
- 影：同じ変形を注入した `MeshDepthMaterial`（鰭は hashed alpha で半透明の影）。

### 4.2 胴フラグメント
- **鱗**：互い違いの格子で「前方の鱗が上」、同じ列では「背側の鱗が腹側の鱗の上」の重なり規則により可視鱗を決定（境界がすべて丸い自由縁になり、ボロノイ状の六角形にならない）。鱗ごとに、ごく弱いドーム（鱗は薄い平板）・自由縁への持ち上がり・縁のロールオフ・同心円の隆起線・放射溝・側線孔の高さ勾配から法線を生成。鱗ごとの向きの揺らぎ（グリント）、反射率・色の揺らぎ、前方鱗の縁が落とす細い影。画面上の鱗サイズ（`fwidth`）に応じて詳細をフェード（エイリアシング防止）、LOD2 では計算自体を省略。
- **模様**：個体シードの 3D ノイズ（背側・頭部・尾柄にバイアス）。境界は鱗中心での評価と 70 % 混合 → **赤斑の縁が鱗に沿ってギザギザ**になる。
- **材質**：色素のアルベド、色素色で着色したグアニン鏡面（白部は銀白・強め）、白部に薄膜干渉（白い鱗は膜厚を揃えて真珠状に。色素のある鱗は膜厚のばらつきが大きく金・緑・紫のきらめき）、白い鱗は起伏と傾きのばらつきを抑える、腹側は銀色、頭部は鱗無しの皮膚（微細凹凸と斑）、鰓蓋に金色の光沢、唇、口腔（奥ほど暗い）、鰓孔（開いた時だけ暗赤）、眼窩縁、腹の黄色素。
- **光**：コースティクス（直接光）、体内の光輸送（4.2.1）、AO、水中の減衰と散乱。

#### 4.2.1 体の透明感（体内の光輸送）

金魚の体は「散乱の強い半透明の組織（筋肉・血液）を、色素細胞と虹色素胞（グアニン）の薄い層が包んだもの」として扱う。赤は組織内を遠くまで届き、青・緑は血液に吸収される。

| 項 | 内容 |
|---|---|
| 厚み | 頂点属性 `aSect`（その断面の中心高さ・半幅・半高）で胴を局所的な楕円柱とみなし、画素ごとに**光線が体内を通る距離（弦長）**を解析的に求める。方向は背骨の姿勢を戻した静止座標系（個体の体高・体幅の倍率も補正）で扱う |
| 消散係数 | σ = (0.2, 0.62, 0.95) /mm（RGB）× 1/透明度。尾柄（幅 ≈ 5 mm）は赤が約 35 % 透過、胴の中央（≈ 20 mm）はほぼ不透過 |
| 近距離の拡散 | チャンネルごとのラップ照明（赤が最も明暗境界の奥まで回り込む）。影は皮膚の少し内側で、ぼかした影マップから取る |
| キーライトの透過 | 光の方向の弦長で減衰させ、光が入る側の表面で影マップを引く（入射点が岩や他の魚の影にあれば透過しない）。等方＋前方散乱の位相関数。光と反対側を向いた面だけに加える |
| 背景光の透過 | 視線方向の弦長（最小値は局所厚みで制限）で、魚の背後の環境（PMREM プローブ＋半球光）の光を透過させる。薄い縁・尾柄・鰭の付け根が背景光で淡く光る |
| 組織の色 | 内部はピンクがかった肉色、鰓蓋の下は鰓の赤、腹はやや淡い。出ていく光は色素層を通るので、赤い部分は赤く、白い部分（虹色素胞が多い）は弱く淡いピンク |
| 表面の色 | 白い部分に肉色のにじみ（薄い部位ほど、正面から見るほど強い）、鰓蓋の赤み（鰓の血色）、喉・腹の暖色 |

デバッグ表示「thickness (transmittance)」で視線方向の透過率を確認できる。GUI：`body translucency`、`subsurface (diffusion)`。

### 4.3 鰭フラグメント
分岐（1→2→4）し節のある鰭条、プリーツ状の膜（鰭条が稜、膜がたるむ：画面微分から接空間を作り法線を傾ける）、基部と鰭条沿いに濃い赤、膜 α と鰭条 α の差、縁の微細な鋸歯とほつれ、背面からの拡散透過＋前方散乱＋**膜内の散乱**（光が膜面をかすめても乳白に光る）、斜めから見た時の不透明度上昇。膜は 1 層あたり α 0.15（白）〜0.46（赤）で、鰭条に沿った濃淡のむらがあり、先端ほど透明になる。プリマルチプライドアルファで鏡面反射は被覆率に依存させない。鰭の描画後に同じインスタンスを**深度だけ**書き込み、被写界深度が鰭越しの背景ではなく鰭に合焦するようにしている。

### 4.4 水中の光（共有）
- コースティクス：512² のタイル状パターンを毎フレーム描画（ミップマップ）。各マテリアルは光の方向に沿って水面まで投影してサンプリング、深さでミップを上げてぼかし、RGB を少しずらして分散。
- 減衰：カメラから各画素までの**水中での経路長**をレイ–AABB で求め、波長依存の消散（赤が最も吸収される）と内部散乱色を適用。
- 光条：コースティクス場を光の方向に積分する 4 層の加算スラブ。
- 水面：下から見ると全反射（臨界角 48.6°、半解像度の平面反射パスを oblique near plane で水面下のみ）、スネルの窓内に LED の帯。上から見ると IOR 1.333 のスクリーン空間屈折（three の transmission）。どちらも同じ波高場（常時の小波＋餌・水面採餌の波紋リング）。

## 5. アニメーション（Locomotion）

| 要素 | 実装 |
|---|---|
| 体波 | h(s,t) = A·env(s)·sin(2πs/λ − φ)、env は Videler–Hess 包絡線、角度勾配 atan(∂h/∂s) を体節の向きとして積分（体長一定） |
| 周波数・振幅 | 推力指令速度から Bainbridge 式で f、f から A。加速中は指令をオーバードライブ（振幅・周波数増）。位相は積分するので周期の途切れがない |
| バースト＆コースト | 1–3 拍のバーストと滑空（滑空中は振幅 12 %、速度は τ 1.6 s で減衰） |
| 旋回 | 重心より後ろの体節は `(s − s_c)·L/U` 秒前の頭の方位を追従、前方は角速度に比例して先行。旋回率上限は速度に応じて 115–300 °/s、角加速度制限 |
| C スタート | 潜時 6–10 ms → Stage 1（22–30 ms、一定曲率の C 字、回頭の 55 %）→ Stage 2（反転、推力で最大 14 BL/s）→ バースト遊泳 0.45–0.95 s |
| 制動 | 胸鰭を流れに直交させ、腹鰭・尾鰭を広げ、τ 0.28 s で減速 |
| 胸鰭 | ホバリング時 1.4–2.3 Hz の漕ぎ（左右逆位相に弱く結合、周波数ゆらぎ）、速度に応じて体側へ畳む、旋回時は内側の鰭を支点に広げる、制動姿勢 |
| 背鰭・臀鰭・尾鰭 | 起立度・展開度を速度・恐怖・制動に応じて変化（恐怖で畳む） |
| 呼吸 | 1.15–1.6 Hz（個体差）、運動後に速く深く、口が鰓蓋に先行、左右の鰓蓋にわずかな非対称、1–3 分ごとの咳 |
| 口 | strike（吸引）、peck（底砂）、gulp（水面）、spit（吐き出し＋砂粒の飛散）、chew（咽頭での選別の小刻みな動き） |
| 眼 | 左右独立の水平サッカード（1–4 s ごと、±17°、60 % 相関）、餌を見る時は輻輳 |
| 微小運動 | 姿勢のゆらぎ・方位のゆらぎ・ホバリング時のドリフトはすべて個体固有シードの fbm で、同期しない |

## 6. AI アーキテクチャ

```
刺激（ガラスタップ／頭上の影／近傍個体の驚愕）──割込み──▶ Startle（C スタート）→ Flee → Freeze
                                                           
欲求（空腹・疲労・恐怖・社会性・好奇心）+ 性格 + 近傍の状況
        │ 0.5–1.1 s ごと（個体ごとにずらす）
        ▼
ユーティリティ評価 ─ softmax(T=0.1) ＋ 現状態 +0.15 のヒステリシス ＋ 状態ごとの最小滞在時間
        ▼
状態：rest / wander(+pause) / cruise / pause / forage / approachFood / surfaceFeed / shoal / wallFollow / startle / freeze
        ▼ 目標速度ベクトル
ステアリング：視覚の先読み回避（SDF：壁・床・水面・岩・水草）、側線の近距離反発、分離（予測衝突含む）、
             群れ（ゆるい結束＋弱い整列）→ 方向のみ変更し、危険度に応じて減速（推力は加えない）
        ▼
運動層（Locomotion）→ リグ → 位置の安全クランプ＋個体間の柔らかい非貫通
```

- 探索目標は新規性（8×3×3 セルの最終訪問時刻）、好みの水深、壁への引き寄せ（thigmotaxis × 恐怖）、側性でスコアリング。
- 採餌：視覚（前方 ~300°、0.55 m）と嗅覚（底の餌 0.16 m）で検出。沈下する餌は先読み。底では頭を下げてついばみ、選り分け、55 % で吐き出す。水面の餌は下から近づいて頭を上げて吸い込む（波紋）。
- 群れ：Boids は群れ状態と分離だけに使い、それ以外は状態機械＋ユーティリティ＋環境刺激で決定。

### 4.5 レンズ・カメラ

- **ポストプロセス**：MSAA 4× の HDR シーン（深度テクスチャを解決）→ **被写界深度** → ブルーム → **レンズ**（倍率色収差・周辺減光・フィルムグレイン）→ Neutral トーンマップ。
- **被写界深度**：薄肉レンズ。画角から 35 mm 判換算の焦点距離 f を求め、無限遠の錯乱円 c = f²/(N(z_f − f))、各画素は c·|1 − z_f/z|。黄金角スパイラルの 1 パス収集（最大 72 サンプル、最大ぼけは画面高の 1.1 %）で、焦点面より奥の画素が手前ににじまないよう制限。
- **オートフォーカス**：シネマは被写体の眼、追従は選択個体、軌道カメラは画面中央付近の魚（いなければ注視点）。焦点距離はなめらかに追従（ピント送り）。
- **シネマカメラ**（`CinematicCamera.js`）：被写体（活発で壁・底から離れた個体、直前の被写体は避ける）とショット（側面、斜め前からの頭部の寄り、水面を背にしたローアングル、尾の追従、並走、水面越しの真上、前面ガラス沿いのワイド）を選び、6–11 秒ごとにカット。魚の速度でカメラを動かし、ばねは構図の補正だけにする（遅れない）。向きは強く平滑化して頭部の左右振れを除き、旋回はゆっくりしたカメラの弧になる。わずかな手持ちの揺れを加え、水中から出ないように制限。縦長画面では引きを大きくする。画面に触れる、ドラッグ、ホイールで自由視点に移る。`V` キーで戻る。
- **自動画質**（`AdaptiveQuality.js`）：実フレーム間隔を 2 秒ごとに平均し、24 ms 超で 1 段下げ、17.5 ms 未満が 3 回続けば 1 段上げる（一度失敗した段には戻らない）。段は解像度倍率（2.0→0.6）、MSAA（4/2/0）、被写界深度、水面反射、ブルーム、レンズ。スマートフォンは 'low' から始める。

## 7. LOD・最適化

- **インスタンス描画**：LOD ごとに胴 1・鰭 1・眼 1 のドローコール。尾数を増やしてもドローコールは一定。
- **GPU スキニング**：背骨曲線と鰭チェーンを DataTexture から頂点シェーダで評価。
- **CPU カリング**：個体ごとの境界球で視錐台判定し、見える個体だけをインスタンスリストへ。鰭は半透明のため個体単位で奥→手前にソート。
- **テクスチャ圧縮 / KTX2 / Draco / Meshopt**：本プロジェクトは外部のメッシュ・テクスチャを持たないため適用対象がない（配信サイズ ≈ JS のみ）。外部アセット化する場合の方針は README に記載。
- 反射パスは半解像度・レイヤー 1 のみ（底砂のインスタンスは除外）。影は 2048² の PCF。
