# Morphology & 3D Specification — シロチドリ

根拠 ID（S1…）は `research.md` を参照。各数値は `src/birds/kentishPlover/KentishPloverConfig.js` に同じ名前で入っている。

## 0. 座標系

- 単位 **メートル（実寸）**。鳥ローカル座標は +Z = 前（嘴方向）、+Y = 上、+X = 鳥の左。
- 原点 = 立位で両足の間の地面。
- バインドポーズ = 「落ち着いた立位（relaxed stand）」。翼のみ展開状態でバインドし、畳んだ状態は骨の回転で作る（羽の配置をオーサリングしやすいため）。

## 2. 骨格（Rig）

鳥の骨格に従う（人型リグの流用なし）。括弧内はバインド位置（鳥ローカル, mm）。

```
root (0,0,0)                       … 地面上の移動基準
└ body  = pelvis/synsacrum (0,56,-12)
   ├ chest  = thoracic spine (0,58,15)
   │  ├ neck0 (0,64,30) ─ neck1 (0,70,36) ─ neck2 (0,75,40)
   │  │   └ head (0,74,40)  … 後頭顆付近
   │  │       ├ jaw (0,77.5,58)      下嘴の関節
   │  │       ├ eyeL/eyeR            眼球（視線の微小回転）
   │  │       └ lidL/lidR            下瞼（閉眼）
   │  └ shoulderL/R (±12,64,22)     肩（肩甲帯）
   │      └ humerus ─ forearm(ulna/radius) ─ hand(carpometacarpus)
   │           │           │                ├ alula
   │           │           │                └ p1…p10  初列風切（各1骨）
   │           │           └ s1…s11  次列風切（各1骨）
   │           └ t1…t3  三列風切
   ├ tail (0,60,-45)  … 尾端骨（pygostyle）
   │  └ r1L…r6L, r1R…r6R  尾羽12枚（各1骨）
   └ femurL/R (±10,52,-6)          大腿（羽毛内）
      └ tibiotarsus (±13,44,10)    膝から下
         └ tarsometatarsus (±12,28,-16)  足根間関節＝外見上の「踵」
            └ foot (±10,3,-8)
               ├ toeInner  (2 節)
               ├ toeMid    (3 節)
               └ toeOuter  (2 節)
```

- 羽毛1枚ごとに骨を持つのは初列・次列・三列・尾羽のみ（展開/折り畳み時に1枚ずつ回転が必要なため）。雨覆は腕の骨にブレンドスキニング。
- 総骨数 ≈ 100。Three.js は骨行列をテクスチャで渡すため上限の問題はない。遠距離 LOD では骨数を減らしたリグを使う（`optimization.md`）。

## 3. メッシュ構成（部位ごとの方針）

| 部位 | 手法 | 理由 |
|---|---|---|
| 頭・首・胴・腰・下尾筒 | **SDF（楕円体・カプセルの smooth-union）で彫刻 → Surface Nets でポリゴン化**、SDF勾配で法線。LOD ごとに解像度を変える（LOD0 0.9 mm ボクセル） | 球・円柱の寄せ集めではなく、胸の張り、急な額、後頸の窪み、腰のすぼまりを1枚の連続曲面として作れる |
| 羽毛表現（胴体） | 羽域ごとの羽毛方向場に沿った **手続き的 normal/roughness/color**（シェーダ）。胸腹は短く柔らかい鱗状、背は大きく重なり明瞭、頭は細かい | テクスチャ解像度に依存せず近接でも破綻しない。ノイズは羽縁の重なりに従う低周波のみ |
| 肩羽・雨覆・三列/次列/初列風切・小翼羽・尾羽 | **実ジオメトリの羽**（羽軸＋非対称羽弁、反り、先端形状を頂点で定義）。不透明なので alpha overdraw なし | 重なりの階層が見えることが品質の決め手 |
| 嘴 | 上嘴・下嘴を別ロフト。断面を位置ごとに変える（基部: 丸みのある三角、中央: くびれ、先端 1/3: dertrum の膨らみ、鈎状でない尖端）。鼻孔溝をジオメトリで刻む | 単純な円錐の禁止 |
| 脚 | 骨チェーンに沿うロフト。脛の羽毛部（腿羽）→裸出脛→足根間関節の膨らみ→左右に扁平な跗蹠（網目状鱗をシェーダ）→足 | 棒状 Cylinder の禁止 |
| 趾 | 節ごとの肉趾の膨らみ、爪（湾曲した円錐状、下面が凹） | 体重を受けて平らに接地 |
| 眼 | 眼球（虹彩・瞳孔をシェーダ）＋角膜（高 specular の透明キャップ）＋瞼縁リング＋下瞼（閉眼）＋瞬膜（前方から後方へ掃く半透明膜） | 「黒い球」の禁止 |

## 5. シルエットを保つためのルール

1. 胴の最大幅は胸の後方（z ≈ +5 mm）。そこから腰に向かって急にすぼまり、尾は細く突き出る。
2. 首は立位で羽毛に埋もれて見えない。後頸の白い襟は首ではなく「頭と背の境界」に見える。
3. 額は急で丸く、嘴基部との間に段差がある（チドリ類の特徴。シギのような滑らかな楔形にしない）。
4. 脚は裸出脛から下が細く、足根間関節だけがわずかに太い。
5. 翼を畳んだとき、肩羽と三列が背の後半を覆い、初列の先端は尾端付近。
