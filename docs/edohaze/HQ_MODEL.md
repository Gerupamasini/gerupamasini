# エドハゼ（*Gymnogobius macrognathos*）成魚 — 高品質モデル

マハゼ幼魚と同じ手続き生成パイプライン（`tools/build-model.mjs`）で作った、全長 約45 mm のエドハゼ成魚の写実モデルです。
形状・色素・ひれ・眼・口と鰓の内部・リグ・アニメーションはすべてコードから生成しています。写真は寸法と色の照合にだけ使い、モデルには一切貼っていません。

- 完成モデル: `models/edohaze.glb`（約 20 MB。単位 m、+Y 背側、+Z 吻端方向）
- 表示: `npm run serve` のあと `http://localhost:8080/?species=edohaze`
- 再生成: `npm run build:edohaze`（約2分。`--fast` で約35秒のプレビュー品質）
- 種ごとの定義: `tools/edohaze/{species,anatomy,body,fins,eye,interior,rig}.mjs`。写真の計測値は `tools/edohaze/targets.json`
- 輪郭の照合: `node tools/fitcheck.mjs --species edohaze`（モデルの SDF から側面・背面の輪郭を取り出し、写真の中央値と比べます）

## 1. 写真計測（70枚）

ユーザー提供の写真 70 枚を1枚ずつ記録しました（向き、生体か標本か、抱卵の有無、使用可否）。そのうち、体がまっすぐな生体・鮮魚の 35 記録（側面 31、背面 4）から寸法を取っています。

- **軸**: 吻端（上顎先端）から尾びれ基部中央（下尾骨）までを 1 SL とし、高さ h はこの軸からの距離です。
- **集計**: 品質で重み付けした中央値と四分位範囲（IQR）。抱卵雌 9 個体は腹部の値を別に集計しました。
- **検証**: 合意値の主要 14 項目は、3 人の独立した検証役がそれぞれ別の写真群で測り直しました。どの項目も 10% 以内で一致しています（眼の高さだけは、さらに低い +0.031 を推す意見がありました）。

## 2. 形態

- **体形**: 細長く、前半は円筒形、後半は側扁します。体高は項部から第2背びれまでほぼ一定で、長い尾柄へ細くなります。モデルは非抱卵個体の中央値に合わせています。抱卵雌は s 0.30〜0.65 の腹部が膨らみ、体高 0.178、背面の半幅 約0.10 になります。
- **頭部**: 大きく、縦扁しています。頭幅（0.157）は眼の位置の頭高（0.127）より大きく、鰓蓋の後縁で幅が一段狭くなります。吻は短く丸みがあり、口は大きな端位で、やや斜め（25〜30°）です。唇は厚く、上下の顎先はほぼ同じ位置にあります。
- **眼**: 背側寄りで、左右が接近しています。眼の上縁は背側の輪郭から 約0.01 SL 下にあります。瞳孔は横・上・やや前を向きます。
- **下顎のひげ（チクゼンハゼの特徴）**: 付けていません。腹側からの描画でも確認しています。
- **鰭条数**（文献値の範囲内）: 第1背びれ VII、第2背びれ I,12、しりびれ I,10、胸びれ 19、腹びれ I,5 が左右で癒合した吸盤、尾びれは主鰭条 17。

## 3. 色と斑紋（写真の合意記載に基づく）

- **地色**: 淡い麦わら色〜オリーブがかったベージュで、腹側は白色です（24 記録の白色補正後の中央値）。
- **黒色素胞**: 微細な点状の黒色素胞が、吻、頬、頭頂、背、体側の上2/3に密に散ります。体側中央線を境に急に少なくなり、腹は白く残ります。
- **背**: 鱗のふちに沿った暗色の網目があります（背面写真 025/029/043/065）。項部から s≈0.6 までが最も濃く、正中線の両脇に鎖状の列になることもあります。眼のすぐ後ろには暗い項部斑があります。
- **背縁の白点列**: 背縁に沿って白い虹色素胞の小点が 6〜10 個並び、暗い点の集まりと交互になって、背縁が数珠玉状に見えます。
- **体側中央**: 淡い暗色斑が 11 個並びます（s 0.31〜0.9、間隔 0.06 SL 前後）。後半の水平隔膜に沿って細い暗色線が 1〜2 本あり、線上に短い点線状の暗斑が乗ります。尾びれ基部には暗色斑があります。
- **頭部**: 頬と鰓蓋に暗色点があります。斑紋は次のとおりです。
  - 眼の前下方の斜めの暗斑
  - 眼から上唇への点列
  - 眼の後ろから前鰓蓋に沿う暗色条
  - 鰓蓋の上の黄緑〜青緑の虹色光沢（ただし色素テクスチャでは銀白の虹色素胞として入れており、色味はビューアのシェーダーで出ます）
  - 鰓蓋越しに透けるピンクの鰓
- **眼**: 瞳孔は黒く、青緑の反射（タペタム）を伴います。瞳孔のまわりに細い銀白の輪があり、下側で三日月状に幅広くなります。外側の虹彩は銅褐色〜ブロンズで、金色と暗色の細点が入ります。眼のまわりは暗褐色の輪で囲まれます。
- **ひれ**: どのひれも透明です。
  - 第1背びれ: 棘に 2〜4 列の暗色点があります。多くの個体で、最後の2〜3本の棘の間、基部側の膜に濃い黒斑があります。
  - 第2背びれ: 鰭条上に 3〜6 列の暗色点が並び、先端の1/4は無斑です。
  - 尾びれ: 基部の 60〜75% に弧状の縦列で暗色点が並び、細かい市松模様に見えます。後縁は透明です。
  - しりびれ: 先端寄りがやや暗くなります。
  - 胸びれ: ほぼ無斑です。
  - 腹びれ: 白っぽい黄色です。
- **半透明**: 背側は色素でやや不透明、腹側と体の後半は半透明です。ビューアのシェーダーでは、内臓塊（白い腹膜、s 0.30〜0.65）、その上の暗い腹膜、脊柱、鰓の血色を、エドハゼの体の寸法に合わせて配置しています（`species.mjs` の `shaderAnatomy`）。

個体差と季節変化（このモデルには入れていないもの）: 婚姻色（033 の黒い背びれ、061〜063 の黄緑の横帯）、抱卵雌の腹の膨らみ、黄色い体色の個体、眼の外周の虹彩が緑に光る個体。

## 4. リグとアニメーション

- **関節**: 24 個。脊椎7節＋尾、頭、左右の下顎、左右の懸垂骨、前上顎骨、舌骨、左右の鰓蓋、眼、各ひれ。
- **ひれのモーフ**: 畳む、しなる、波打つ。
- **クリップ**: `Idle`（呼吸と胸びれのスカーリング）、`Swim`（9 Hz）、`Yawn`。`Yawn` の開始時のひれの畳み具合を `Idle` と同じ値にしたので、クロスフェードしてもしりびれが跳ねません。
- **眼のサッカード**: 回転軸を眼自身の座標系（視軸に直交する上向き軸と前後軸）に取っています。エドハゼの眼は上外方を向いているため、物体座標の X/Y 軸で回すと、視線が動かずに虹彩が視軸まわりにねじれるだけになるからです。
- **行動**: 着底、警戒、ダッシュ、位置直し、あくび。距離・速度・尾の打ち数は、全長に比例してマハゼの値から換算しています（`pose.js` の `configureBody`）。

## 5. 未確定の点

- 眼の中心の高さは +0.031〜+0.045 の幅で個体差があります。モデルは中央値（+0.037）付近に合わせています。
- 第1背びれの棘数は文献で VI〜VII です（056 は VI）。モデルは VII です。
- 種名の由来である雄の長い顎は、写真では確認できませんでした。モデルの上顎は、眼の中央の下（0.10 SL）までです。
- 下顎のひげは写真の解像度では確認できません。種の特徴（ひげがない）に従っています。
- 背面の計測は 4 個体だけ（うち1個体は抱卵雌）なので、幅の値は側面の値より不確かです。
