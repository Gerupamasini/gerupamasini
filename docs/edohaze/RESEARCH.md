## 2. 本種で確認された形態 [確認]

- 成魚全長 4〜6 cm（体長5 cm前後）。Fishbase最大15.7 cm は記録値として扱い、ゲームでは使わない。
- 鰭式: D VII–I,12 / A I,10 / 脊椎骨 35。→ **第1背鰭 7棘、第2背鰭 1棘12軟条、臀鰭 1棘10軟条**をモデルの鰭条数に採用。
- 体は **細長く寸胴**。**頭部断面は円形に近い**（ハゼとして強い縦扁ではない）。
- **顎が大きい**（種小名 *macrognathos* = 大きな顎）。
- **第2背鰭・臀鰭が通常のハゼより後方**に位置する。
- **目立った模様がない / 体側斑紋は不明瞭**。
- **尾鰭の点列が下方まで達しない**。
- **チクゼンハゼとの識別: 下顎腹面にヒゲ状突起（皮弁）がない**。
- チクゼンハゼに見られる **体側中央の黒い横帯を欠く**。

## 4. 色彩（推定を多く含む）

- [確認] 目立った模様なし・体側斑紋は不明瞭・中央黒色横帯なし・尾鰭点列は下方まで達しない。
- [近縁推定] 生時は淡い灰褐〜黄褐色で半透明感があり、背側に細かい黒色素胞の網目、体側中央に不明瞭な暗色斑列、
  腹面は白っぽい。頭部は鱗がなく感覚乳頭列がある（*Gymnogobius* は頭部無鱗）。
- [近縁推定] 背鰭・尾鰭には鰭条上に小暗点が並ぶ（→尾鰭では上半分〜中央に限定：[確認]に整合）。
- 固定標本は褪色し黄土色〜白っぽくなるため、標本写真の色を生体色に使わない。
- 繁殖期の雄の婚姻色（第1背鰭の黒化等）は本種で確認できていない → 実装は弱い差（雄の頭部・顎がやや大きい）だけに留める [ゲーム補完]。

## 5. 生態・行動

### 5.1 本種で確認
- 汽水の河口干潟・前浜干潟の **砂泥底** に生息する底生魚。自然度の高い干潟に残存（環境省RL 絶滅危惧II類）。
- **ニホンスナモグリ・アナジャコ等の甲殻類の巣穴（生息孔）を生息場・産卵場として利用**。
- 低潮時に巣穴を掘って（アナジャコ *Upogebia major* と一緒に）採集される／吸引ポンプで巣穴から直接採集。
  → **干出時は巣穴内に留まる**。
- **春（3〜5月）に巣穴内に産卵し、雄が卵を保護**。産卵巣はスナモグリ類の巣穴構造（樹脂注型で確認）。
- 食性: 初夏〜秋に **小型甲殻類・ゴカイ類** を食べて成長（東京湾 葛西人工渚）。

### 5.2 近縁種・一般ハゼ類からの推定 [近縁推定]
- 巣穴共生性ハゼ類は、水が被っている間に巣穴を **数秒〜10秒以上の単位で出入り** する（実験で20個体中19個体）。
- 巣穴を隠れ家として使い、危険時は巣穴に逃げ込む（*Eutaeniichthys gilli*, *Mugilogobius abei* 等）。
- 底生ハゼは腹鰭吸盤と胸鰭で底に「着底（perch）」し、**短い突進→滑走→着底を繰り返す間欠的移動（saltatory）** をとる。
- ハゼの胸鰭は強い内転筋をもつ抗力型推進に適応しており、微速移動・姿勢保持・制動に多用される。
- 驚愕反応は硬骨魚一般の **C-start（マウスナー細胞駆動、潜時 ~10ms, C屈曲 ~20–40ms）** → 短距離バースト。
- 摂餌は吸引摂食（ハゼ類）で、底面上の餌への短い突進と顎の急速開閉。

### 5.3 資料なし → ゲーム補完または削除
- **MUD_DIVE（砂泥への潜り込み）: 本種の記録なし → 削除**。代替として「着底してフリーズ（体色と底質による隠蔽）」を採用。
- **中層への浮上 / 自由遊泳: 記録なし**。底生性から、**底面上 1〜2 体長以内の短い浮遊（HOVER）** のみに限定 [ゲーム補完]。
- 昼夜差: 資料なし → 夜間は活動をわずかに下げるのみ [ゲーム補完]。
- 巣穴への進入姿勢: 頭から進入・内部で反転し頭を出して外を窺う、は一般的なハゼ類の観察に基づく [近縁推定]。
- 潮位: 干出（水深が体高の数倍未満）で巣穴退避 [確認に基づく推定]。満潮時の上げ潮で活動増加 [ゲーム補完]。
