# 漫湖マップ

「干潟へ行く！」の日本マップで沖縄を選び、漫湖へ入場する。地域ボタンはタッチ画面でも利用できる。東京湾の既存マップも引き続き選べる。

300 m × 300 m、601 × 601（50 cm格子）の地形。動ける範囲は中央の200 m × 200 m。周囲の景観は地形の外側に1.6 kmまで続く。ユーザー提示の航空写真・現地写真を参考にしたゲーム用の構成で、現地を測量した再現ではない。**海ではなく湖**：水平線はなく、どの方向もマングローブ林か湖の対岸で閉じる。湖は国場川の広がった所という設定で、川は湖の南北の両端から先へ、幅約180 mまで細りながら蛇行して地平まで続く（閉じた池に見えない）。

- 泥の質感：湖の静かな泥干潟なので風紋（漣痕）は無し（`ripples: 0`）。干潟のマハゼ・エドハゼのシーン（MahazeViewer の泥）に合わせ、淡いまだら（数cm〜数十m）、泥のこぶの細かな起伏、少ない砂粒、群れて落ちた糞粒、巣穴の開口、オリーブ色の珪藻の膜、濡れた泥のつや（`mudLook: 1`）。干出した泥の窪みには薄い水膜が残り、湖の映り込み（空・雲・林・街）をそのまま映す鏡になる（水の鏡像テクスチャを共有。鏡像の無い低画質では空のキューブ）。水膜の縁と水際には濡れた暗い縁取り、水面下の泥はつやを消す。高潮線より上で乾いた泥（入口の岸）は、30〜60 cmの不規則な板に乾燥ひび割れし、小さなひびが一部の板を割る。
- 盆地：いくつもの入り江が連なる泥干潟（歩行範囲の開けた部分の大半が泥）。澪筋と支流、林縁に沿った実生の群れ、マングローブの島。
- 東：盆地の東側がそのまま湖に開く。干潟は湖へ向かって約60 mかけてゆるやかに（約1%）下がり、岸の近くだけ少しきつい斜面（最大5〜6%）で湖底へ下りる。歩行範囲の東の一辺は水深で進めなくなる（他マップと同じ）。澪筋・支流も同様に、幅約12 mのゆるい窪みの中で、流路の手前数mだけ斜面がきつくなる。澪筋は西の林から湖まで、支流は南の林から合流点まで、川床が下流へ向かって途切れずに下がり、干潮でも細い流れが林から湖までつながる（潮だまりと同じく地形の等高線で水際が決まる）。澪筋の河口はマングローブの岬を抜けて湖へ開く。
- 入口：東岸の小高い泥混じりの砂の岸。左にマングローブ、右に湖という写真の構図。干潟の中には岩を置かない。
- 背景の林の縁：湖の両岸・対岸など、樹木モデルの外側で林が水や泥に接する所には、樹木モデルを8方向から焼き込んだビルボード（インポスター）を3列ほど並べる（約2,200本、1本2三角形、1描画）。樹冠の屋根はその列の奥から立ち上がる。
- 林：手前の数列は実際の樹木モデル（全画質）、その奥の数列は中・高画質のみ。さらに奥は、樹木と同じ葉カード・葉シェーダーで描く遠景の樹冠（インスタンス1描画）と樹冠の屋根。樹冠の屋根には、実物より少し大きく（葉長0.3〜0.4 m）デフォルメしたヒルギの葉のロゼットを3層（陰・中・日なた）に描いたテクスチャを貼り、数百mまで葉として見える。林の内部（林縁から約11 m以上）は立ち入れない。
- 対岸（約430 m）：海岸の林の帯、その奥に中層の集合住宅群（屋上の貯水タンク・塔屋、一部に赤瓦の寄棟屋根、パステル調の外壁）。
- 北の道路橋：箱桁の連続橋（張り出し床版、コンクリートの壁高欄と鋼製の手すり、伸縮継手）を約44 mごとの2本柱・張り出し梁の橋脚が支え、水際の柱脚には潮の跡。街路灯が左右交互に並ぶ。両岸とも長い取付け高架で約4%の勾配で地上へ下り、西は林の切通し、東は街並みの間へ道路が続く（途中で途切れない）。
- 南西の林の奥：赤瓦の寄棟屋根（白い漆喰の棟・下り棟、深い軒）を載せた2階建ての白い建物（漫湖水鳥・湿地センターを参考にした独自の造形）。盆地から樹冠越しに屋根が見える。
- 南国の空気：地図ごとの大気設定（`atmosphere`）で、高い太陽でも白飛びしない深い青空、白い積雲（厚い所は灰青の陰、`cloudShadeMin`・`cloudNeutral`）、強い暖色の日差し。他のマップは従来の値のまま。
- 湖の水：濁った灰緑〜くすんだ青緑（ユーザー提示の写真、`water.colour`・`scatter`、`turbidity 3.5`）。風の細かなさざ波（`ripple`：短波長の強調、遠くまで残るフィルタ、浅い所と水膜は鏡のように静か）で、岸の林や空を揺らいで映す。
- マングローブの葉色：日差しを受けた明るい黄緑（`mangroveLeafTint`）。

色：泥は写真のわずかに緑がかった中立的な灰色（`mudTint`）。濡れるとより暗い。入口の岸の砂混じりの泥も灰色寄り（`sandTint`）。

ヤエヤマヒルギは林縁に配置し、成木5樹形・幼木3サイズ・seed・LOD・根のcollisionを既存実装から利用する。低画質の遠景は板ポリ。背景建物、船、既存東京湾のランドマーク、アマモの植生、牡蠣礁、アカエイの跡、埋在貝は配置しない。`animals: false` により自然スポーン・強制スポーン・個別スポーン・生物モデルの先読みを停止する。既存マップは初期値trueで維持する。

潮汐の公式値をこの環境では取得できなかったため、`manko_demo` はゲーム環境確認用の仮潮汐。観測地点名・選択画面にも明記している。実際の漫湖の水位や那覇の潮汐予測として利用しない。今後、公式調和定数と現地の水位基準を確認して差し替えられる。

再生成: `npm run terrain:manko`。
検証: `npm run check`、`npm run build`、`node tests/smoke/manko.mjs`（Chromium、既定 `/usr/bin/chromium`）。ブラウザ検証は沖縄選択→漫湖入場を操作し、300 mの地形・周囲の景観・各画質の描画負荷、マングローブ、無生物を確認する。単体テストは澪筋・支流の連続（開けた流路、途切れない干潮の流れ、下流へ下がる水面）、湖の上下流への川の連続、満潮時に入口から切り離される泥の区画が無いことも確かめる。画像は `docs/maps/manko/` に保存する。
