# 漫湖マップ

「干潟へ行く！」の日本マップで沖縄を選び、漫湖へ入場する。地域ボタンはタッチ画面でも利用できる。東京湾の既存マップも引き続き選べる。

300 m × 300 m、601 × 601（50 cm格子）の地形。動ける範囲は中央の200 m × 200 m。周囲の景観は地形の外側に1.6 kmまで続く。ユーザー提示の航空写真・現地写真を参考にしたゲーム用の構成で、現地を測量した再現ではない。**海ではなく湖**：水平線はなく、どの方向もマングローブ林か湖の対岸で閉じる。

- 盆地：いくつもの入り江が連なる泥干潟（歩行範囲の開けた部分の大半が泥）。澪筋と支流、林縁に沿った実生の群れ、マングローブの島。
- 東：盆地の東側がそのまま湖に開く。泥が湖へ傾いて深くなり、歩行範囲の東の一辺は水深で進めなくなる（他マップと同じ）。
- 入口：東岸の石灰岩の岸（白っぽい多孔質の岩と、浅瀬の藻をまとった石）。左にマングローブ、右に湖という写真の構図。
- 林：手前の数列は実際の樹木モデル（全画質）、その奥の数列は中・高画質のみ。さらに奥は、樹木と同じ葉カード・葉シェーダーで描く遠景の樹冠（インスタンス1描画）と樹冠の屋根。林の内部（林縁から約11 m以上）は立ち入れない。
- 対岸（約430 m）：海岸の林の帯、その奥に中層の集合住宅群、北に湖を渡る道路橋。

色：泥は葛西の中立的な灰色ではなく、写真の暖かいグレージュ〜カーキ（`mudTint`）。濡れるとより暗く茶色い。水はカーキ褐色で濁りが強い（`turbidity 1.4`）。

ヤエヤマヒルギは林縁に配置し、成木5樹形・幼木3サイズ・seed・LOD・根のcollisionを既存実装から利用する。低画質の遠景は板ポリ。背景建物、船、既存東京湾のランドマーク、アマモの植生、牡蠣礁、アカエイの跡、埋在貝は配置しない。`animals: false` により自然スポーン・強制スポーン・個別スポーン・生物モデルの先読みを停止する。既存マップは初期値trueで維持する。

潮汐の公式値をこの環境では取得できなかったため、`manko_demo` はゲーム環境確認用の仮潮汐。観測地点名・選択画面にも明記している。実際の漫湖の水位や那覇の潮汐予測として利用しない。今後、公式調和定数と現地の水位基準を確認して差し替えられる。

再生成: `npm run terrain:manko`。
検証: `npm run check`、`npm run build`、`node tests/smoke/manko.mjs`（Chromium、既定 `/usr/bin/chromium`）。ブラウザ検証は沖縄選択→漫湖入場を操作し、300 mの地形・周囲の景観・各画質の描画負荷、マングローブ、無生物・無建物を確認する。画像は `docs/maps/manko/` に保存する。
