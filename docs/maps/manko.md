# 漫湖マップ

「干潟へ行く！」の日本マップで沖縄を選び、漫湖へ入場する。地域ボタンはタッチ画面でも利用できる。東京湾の既存マップも引き続き選べる。

120 m × 120 m、481 × 481（25 cm格子）の地形。動ける範囲は中央の100 m × 100 m。ユーザー提示写真（漫湖の泥干潟・林縁・石灰岩の岸）を参考にしたゲーム用の構成で、現地を測量した再現ではない。

- 北：石灰岩の礫の岸（入口、標高約1.5 m）から砂混じりの裾を経て干潟へ下りる。
- 中央：泥が主体（歩行範囲の7割以上）。こぶ・低い段・水たまりのある不均一な泥面に、ヤエヤマヒルギの実生・幼木が点在する。
- 西から東へ蛇行する主澪筋（周囲より約40–70 cm低く、河口で広がる）と、中央を流れる支流。
- 東：湖の開けた水面（x>44から深くなる）。
- 西・南：一段高い泥の上の密なマングローブ林帯。干潟中央の島状の林と、澪筋河口の小さな林。

色：泥は葛西の中立的な灰色ではなく、写真の暖かいグレージュ〜カーキ（`mudTint`）。濡れるとより暗く茶色い。水はカーキ褐色で濁りが強い（`turbidity 1.4`）。

ヤエヤマヒルギは林縁に配置し、成木5樹形・幼木3サイズ・seed・LOD・根のcollisionを既存実装から利用する。低画質の遠景は板ポリ。背景建物、船、既存東京湾のランドマーク、アマモの植生、牡蠣礁、アカエイの跡、埋在貝は配置しない。`animals: false` により自然スポーン・強制スポーン・個別スポーン・生物モデルの先読みを停止する。既存マップは初期値trueで維持する。

潮汐の公式値をこの環境では取得できなかったため、`manko_demo` はゲーム環境確認用の仮潮汐。観測地点名・選択画面にも明記している。実際の漫湖の水位や那覇の潮汐予測として利用しない。今後、公式調和定数と現地の水位基準を確認して差し替えられる。

再生成: `npm run terrain:manko`。
検証: `npm run check`、`npm run build`、`node tests/smoke/manko.mjs`（Chromium、既定 `/usr/bin/chromium`）。ブラウザ検証は沖縄選択→漫湖入場を操作し、120 mの地形、マングローブ、無生物・無建物を確認する。画像は `docs/maps/manko/` に保存する。
