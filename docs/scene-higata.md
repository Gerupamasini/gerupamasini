# 干潟のハゼ（`higata.html`）

水深 約10cm の干潟（砂泥底）に、エドハゼとマハゼが数匹いるだけのシーンです。ゲームの要素や UI はほとんどなく、ハゼが自分のペースで過ごす様子を眺めるためのページです。

```bash
npm run dev      # → http://localhost:5173/gerupamasini/higata.html
npm run build    # dist/higata.html（GitHub Pages では /gerupamasini/higata.html）
```

WebGL2 と `EXT_color_buffer_float` に対応したブラウザが必要です（デスクトップ版 Chrome / Edge / Firefox / Safari 17 以降）。

## 使っているモデルと行動

| 種 | モデル | 出典ブランチ |
|---|---|---|
| エドハゼ成魚（*Gymnogobius macrognathos*、全長 約45mm） | `src/assets/models/edohaze/edohaze.hero.glb` | `claude/awesome-ride-3rde4w`（`models/edohaze.glb`） |
| マハゼ幼魚（*Acanthogobius flavimanus*、全長 約50mm） | `src/assets/models/mahaze/mahaze_juvenile.hero.glb` | `claude/adoring-faraday-h25n7c`（`models/mahaze_juvenile.glb`、同一ファイル） |

- 描画: 2 つのブランチのシェーダー（`src/materials/`）を `src/scene-higata/materials/` に移しました。胴体の体積レイマーチ（背景の屈折透過・逆光・内臓と背骨の影）、ひれの薄膜 2 パス、眼の屈折、口と鰓の内部はそのままです。変更は、コースティクスを水面の波から計算するようにしたこと、霧を水中の経路長だけでかけるようにしたこと、個体ごとの体色（`uTint`・`uMelanin`）を足したことです。
- 姿勢: `pose.js` はブランチの姿勢モデルそのままで、種ごとの体軸（全長、関節位置、休止時のひれ）をモジュール全体ではなく個体ごとに持てるようにしました（2 種を同時に動かすため）。巣穴に出入りするときの背腹方向の曲げ（`segPitch`）を足しています。
- 行動: `Behavior.js` はブランチの行動（長い休止、胸びれでの位置直し、C 字ターンからのダッシュと滑空・着地、背びれ立て、あくび、左右別々の眼の動き、警戒姿勢）をもとに、次を加えました。
  - 起伏のある地面に、腹びれの吸盤・腹・尾びれ・あごの接地点で乗る（斜面に沿って体が傾く）
  - 行動圏を持ち、ほかのハゼや巣穴の上を避けて着地点を選ぶ
  - カメラの急な接近（見かけの大きさの増加率）で恐怖が高まり、閾値を超えると C 字の素早いスタートで逃げ、しばらく動かない。逃げたハゼの近くの個体も警戒する
  - マハゼ: 砂をついばむ（頭を下げて吸い込み、泥煙が上がる。数回かんで鰓孔から砂を出す）
  - エドハゼ: アナジャコ／スナモグリの巣穴を持ち、入口のそばで休む。驚くと頭から巣穴に飛び込み、中で向きを変え、頭だけ出して周りを見てから、出てくるか引っ込む。巣穴に近づいたハゼには、ひれを立てて大きく口を開ける威嚇をする
  - 底の小さな餌へのついばみ（吸い込み）

## 環境

- 干潟（`world/Terrain.js`）: 解析的な高さ関数。うねり、砂の多い所に出る非対称な流れ漣痕（波長 約6cm）、泥の多い所の平らな面、アナジャコの巣穴（2 つの開口、低い縁）、スナモグリの噴出丘、ゴカイの糞塊、浅いくぼみ。巣穴の開口は実際に穴になっていて、下に暗い坑道が続きます。表面は泥・砂・還元層（黒い泥）・珪藻の膜を頂点ごとに持ち、砂粒、糞粒、泥のこぶを細かい法線で描いています。
- 水面（`world/waves.js`, `world/Water.js`）: 微風の波（16 成分、表面張力を含む分散関係で進む）。下からはスネルの窓の空と、その外側の全反射に映る干潟と魚（平面反射）、上からは空の反射・太陽のきらめき・屈折した水中が見えます。
- コースティクス: 同じ波の曲率から、光の集まり方（写像のヤコビアンの逆数）を画素ごとに解析的に計算しています。水の分散で、明るい線にかすかな色のにじみが出ます。
- 泥煙と浮遊物（`world/Silt.js`）: 飛び出し・着地・ついばみ・巣穴への出入りで舞い上がる泥の粒（抵抗、沈降、渦）と、カメラのまわりを漂う細かな懸濁物。
- 貝殻片と小石（`world/Debris.js`）。
- ポストプロセス（`render/Post.js`）: マクロ撮影のような被写界深度（見ているハゼに合焦）、ブルーム、ACES、軽い色調整、周辺減光。

## 操作

| 操作 | 内容 |
|---|---|
| ドラッグ | まわりこむ |
| ホイール／ピンチ | 近づく・離れる |
| ダブルクリック | そのハゼを見る |
| F / Tab（Shift で逆順） | 次のハゼへ |
| 1 / 2 / 3 | 水中の低い視点／水面の上／接写 |
| Space | 一時停止 |
| P | 被写界深度の切替 |
| A | 自動カメラ（しばらく操作しないと、ゆっくり回りながら別のハゼを見に行く）の切替 |
| C | カメラへの警戒の切替 |

URL パラメータ: `edo=3&maha=3`（匹数、各 4 まで）、`seed=…`（干潟と配置）、`wind=0.72`（波の強さ）、`sunEl=52&sunAz=215`（太陽の高度・方位）、`exposure=1.5`、`dof=0`、`calm`（カメラを怖がらない）、`dpr=1.5`（解像度）、`cam=px,py,pz,tx,ty,tz`。

## 確認用スクリプト

```bash
npm run build
npm run scene:shot -- <出力フォルダ>    # ヘッドレス Chromium でスクリーンショット（tools/scene/shot.mjs）
npm run scene:sim -- 240               # 行動の統計（各モードの時間、巣穴の出入り、NaN、地面へのめり込み、個体の重なり）
```
