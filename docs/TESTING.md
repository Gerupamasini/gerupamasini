# 身内テスト手順（金曜版 v0.1）

## 動作環境
- PC の Chrome / Edge / Firefox / Safari 17 以降（WebGL2 必須）。スマホは未対応。
- マウスとキーボード。

## 操作
| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 走る | Shift |
| 低い視点 ⇄ 立つ（切り替え） | C または Ctrl（最初は水面近くの低い視点） |
| ズーム（望遠） | 右クリック長押し または Z（観察中も） |
| 全体図 | M（干潟で） |
| 採集（手網） | E（対象を画面中央に入れて 2.5 m 以内） |
| 観察 | F（対象を画面中央に入れる） |
| 観察の速度 | [ と ] または画面下のボタン |
| 観察中に寄る・離れる | ホイール、または + と −、画面下のボタン |
| 図鑑 | Tab |
| 自宅の水槽 | H |
| 潮時チケット | T |
| メニュー | Esc |
| デバッグモード | F3（時刻・潮位・曇りの自由設定、生物マーカー、テレポート、統計） |

画面をクリックするとマウスで視点を操作できます（ポインターロック）。Esc で解除されます。解除後は「クリックで操作開始」の案内をクリック（または Enter / Space）で再開します。ブラウザがポインターロックを拒んだときは、ドラッグで視点を回す方式に自動で切り替わります。

## 一周の流れ
1. タイトルで「はじめる」。自宅（大型水槽のホーム画面）が開くので、下のナビの「干潟へ」。
   - ホームでは生物をクリックで情報、水槽をクリックで管理パネル、右上の潮汐パネルをクリックで潮見表。
2. 左上の潮位グラフを見る。現在の現実の潮位（気象庁「東京」基準の予測）で水位が決まっています。
3. 南（海側）へ歩く。水深 35 cm を超える場所には入れません。
4. 浅い水中や潮だまりでマハゼ、エドハゼ、シラタエビを探す。干潟が露出しているときは水際でシロチドリを探す。小さな潮だまり（40 m² 未満）には小さなハゼが数匹だけ。砂地にはアカエイの食痕（直径 1 m ほどの浅い窪み）が群れて残り、潮が引いて水が溜まると、ときどき小さなハゼやエビが取り残されています（1 日・1 窪みあたり 18 %）。
5. 生物を画面中央に入れて F で観察。カメラが生物の周りを回ります。ホイールで接近。行動（ダッシュ、あくびなど）が起きると図鑑に記録されます。
6. マハゼかシラタエビに 2.5 m 以内まで近づいて E。ゲージが帯に入ったらクリック（または E）。成功すると観察ケースに入ります。
7. Tab で図鑑を確認。
8. H で自宅へ。下のナビ「水槽」で編集パネル。「生物」タブでケースの生物を「水槽に入れる」（4 匹まで）。「レイアウト」タブで底床（砂／泥／なし）と、小石・石・流木・貝殻・水草を置けます（置いたものはドラッグで移動、回転・削除はリストから。12 個まで）。水槽はドラッグで回転。水槽をクリックすると水面に波紋。「干潟へ」で戻る。
9. T で潮時チケット。日時を選んで「使う」と 30 分間その時刻の潮位と太陽が再現されます（テスト版は無制限）。
10. ブラウザを閉じて開き直し、「つづきから」で復元されることを確認。

## デバッグモード（F3）
- 時刻を任意に設定（±1h、+1日、リアルに戻す）。潮位を固定するスライダー。曇りの度合い。
- 生物マーカー（画面上の名前と距離、ミニマップの点）。
- テレポート: 浜 / 汀線 / 澪（砂州の内側の水路）/ 水路（西の澪筋）/ 潮だまり。「周囲に生物」で近くにも出現させます。
- 統計にチャンク数（地形は 25 m 四方 144 チャンクを距離で 3 段階の粗さに切り替え、遠いチャンクは解放）。
- `?debug=1` を URL に付けると最初から有効です。

## 設定
- Esc → メニューに「目の高さ」スライダー（1.1〜1.9 m）。これは C で立ったときの高さで、低い視点は 0.45 m 固定です。

## 地形（4 回目で作り替え）
- 起伏: 地図の種（`public/data/maps/kasai_west.json` の `seed`）から乱数で起伏を生成しています（大きなうねり 110 m・中くらい 38 m・細かい 11 m・砂堆の畝 21 m を歪ませて重ねる）。全体は海へ向かって下がり、その上に 20〜40 cm の高まりと窪みが乗ります。窪みは潮が引くと潮だまりになります。種を変えれば別の干潟になります（`node tools/terrain/bake-map.mjs` で焼き直し）。
- 底質: 「泥っぽさ」の連続値から砂・砂泥・泥を分けています。窪み・澪や澪筋の縁・低い場所・西側は泥寄り、高まり・砂州・斜面・浜の上部は砂寄り。境界は少し乱して自然な形にしています。
- 風紋: 砂面の漣痕は均一なテクスチャではなく、干潟全体でひと続きの「歪めた縞」の場から計算しています（海岸線に平行な縞を 3 段階のノイズで曲げる）。うねって分岐・合流しますが途切れず、チャンクの境でもつながります。風紋のない平らな砂の区画も混ざります。

## 生物の出現と水位
- 水中の生物（ハゼ・エビ）は、その時刻の水位で「体長の 15 % 以上（最低 1.5 cm）」の水深がある場所にだけ出現します。チケットやデバッグで時刻・潮位を変えると、観察中の個体以外は入れ替わり、新しい水位に合わせて出現し直します。自宅に 10 分以上いてから戻った場合も同じです。
- 潮が引いて足元の水が浅くなった個体は、近く（6 m 以内）の十分深い水へ移動します。移動先がない、12 秒たっても浅いまま、または 25 m 以上離れていて見えていない個体は（潮と一緒に去ったことにして）消えます。食痕の居残りは窪みが乾くと消えます。

## 干潟の水（葛西の渚ビューアの水面パスを移植）
- 画面空間で水面を合成: 深さに応じた屈折の揺らぎ、吸収と散乱（薄い水はほぼ透明、厚い水は緑灰色）、空の映り込み（フレネル）、太陽のきらめき、汀線の縁と泡、遠くは霞。
- 潮だまり: 潮位より上に残った窪みの水は海と切り離され、水面がほぼ静かで透明度が高く、水底が見やすい。

## 水槽の見た目（caustic-volume 参考）
- 水面は細かな波と波紋のシミュレーション（エアストーンの泡がはじけると波紋）。水面を通った照明が砂と生物に本物のコースティクス（光の網）を描き、水中にうっすら光の筋が見えます。
- 水の色は極力薄くしています。濁って見える、暗い、重い（fps が落ちる）など感じたら教えてください。

## 確認してほしいこと
- fps（右上）。30 を切る場合は Esc → 設定 → 画質を「低」にして再確認。
- 潮位の満干の時刻が、Yahoo 天気などの東京の潮汐表と合っているか（±20 分程度なら想定内。大きくずれていたら教えてください）。
- 生物が地面にめり込む、空中に浮く、水の外に出るなどの不自然な動き。
- 採集ゲージの難易度。
- 分かりにくい操作や表示。

## 既知の制限
- シロチドリは仮モデル（簡易形状）です。シラタエビは写真から起こした手続きモデル（透けた甲、脚の歩行、尾扇の逃避）に替わりましたが、実機 GPU での負荷は未確認です。重いときは教えてください。
- エドハゼは体型と模様がマハゼ系の手続きパイプラインで作られています。個体の斑紋の違いはまだありません。
- アカエイの食痕は地形格子（0.52 m）の都合で縁が滑らかで、実物より浅く見えます。
- 地形の起伏は格子 0.52 m で表現しているので、1 m 未満の段差は丸く見えます。
- ハゼの突進は直線なので、目的地は水中でも途中でごく浅い場所をかすめることがあります。
- マハゼの半透明表現（ヒーローシェーダー）は観察ロック中と水槽でのみ有効です。重い場合はメニューの画質を「低」にしても変わらないので、動作が遅いときは観察モードを短めに使ってください。
- 潮位は主要 4 分潮の暫定値で計算しています。
- 音はありません。水槽のレイアウト変更、ショップ、写真撮影は未実装。
- 初回読み込みで 10 MB 前後のモデルを取得します。
