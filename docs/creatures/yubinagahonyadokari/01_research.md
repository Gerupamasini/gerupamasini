# ユビナガホンヤドカリ *Pagurus minutus* Hess, 1865 — 調査まとめ（Phase 1–5）

旧学名 *Pagurus dubius* (Ortmann, 1892)（= *Eupagurus dubius*）でも検索した。Komai & Mishima (2003) が
Hess のレクトタイプと Ortmann のシンタイプを比較し、*P. minutus* を古参異名として再記載している。

## 0. 根拠の区分と調査の限界

本書の各項目に次のタグを付ける。

| タグ | 意味 |
|---|---|
| **[本種直接]** | *P. minutus*（または旧名 *P. dubius*）を対象とした文献・標本記載・図鑑・実写写真で確認したもの |
| **[近縁推定]** | 同属 *Pagurus* 他種や他のヤドカリ類・十脚類の知見から推定したもの（種名を併記） |
| **[ゲーム補完]** | 文献で値が見つからず、ゲーム実装のために設定した値。調整可能なパラメータとして実装 |

**調査の限界（重要）**

- このセッションのネットワーク方針により、学術系ホスト（www.jstage.jst.go.jp、zoolstud.sinica.edu.tw、www.hitohaku.jp、Springer、PMC など）への直接アクセスは拒否された（HTTP 403）。

- 実写資料は依頼者提供の 70 枚（iNaturalist Research Grade）を全数確認した。所見は `02_reference_photos.md` にまとめた。

### 1.2 混同してはいけない同所性の近縁種

モデルに入れてはいけない特徴を、種ごとに挙げる。

| 種 | 本種に入れてはいけない特徴 | 根拠 |
|---|---|---|
| ホンヤドカリ *P. filholi* | 歩脚の先が白い（白い靴下状）／鉗脚の指先が白い／眼柄が短く第 1 触角柄部を越えない／指節は長くない | [本種直接] 比較記載（図鑑） |
| ケアシホンヤドカリ *P. lanuginosus* | 鉗脚と歩脚に密な長毛／黒い斑点／赤い触角 | [本種直接] 比較記載（千葉県立中央博物館） |
| テナガホンヤドカリ *P. middendorffii* | 体表が滑らかで無毛・無棘／鉗脚と歩脚が非常に長い／北方系 | [本種直接] 比較記載（BISMaL） |
| イクビホンヤドカリ *P. proximus* | 各節に暗褐色の横帯／鉗脚掌部に長毛／まだら模様 | [本種直接] 比較記載 |

**判定基準**: 第 2・3 胸脚（歩脚）の指節が前節より長くなければ、本種ではない。

## 2. 形態（Phase 3・4）

甲長（SL、楯部の長さ）を 1 とした比で記す。

### 2.1 体サイズ

| 項目 | 採用値 | 根拠 |
|---|---|---|
| 甲長 SL | 平均 4.2 mm（SD 0.9）、範囲 2.0–7.0 mm | [本種直接] 韓国の記載で 3–6 mm（図示個体 6.1 mm）／ロシアの個体群で ♂ 1.0–7.0、♀ 1.1–4.7 mm／和歌浦のガード中の雄で 3.76 ± 0.37 mm（要確認） |

## 3. 生態（Phase 5）

### 3.1 生息環境

| 項目 | 内容 | 根拠 |
|---|---|---|
| 場所 | 内湾の砂泥干潟、河口、汽水域、アマモ場 | [本種直接] |

### 3.2 殻の利用（本種で直接確認された事実）

| 殻 | 利用頻度・記録 | 根拠 |
|---|---|---|
| ウミニナ類 *Batillaria* | 約 40%（和歌川）、ホソウミニナで 77.5%（東ほか 2013） | [本種直接] |
| イボキサゴ *Umbonium moniliferum* | 約 40%（和歌川） | [本種直接] |
| アラムシロ、イボニシ、キサゴ類、ナガニシ類 | 図鑑に記載あり | [本種直接] |

その他の知見（いずれも [本種直接]）:

- 繁殖期には雄が丸いイボキサゴ型の殻を独占し、雌の 80% 以上が塔型のウミニナ型の殻を使う（JMBA）。
- 室内実験（旧名 *P. dubius*、浅虫）では殻の種類による選択性は無かった。野外の利用は入手しやすさと耐久性で決まり、厚く丈夫な殻が残りやすく、よく使われる（J. Crust. Biol. 2021）。
- 殻をめぐる闘争がある（Koga ら、学会発表 2024）。

### 3.6 活動と環境（[ゲーム補完] を含む）

文献では「潮だまり・澪筋で活動し、露出した泥上には少ない」[本種直接] までしか確認できなかった。
そこで、活動度を次のように定義する。

```
activity = base(個体)
         × water(水深)
         × light(日照)
         × season(季節)
         × temp(干出による乾燥・高温)
```

| 因子 | 値 | 根拠 |
|---|---|---|
| water | 水深 2–40 cm で 1.0。極浅水（<1 cm）で 0.7。露出した直後で 0.45。露出して 30 分以上で 0.2 | 露出時に不活発になることは本種の観察と整合。数値は [ゲーム補完] |
| light | 昼 0.9、夜 1.0 | [ゲーム補完] 根拠なし。差を小さくした |
| season | 冬 0.6、それ以外 1.0 | [近縁推定] 冬は深所へ移動する（ロシアの本種個体群） |
| temp | 露出中の正午付近で 0.5 | [近縁推定] *Diogenes* の高温反応 |

## 4. 運動（Phase 5）

### 4.1 脚の役割と関節

| 項目 | 内容 | 根拠 |
|---|---|---|
| 歩行に使う脚 | P2・P3（歩脚）だけ。P4・P5 は殻の保持 | [近縁推定] *P. pollicarus*（Chapple 2012） |
| 鉗脚 | 支持脚として接地することがある | [近縁推定] *Coenobita* |
| 関節の構造 | 双顆関節が連続し、隣り合う関節の回転面は直交する | [近縁推定] 十脚類 |

関節の自由度（[近縁推定] *Libinia*・*P. pollicarus*）:

| 関節 | 動き | 回転面 |
|---|---|---|
| 体–底節（TC） | 前引・後引（promotion/remotion） | ほぼ鉛直軸まわりの yaw |
| 底節–基節（CB） | 挙上・下制 | pitch |
| 坐節–長節（B/IM） | 前方回転 | 水平面 |
| 長節–腕節（MC） | 屈伸 | 鉛直面 |
| 腕節–前節（CP） | 屈伸 | 水平面寄り |
| 前節–指節（PD） | 屈伸 | 鉛直面 |

### 4.2 歩容

| 項目 | 内容 | 根拠 |
|---|---|---|
| 位相の組 | P2 と P3 を対角の組で交互に動かす（L2+R3 と R2+L3） | [近縁推定] *P. pollicarus* |
| 歩行方向 | 主に前進。横歩きもできる | [近縁推定] *P. pollicarus*、系統比較 |
| 速度の変え方 | 歩幅を変える（大きい個体ほど歩幅が大きい） | [近縁推定] *Coenobita* |
| 殻の有無 | 殻があってもなくても歩行周波数と歩幅は同じ | [近縁推定] *Coenobita* |
| 殻のヨー振動 | 小型個体では P3 の一歩ごとに殻と腹部が左右へ振れる | [近縁推定] *Coenobita* |
| 殻を引きずる | 大きい殻は引きずり、砂に跡を残す | [近縁推定] *Coenobita* |
| 殻の高さ | 地面からほぼ一定。殻が重いほど低い | [近縁推定] *P. pollicarus* |
| デューティ比 | 0.62（速歩）〜0.80（ゆっくり） | 値は不明。[ゲーム補完]。歩幅主体の速度調節と整合させた |
| 歩行周波数 | 1.6–2.6 Hz | [ゲーム補完] 小型十脚類としての設定 |
| 速度 | 探索時 1.2–1.8 SL/s、移動時 2.5–3.5 SL/s、逃避時 最大 5 SL/s | [ゲーム補完] |
| 旋回 | 一歩ごとに最大 14° ずつ向きを変え、その場の回転は弱く制限する | 実測データは不明。[ゲーム補完]。非対称な殻を付けると旋回角が変わること（*Coenobita*）を参考にした |

### 4.3 触角・眼柄

| 項目 | 内容 | 根拠 |
|---|---|---|
| 第 1 触角の動き | flicking、回転、拭い、収納の 4 種 | [近縁推定] *P. alaskensis*（Snow 1973） |
| flicking の周期 | 非周期的。左右は決して同期しない | [近縁推定] *P. alaskensis*（Snow 1973） |
| 下降ストローク | 0.06–0.15 s | [近縁推定] *Coenobita* |
| 頻度 | 平常 0.2 回/s。においがあると 0.5–1.5 回/s | [近縁推定] ザリガニ |
| 第 1 触角の向き | 注意の向きを示す（視線のように振る舞う） | [近縁推定] *P. bernhardus* 2025 |
| 第 2 触角の掃引 | 速度は不明。ゆっくり探るように掃く | [ゲーム補完] |
| 眼柄の微振動 | 2–5 Hz、0.05–0.2° | [近縁推定] *Carcinus* |
| 眼柄のサッカード | 立ち上がりが速く、戻りが遅い。片側だけ引っ込めることがある | [近縁推定] *Carcinus* |

### 4.4 退避と出現

**退避**

| 項目 | 内容 | 根拠 |
|---|---|---|
| 最終姿勢 | 大鉗脚で殻口を塞ぎ、歩脚の前節・指節を左右に縦に並べる | [本種直接] 写真 |
| 引っ込める順序 | 不明 | 文献なし。[ゲーム補完] |

[ゲーム補完] として採用した順序と時間:

| 区間 | 動き |
|---|---|
| 0–80 ms | 硬直（freeze）。第 1 触角は下ろす |
| 30–200 ms | 第 2 触角を後方へ倒す。眼柄を下げる |
| 80–350 ms | 体を殻へ引き込む。歩脚は膝を曲げて縮める |
| 200–450 ms | 鉗脚を前に揃えて殻口を塞ぐ |

**出現**

| 項目 | 内容 | 根拠 |
|---|---|---|
| 隠れる時間 | 2.6–70 s（性格で 2–4 倍の差） | [近縁推定] *P. bernhardus* |
| 出てくる順序 | 触角 → 眼 → 脚 | [近縁推定・低信頼] *Coenobita* の飼育者情報 |
| 起き上がり | 歩脚の 2 対が接地した時点で、起き上がり完了とする | [近縁推定] startle assay の判定基準 |

### 4.5 殻の調査と交換

**行動の順序**（[近縁推定] Reese 1962・1963、Elwood & Stewart 1985、Elwood 2022）

1. 歩脚で殻を抱える
2. 鉗脚で外面を探る
3. 殻を回すか乗り越えて、殻口を探す
4. 鉗脚を殻口に差し込む（殻を持つ個体は大鉗脚を使う）
5. 受け入れるなら、腹部から入る

**判断に関わる要因**

| 要因 | 根拠 |
|---|---|
| 現在の殻が悪いほど、速く近づき、長く調べる | [近縁推定] *P. bernhardus* |
| 一度拒否した殻は短く調べる | [近縁推定] *P. bernhardus* |
| 迷いがあると殻口の探査が繰り返される | [近縁推定] *P. bernhardus* |
| 死んだ巻貝や同種のにおいで殻調査が強まる | [近縁推定] Gherardi & Atema 2005 |

**移り替え**

| 項目 | 内容 | 根拠 |
|---|---|---|
| 所要時間 | 腹部から入り、5 s 未満で完了する | [近縁推定] *P. longicarpus* |
| 試し入り後に元の殻へ戻る行動 | 頻度は不明 | 頻度は [ゲーム補完] |
