# ユビナガホンヤドカリ 科学的検証と自己レビュー（Phase 14–16）

実装を `01_research.md`（文献）と `02_reference_photos.md`（実写 70 枚）に照らして点検した結果をまとめる。
根拠タグは `01_research.md` と同じ（**[本種直接]** / **[近縁推定]** / **[ゲーム補完]**）。

## 0. 点検の方法

| 方法 | 内容 |
|---|---|
| 単体テスト | `tests/unit/pagurus.test.ts`（16 件）。交尾前ガード（繁殖期だけ・保持・運搬）、殻の物理、殻の面の向き、殻口の通過、隠れた腹部の収まり、指節比、IK 精度、足の滑り、歩容の位相、退避と出現、殻交換、触角の非同期性、決定性 |
| ラボの撮影 | `node tests/smoke/pagurus-lab.mjs`。`hermit-lab.html` を斜め・正面・側面・上・後ろ・マクロの各方向、歩行中、退避姿勢、5 種の殻の並び、LOD1・LOD2、デバッグ表示で撮る。腹部の収まりは URL パラメータ `hideAbd`・`fouling` を切り替えて個別に確かめた |
| ゲーム内の撮影 | `npm run smoke`。フィールド、観察モード、採集、水槽で撮る。コンソールに警告やエラーが出たら失敗にする |
| 実写との比較 | 上の画像を写真 001–070 と並べ、比率と色を目で比べた |

判定の記号:

| 記号 | 意味 |
|---|---|
| ◎ | 根拠と一致し、テストか画像で確認した |
| ○ | 概ね一致。数値の一部は原著での確認待ち（要確認）か写真からの推定 |
| △ | 根拠がなく、[ゲーム補完] の値で実装した |
| ✕ | 未実装 |

## 1. 10 項目の自己レビュー

### 1.1 楯部 — ○

### 1.9 殻の保持姿勢 — ○

| 観点 | 実物 | 実装 |
|---|---|---|
| 向き | 殻口を下に向け、殻頂を後ろへ上げる（写真） | 殻頂の仰角（種ごと 6°–52°）を決め、殻口が真下を向くまで殻軸まわりに回す（`Shell._carryFrame()`）。殻口の法線は唇の輪郭からニューウェル法で求める |
| 重さ | 殻が重いほど低く構える [近縁推定] *P. pollicarus* | 殻の質量・重心・慣性を解析形状から数値積分で求める（密度 2700 kg/m³）。殻と体の質量比が 1 から 5 へ上がるにつれ、体を最大 14 % 低く構える。慣性が大きい殻ほど揺れがゆっくりになる |
| 揺れ | P3 の一歩ごとに殻が左右へ振れる [近縁推定] *Coenobita* | ばね・ダンパに、体の加速度と重力による擬似トルクを加える。角度は柔らかく制限する |
| 接地 | 大きい殻は引きずる [近縁推定] *Coenobita* | 殻の凸包の点で接地を判定して押し戻す。殻が地面に刺さると体を少し上げる |
| 隠れた体 | 腹部は殻の螺旋に沿って右巻きにねじれる [本種直接] | 腹部ボーンを内腔の中心線に置き、断面を内腔に合わせて潰す。テストで 5 種すべての殻について、隠れた頂点のうち殻の外に出るものが 3 % 未満 |

残る課題: 殻頂の仰角と把持点は写真から目で合わせた値。

### 1.10 退避と出現 — ◎（最終姿勢）／△（順序と時間）

| 観点 | 実物 | 実装 |
|---|---|---|
| 最終姿勢 | 大鉗脚で殻口を塞ぎ、歩脚の前節・指節を左右に縦に並べる [本種直接・写真] | 同じ姿勢。体は殻口から 1.55 SL 奥まで引き込む |
| 順序 | 文献なし | 硬直 → 触角を倒す・眼柄を下げる → 体を引き込み脚を畳む → 鉗脚で殻口を塞ぐ（0–450 ms）[ゲーム補完] |
| 隠れる時間 | 2.6–70 s（性格で 2–4 倍の差）[近縁推定] *P. bernhardus* | 対数正規分布で 2.6–70 s に収める。`personalitySeed` の大胆さで中央値を変える。テストで確認 |
| 出てくる順序 | 触角 → 眼 → 脚 [近縁推定・低信頼] | 同じ順。歩脚 2 対が接地した時点で出現完了 |
| 脅威の手がかり | 視覚と化学の手がかりを両方与えても、隠れる時間は片方だけのときと同程度 [本種直接] Behav. Ecol. Sociobiol. 2023 | 視覚（迫る影）・振動・ゲームの警戒度・明示的な逃避指示を足し合わせず、最大値を一つの手がかりとして使う |

## 2. 混同種の特徴が入っていないか

| 種 | 入れてはいけない特徴 | 実装での確認 |

## 3. 性能（実測）

この環境（Node 22、V8）で 20 個体を 600 フレーム動かして測った。ブラウザのメインスレッドでも桁は同じと見込む。

| LOD | 三角形（体＋剛毛＋殻） | draw call | ボーン | 更新時間（1 個体・1 フレーム） |
|---|---|---|---|---|
| LOD0（観察・水槽） | 59,031 | 4 | 137 | 0.11 ms |
| LOD1（約 4.5 m 以内） | 15,328 | 4 | 137 | 0.09 ms |
| LOD2（遠景） | 3,608 | 3 | 137 | 0.06 ms |

体だけの三角形は 32.2k / 10.2k / 2.7k（§7 の見た目の再点検で剛毛を足した後の値）。プロジェクトの上限（hero ≤ 400k、lod1 ≤ 30k、lod2 ≤ 4k）に収まり、テストで確認している。

|---|---|---|---|---|---|
| ホソウミニナ | 38,676 / 7,722 / 1,290 | 0.075 g | 64 mm³ | 58 mm³ | 1.99 × 4.91 mm |
| イボキサゴ | 27,944 / 5,566 / 958 | 0.414 g | 203 mm³ | 203 mm³ | 5.05 × 3.53 mm |
| アラムシロ | 30,844 / 6,094 / 990 | 0.425 g | 197 mm³ | 197 mm³ | 2.99 × 5.32 mm |
| イボニシ | 25,828 / 5,038 / 810 | 0.485 g | 251 mm³ | 251 mm³ | 3.38 × 7.62 mm |
| スガイ | 23,984 / 4,730 / 798 | 0.475 g | 285 mm³ | 285 mm³ | 5.43 × 6.18 mm |

- テクスチャは 0 枚。模様はすべてシェーダで描く。

- 最悪の場合（湧く上限 36 個体がすべて LOD1）でも更新は約 3.4 ms。通常は大半が LOD2 か非表示。

## 4. ゲームへの統合で確認したこと

| 項目 | 結果 |
|---|---|
| 湧き | 潮だまり・浅場・水際に 36 個体（上限）が湧いた |
| 観察モード | 行動の記録（歩行、退避など）が図鑑に入る。最初の撮影では 2 cm の個体が画面の約 3 % にしか写らなかった。そこで、体長 4 cm 未満の動物だけ、観察開始時のカメラ距離を体長の 9 倍まで近づけた（`src/systems/Observation.ts`）。ハゼ・エビ・チドリの距離は変わらない |
| 採集・水槽 | 採集して水槽に入れられる。水槽のコースティクスのシェーダと本種のシェーダを連結して両方効く |
| エラー | スモークテストでコンソールの警告・エラーなし |
| フィールドでの見え方 | 立った目の高さ（約 1.5 m）から水深のある潮だまりを見下ろすと、水面の反射で個体がほとんど見えない。実物でも同じなので現状のままにした。見つけやすさが問題になるなら、HUD の照準表示で補う |

## 6. 見た目の再点検（実写写真との並べ比べ）

写真 001・002・018・019・021・022・050・053・054・063・064 とラボの画像を並べ、差の大きい順に直した。

| 差 | 原因と対処 |
|---|---|
| 殻がつやのある黒紫に見え、模様・彫刻・泥が出ない | **殻の外面と内面の三角形の向きが逆**で、外から内面（奥の壁の内側）が見えていた。全 5 種で巻き順を直し、面の向きを確かめるテストを足した |
| 実物の殻は泥をかぶってつやがない | 泥の膜（`silt`）を足した。縫合と彫刻の溝に溜まり、稜では薄い。殻への空の映り込みを弱めた |
| ホソウミニナの螺層が数珠のように膨らむ | 螺管の断面を超楕円（`profileN`）にして、側面の平たい螺層にした |
| 体が黄緑に見える | 色を灰色がかったオリーブ〜カーキに寄せた。逆光の透過色の緑みを除いた |
| 脚の模様が単調 | 不規則な暗褐色のまだらを脚と鉗脚に足した。白い帯と指節の白い区間はコントラストを下げた |
| 輪郭がつるりとしている | 短い剛毛を各節の全周に足した（写真では脚と鉗脚の輪郭が毛でけば立つ） |
| 脚が細い竹馬のよう | 歩脚の断面を幅 1.4 倍・高さ 1.12 倍にした（写真 063・064 で節の幅 ≈ 0.2 SL） |
| 第 2 触角の縞が粗い | 環節を細かくし（3 節に 1 本）、白をクリーム色にした |
| 大鉗脚の顆粒が粗い水玉 | 顆粒を小さく密にした |
| 眼柄・第 1 触角が目立ちすぎる | 眼柄を乳白から灰黄に、第 1 触角を橙から黄褐に寄せた |
| 退避中、触角が殻の外へ広がり、脚が地面に投げ出される | 触角は下・内へ向け、鞭を基部から縮めて殻に引き込む（[ゲーム補完]）。歩脚は殻ごとに関節空間を探索して畳み、膝を殻の内腔に入れ、殻の壁を貫かず、前節・指節を急角度で殻口に並べる |
| 体が殻口を通れない大きさの殻を背負っていた | 殻口の狭い側が 0.75 SL 以上という条件（[ゲーム補完]）で殻の大きさを選び、殻の評価にも入れた。大きい個体は小さいイボキサゴやアラムシロを選ばなくなる |

残る差:

- 退避した姿勢の脚の一部（P3 の節）が、殻の脇から見えることがある。殻が地面に接して少し回る分を、畳み方の探索に入れていない。
- 写真の多くは水中のマクロ撮影で、被写界深度が浅く、粒子が浮いている。ラボとゲームではこの撮影条件を再現していない。

## 7. 再現手順

```sh
npm run check                      # 型検査・単体テスト・データ検証
npm run build && npm run smoke     # ゲーム全体の撮影（tests/smoke/out/17〜19 が本種）
node tests/smoke/pagurus-lab.mjs   # ラボの撮影（tests/smoke/out/pagurus-*.png）
npm run dev                        # http://localhost:5173/gerupamasini/hermit-lab.html
```

ラボの URL パラメータ: `mode`（`pose` / `walk` / `retract` / `shells` / `group` / `change` / `guard`）、`view`（`face` と `profile` は個体の向きに追従）、`lod`、`seed`、`shell`、`water`、`debug`、`t`、`shot`、`fouling`、`silt`、`hideAbd`、`sex`、`sl`、`size`、`heading`、`month`。
例: `hermit-lab.html?shell=umbonium_moniliferum&lod=0&debug=1`
