# 生きものの物理（ぶつからない・接地する・波に揺られる）

干潟と水槽の生きもの全種に共通の、軽い物理エンジン風の層。コードは `src/creatures/physics/`。

各種のドライバ（`src/creatures/species/*` ほか）はこれまでどおり自分で動きと姿勢を作る。物理の層はその上に次の 3 つを足す。

| 層 | ファイル | やること |
|---|---|---|
| 接触 | `contacts.ts`, `animals.ts` | 生きもの同士が重ならないように押し分ける |
| 接地 | `bed.ts` | 体の足場（頭・尾・左右）が作る面に沿って寝かせる |
| 水の動き | `water.ts`, `src/world/surfCpu.ts` | うねりと寄せ波で小さな魚を前後に運び、揺らす |

## 1. 接触（生きもの同士がぶつからない）

- **体の形**
  - 体は向きに沿って寝かせたカプセル（丸い種は円盤）で表す。高さの幅も持つ。
  - 形は種ごとの「体つき」で決める。`DRIVERS[...].body` に全長に対する割合で書く（`BodyBuild`）。
    - `width`, `height`: 幅と高さ
    - `core`: 体の芯の長さ（エイの尾やハゼの尾鰭は除く）
    - `ahead`: 芯の中心が位置からどれだけ前にあるか
  - 重さは個体の体重（g）。
- **毎フレームの手順**
  1. ドライバが動いたあとに体を読む（`Driver.body()`）。
  2. 重なっている組を、いちばん短い向きへ押し分ける（位置ベースの緩和を 1 フレームに 3 回）。
     - 軽いほうが多く動く。カキ・アサリ（`fixed`）は動かない。
     - 押しはドライバに返す（`Driver.nudge(dx, dz)`）。動物は押された場所から、していたことを続ける。
- **押し方の細部**
  - 触れる手前に柔らかい余白がある。そこで少しずつ譲り合うので、ぶつかるより「すれ違う」動きになる。
  - 1 フレームに押す量には上限がある。同じ場所に置かれた個体は数フレームかけて離れる。
  - 水槽の壁の外や、その動物に浅すぎる水へは押し出さない。
- **触れ合わないもの**
  - 高さが重ならない組。例: 底のハゼの上を泳ぐ稚魚。
  - 砂に潜った個体、巣穴の中のミズヒキゴカイ、飛んでいるシロチドリ（`away`）。
  - 同じ群れのハク（`flock`）。群れの間隔は `School.ts` の分離が受け持つ。
- **固定**
  - 草に巻きついたヨウジウオ、腐肉に陣取ったアラムシロ、草につかまったエビは `fixed`。周りが避ける。
- **範囲**
  - 干潟では画面に描かれている個体だけが対象（`CreatureSystem`）。
  - 水槽（`TankScene`）と観察ケース（`FieldCase`）は全員が対象。
  - 300 体で 1 フレーム約 0.3 ms。軸に沿った掃引で近い組だけを調べる。

### ドライバの約束

| メソッド | 返すもの / すること |
|---|---|
| `body()` | `{ mode, heading, y }`。`mode` は `bed`（底）/ `water`（遊泳）/ `away`（砂の中・巣穴・空）/ `fixed`（動かせない）。`y` は体の下面の高さ |
| `nudge(dx, dz)` | 動物の本当の位置（ドライバ内部の位置と `ind.pos`）をずらす。描画は次の更新で追いつく |

- 脚で歩く種は、地面に置いた足も一緒にずらす。そうしないと脚が伸びてしまう。
  - 対象: エビは `leg.foot`/`leg.from`、ユビナガホンヤドカリは `planted` ほか、アカエイは尾の鎖。
- `nudge` がない種は押されない。ほかの個体がよける。

## 2. 接地（地面に合わせる）

- `fitBed()` は、体の足跡の 4 点（前・後・左・右）の高さから、体が乗る面を出す。
  - 傾き、面の高さ、法線を返す。
  - 体より狭いくぼみは縁に乗ってまたぎ、真ん中のこぶには乗り上げる。
- `bedTilt()` は、水平な姿勢をその面へ回す回転を返す。
- **マハゼ・エドハゼ・ヒメハゼ**
  - これまでは体の中心の高さで水平に置いていた。斜面では頭が砂に埋まり、尾が浮いていた。
  - 今は足跡の面に沿って体を傾ける。そのうえで接地点（吸盤の縁、腹、尾鰭の下葉）を、それぞれ**真下の**地面に下ろす。
- **アサリ・ハマグリ**
  - 砂の面に直角に寝る（潜る）。
- **もともと傾きを持つ種**（変更なし）
  - カニ、ヤドカリ類、アラムシロ、イシガレイ、ミミイカ、アカエイ、エビ（足ごとの接地）
- **シロチドリ**
  - 脚で立つ鳥なので水平のまま。

## 3. 水の動き（小さな魚が波に揺られる）

### 水が動く速さ（`WaterMotion.sample`）

- **うねり**
  - アマモを揺らす 3 本の波列と突風（`world/amamo/flow.ts` の `waveOrbital`）を使う。
  - アマモ場のある浜では、その時計と向きをそのまま使う。だから稚魚とそばの葉は一緒に前後する。
  - 強さは地図ごと。
    - 走水: 0.1 m/s
    - 葛西: 0.05 m/s
    - 漫湖: 0.03 m/s
  - 浅い波として扱う。
    - 水平の動きは水深の浅い所で弱まる。
    - 上下の動きは底でゼロになる。
- **寄せ波**（走水）
  - 水のパスが描く寄せ波のシェーダー（`SURF_GLSL`）を CPU に移した（`surfCpu.ts`）。
    - ハッシュは GPU と同じ単精度で計算する。だから見えている波と同じ時刻に山が来る。
  - 山の下では水が岸へ η·√(g/D) で流れ、谷の下では沖へ戻る。
- **潮だまり**
  - 引き潮で潮位より上に残った潮だまりは静か。

### 一匹ごとの応答（`WaterRider`）

- **流され方**
  - 体長に応じた割合で水に運ばれる（`carryFor`）。
    - 3 cm の稚魚はほぼ全部（0.8）。
    - 6 cm で半分。
    - 20 cm の魚はほとんど運ばれない（0.08）。
  - 流された分だけ自分の持ち場へ泳いで戻る。
    - 遠くへ運ばれるほど強く戻る。だから波打ち際で大きく振られても、急に止まって見えることはない。
    - 運ばれる範囲は体長の数倍まで。
  - 浅すぎる水へは運ばれない。
- **揺れ**
  - 水の加速度で見かけの重力が傾き、体の背が振れる（浮き袋の下に重心がある振り子）。
  - バネで少し行き過ぎて戻り、最大で約 17°。
  - 実際の物理より 3 倍大きく見せている。魚が姿勢を立て直す動きで、揺れはもっと目立つため。
- **適用**
  - ドライバは `vel × dt` を位置に足す。だから影・カメラ・タモ網も一緒に動く。
  - `tiltX`, `tiltZ` は姿勢（YXZ オイラー）に足す。

| 種 | 波への応答 |
|---|---|
| ハク | 群れごと前後し、揺れる。C スタートで逃げる間は 3 割 |
| アミメハギ | アマモの間で葉と一緒に前後し、揺れる |
| ミミイカ | ホバリングと遊泳の間。砂の上・潜砂中は踏みとどまる |
| イシガレイ | 底を離れて泳ぐ間だけ |
| シラタエビ・イソスジエビ | `ShrimpWorld.flowAt` に水の速さを入れた（もとの移植コードが持っていた口）。泳ぐ個体は水に対する抵抗で運ばれる。立っている個体は流れに身を低くする。触角は流れになびく |
| ヨウジウオ | もともと持っていた、アマモの流れに乗る動きのまま |
| ハゼ類・底生の種 | 底にしがみついているので運ばれない |

## 4. 確かめ方

- **単体テスト**: `tests/unit/creaturePhysics.test.ts`
  - 押し分け: 短い向き・重さ・固定・高さ・群れ・余白・水際・壁
  - 300 体の速さ
  - 斜面の面・くぼみ・こぶ
  - 本物のハゼのリグを斜面に置き、頭と尾が地面に乗るか
  - 2 匹のハゼをドライバ経由で押し分ける
  - 稚魚と大きな魚の振れ幅、潮だまり、アマモとの同期、浅瀬、寄せ波の流れの向き
- **ゲーム内**: `node tests/smoke/physics.mjs`
  - 走水の浅瀬で、ヒメハゼ 6 匹とイソスジエビ 3 匹を重ねて置く。
  - 数秒後に重なる組がゼロになっていることを確かめる。
  - ハゼが海底の傾きに沿って寝ていることを確かめる。
  - ハクとアミメハギが波で前後していることを確かめる。
  - 前後の写真を `tests/smoke/out/physics-*.png` に保存する。
