# イソスジエビ（*Palaemon pacificus*）— シラタエビからの差分改修

シラタエビ（*Exopalaemon orientis*、`claude/epic-noether-hzhjhj` で作ったもの）のモデル・リグ・歩行・遊泳・tail-flip・行動 AI をそのまま土台にした。
イソスジエビとして違う部分だけを、**種プロファイル**として差し込んでいる。
シラタエビ本体のコード（ゲームの `src/creatures/species/shrimp/model/`）は種を指定しなければ従来どおりに動く。

- 種プロファイル: `src/creatures/species/shrimp/model/isosuji.js`（形態・運動・色・模様・行動の差分）
- 行動 AI: `src/creatures/species/shrimp/model/IsosujiBrain.js`（シラタエビの `Brain` を継承）
- ビューア: `reference/isosuji-viewer/`（開発時は http://localhost:5173/gerupamasini/reference/isosuji-viewer/）。岩礁の潮だまりとアマモ場を再現している

確度タグはシラタエビの `docs/RESEARCH.md` と同じ。

| タグ | 意味 |
|---|---|
| [PHOTO nn] | ユーザー提供の写真資料（iNaturalist 掲載 50 枚、2026-10-08 作成の PDF）の番号 |
| [LIT] | 文献 |
| [G] | 表現上の補完 |

写真そのものは再配布条件が写真ごとに違うため、リポジトリには入れていない。

## 1. 調査

### 体型
- 全長は成体で 40–50 mm [LIT 徳島県・三重県の解説; PHOTO 18 の物差しで額角先端〜尾節末端 ≈ 48 mm]。
  - シラタエビ（55–70 mm）より小さい。
  - 頭胸甲は相対的に高く幅もあり、ずんぐりして見える [PHOTO 02, 12, 30, 47]。
- 腹部の背は第 3 節で緩く盛り上がる。
  - シラタエビほど強いこぶ（第 3/4 節での急な屈曲）にはならない [PHOTO 02, 15, 30, 47]。
  - 手で持った個体は大きく曲がる [PHOTO 08, 45] が、これは静止姿勢ではない。

### 額角
- 額角式は 1–3+6–9/3–5 [LIT Plazi: *Palaemon pacificus* (Stimpson, 1860)]。
  - 背縁の 1–3 歯は眼窩より後ろの頭胸甲上にある。
  - 腹縁には 3–5 歯がある。
- 遠位半分は上向き（ascendant）で、先細りする [LIT]。
- 鱗片（scaphocerite）の先端とほぼ同じか、わずかに越える長さ [PHOTO 08, 12, 18]。
- シラタエビと違い、基部に高い鶏冠状の隆起がない。歯は基部から中ほどまで等間隔に並ぶ。
- 側面に赤褐色の線が 1 本ある [PHOTO 08, 41]。

### 体節・腹部
- 腹部は 6 節で、第 6 節が最も長い。
- 第 5 節の側甲は後下角が角張る（quadrate）[LIT]。
- 体節の境目ごとに暗色の横帯があるので、体節感が強い [PHOTO 07, 19, 34]。

### 歩脚・鉗脚
- 第 1 胸脚は腕節が鋏の 1.6 倍 [LIT]。
- 第 2 胸脚は鋏が腕節の 1.3–1.4 倍。ここはシラタエビ（腕節が長い）と比率が逆になる [LIT]。
- 歩脚（第 3–5 胸脚）は細く長い。体を高く持ち上げて立つ [PHOTO 13, 15, 30, 47]。
- 歩脚の色は青白い半透明。各関節の手前に黒、関節に橙〜黄の輪がある（縞の脚）。
  - 和名の由来ではないが、一目で分かる特徴になっている [PHOTO 09, 13, 20, 34, 49]。

### 触角
- 第 2 触角の鞭は体長の 1.5–2 倍あり、色は橙〜赤褐色 [PHOTO 13, 20, 33, 48]。
  - シラタエビの第 2 触角はほぼ無色。
- 第 1 触角は 3 本の鞭を持ち、上外鞭が長い。黄褐色 [PHOTO 18, 28, 41]。

### 眼
- 角膜は暗褐色で、明るい金褐色の縁取りがある。
- 眼柄に橙の斑がある。
- 眼は横に張り出すが、シラタエビ（ほぼ真横、約 80°）ほどではない。約 55–60° [PHOTO 07, 20, 34, 41]。

### 尾節・尾肢
- 尾肢の外肢の先寄りに、黄〜橙の丸い斑が黒で縁取られて入る [PHOTO 11, 13, 19, 20, 34, 38, 40][LIT 徳島県: 「尾扇には黒で囲まれた黄色の丸い斑紋」]。
- 尾扇の地色は青みがかった透明。個体によっては赤橙になる [PHOTO 20, 22, 50]。

### 透明感と模様
- 地は半透明で、オリーブ〜黄緑がかって見える [PHOTO 02, 12, 30, 36, 47]。
- 中腸腺は頭胸甲の中に緑褐色の塊として透けて見える [PHOTO 20, 24, 33, 36]。
- 筋模様は暗褐色〜黒褐色の細い線で、縁は赤褐色になる。
  - **腹部**: 各節に横帯が 2 本ある。中ほどの細い 1 本と、後縁の太い 1 本。側甲では前下方へ斜めに傾く [PHOTO 15, 30, 40, 47]。
  - **頭胸甲側面**: 後背方から前腹方へ走る斜線が 4–6 本ある [PHOTO 02, 12, 18, 30]。
  - **頭胸甲背面**: うねる縦線がある [PHOTO 34, 41]。
- 線の間には白〜クリーム色の微小な点が並ぶ。側甲の下縁は黄色い点になる [PHOTO 09, 12, 19, 21, 23, 30, 47]。
- 体色は環境と個体で幅がある。
  - 明るい黄色の個体 [PHOTO 36]、暗褐色の個体 [PHOTO 01, 45] もいる。
  - 岩の上の個体は全体が暗い [PHOTO 09, 22, 23]。

### 生息場所と行動
- 内湾〜外洋に面した岩礁の潮間帯、潮だまり、転石の下、海藻の間、アマモ場にすむ [LIT; PHOTO 03, 09, 21–27, 29, 31, 32]。
- 夜行性。昼は岩の割れ目やオーバーハングの下、海藻の陰に潜む [LIT BE-PAL; PHOTO 22, 31]。
  - 夜は岩の上や開けた砂礫に出て、歩きながら摂餌する。
- **歩行**: 長い歩脚で体を高く上げ、凹凸のある岩の上を乗り越えて歩く [PHOTO 23, 26, 27, 31]。
- **摂餌**: 第 1・第 2 鋏脚を交互に基質へ伸ばし、付着藻類やデトリタスをつまむ。
- **遊泳**: 長い距離は泳がない。岩から岩へ、あるいは海藻の上へ、腹肢で短く泳ぎ移る [R]。
- **静止**: 静止中も第 1 触角を左右別々に小刻みに弾き（化学受容のフリック）、第 2 触角をゆっくり振る [R]。
- **逃避**: 驚くと腹部を急に屈曲させ、後方へ跳ぶ（caridoid escape）。1–2 回跳んで、すぐ近くの隠れ家へ入る [R]。
- **アマモ場**: アマモの葉に脚で取り付き、葉に沿って上下を向いて止まる。葉ごと揺られながら葉面をつまむ [R; 近縁の *Palaemon* 属でアマモ葉上の付着行動が知られる]。

## 2. シラタエビとの違い（改修一覧）

| 項目 | シラタエビ（土台） | イソスジエビ（改修後） | 主な変更箇所 |
|---|---|---|---|
| 全長 | 60 mm（45–75） | **48 mm（35–55）** | `isosuji.js` `TL`、ビューアの個体サイズ |
| 頭胸甲 | 細め | **高さ +8%、幅 +6%** | `morph.carapace.stations` |
| 腹部のこぶ | 第 3 節で強く盛り上がり、第 3/4 節で急に曲がる | **穏やかなアーチ**（こぶ 0.08→0.03、静止屈曲を弱く） | `morph.abdomen`、`morph.rest.joints` |
| 額角の長さ | 眼から 0.25 TL（1.3–1.4 CL）、細長い | **眼から 0.17 TL（鱗片と同程度）** | `morph.rostrum.tipAhead` |
| 額角の形 | 基部に高い隆起冠があり、中央は無歯、先端は細い | **隆起冠なし。基部〜中ほどは直線的で、遠位半分は上向き。高さがある** | `morph.rostrum.dorsal/ventral` |
| 額角歯 | 背 7 + 副歯 / 腹 5 | **背 2（眼窩後）+6 + 亜端 1 / 腹 4** | `morph.rostrum.*Teeth` |
| 眼 | 横 80°、黒い角膜 | **横 57°、暗褐色の角膜に金褐色の縁、眼柄に橙斑** | `morph.eye`、`look.eye` |
| 第 2 触角 | ほぼ無色、半透明 | **橙〜赤褐色ではっきり見える** | `look.flagellum` |
| 第 2 胸脚 | 腕節が鋏より長い | **鋏が腕節の 1.35 倍** | `morph.pereopods` P2 |
| 歩脚 | 短め、乳白色 | **長節・前節を約 15% 延長。青白い半透明に黒・橙の輪** | `morph.pereopods`、脚の縞シェーダ |
| 体の地色 | 乳灰色（ミルキー） | **オリーブ〜黄緑がかった半透明** | `look.*` |
| 模様 | 点状の色素胞が散る | **黒褐色の横帯（腹部 2 本/節）、頭胸甲の斜線と縦線、白点、黄点** | 体の縞シェーダ（`PAT_MODE 1`） |
| 尾扇 | 基部に暗斑 | **外肢先寄りに、黒で縁取った黄〜橙の眼状斑** | 尾肢の眼状斑シェーダ（`PAT_MODE 3`） |
| 中腸腺 | 黄土〜褐色 | **緑褐色** | `morph.colour.hepatopancreas` |
| 生息場所 | 砂泥底、河口 | **岩礁・潮だまり・海藻・アマモ場** | ビューアの `World.js` |
| 歩行 | 砂泥の上、岩は迂回 | **低い岩を乗り越えて歩く**（足の接地を上から取る、岩を障害物にしない） | `anatomy.footProbe`、`World` の `climbable` |
| 遊泳 | 6–14 秒の巡航、ホバリング | **2–5 秒の短距離（岩から岩へ）、着地する** | `IsosujiBrain` の `SLOW_SWIM` |
| 静止時の触角 | 左右同時のフリック | **左右別々のフリック、第 2 触角のゆっくりした振り** | `anatomy.antennae` |
| 逃避 | 1–3 回の tail-flip のあと、行動を選び直す | **1–2 回で後方へ跳び、最寄りの隠れ家（割れ目・アマモ）へ入る** | `anatomy.tailFlip`、`IsosujiBrain` |
| アマモ | 隠れ家の目印にするだけ | **葉に取り付き、登り、葉の揺れに乗って止まる（CLING）** | `Shrimp` の `cling` モード、`World.bladeFrame()` |

## 3. 行動（状態）

`IsosujiBrain` はシラタエビの `Brain` を継承し、内部状態（空腹・恐怖・疲労）、softmax 選択、慣性、反射層をそのまま使う。
選べる状態は次のとおり。

| 状態 | 中身 |
|---|---|
| `IDLE` | 静止。第 1 触角を左右別々にフリックし、第 2 触角を低い振幅で振り、顎脚を動かす |
| `WALK` | 岩の上を含めて歩く（脚が地面を押して体が進む、シラタエビの歩行ロジック） |
| `FORAGE` | ゆっくり歩きながら鋏脚で基質をつまむ。体を前傾させる |
| `SLOW_SWIM` | 0.06–0.15 m 先の岩の上などへ、腹肢で短く泳いで着地する |
| `HIDE` | 割れ目、平石の下、アマモ場へ戻り、頭を外へ向けて止まる。昼と恐怖で選ばれやすい |
| `ESCAPE_BACKWARD` | 腹部屈曲による後方への tail-flip（反射層）。そのあとは `HIDE` へ移る |
| `CLING` | アマモ場では葉に取り付き、登り、揺れに乗って止まる（ここから `FORAGE` のつまみ動作もする） |

補助の状態として、`FEED`（餌の上で摂食）、`GROOM`（触角の掃除）、`INVESTIGATE`（匂い・刺激に近づく）も残している。

## 4. 見た目の実装

- 透明感、殻の薄さ、体節感、濡れ感は、シラタエビの外骨格マテリアルをそのまま使う。
  - 外骨格は `MeshPhysicalMaterial` に clearcoat、縁で濃くなる α、関節膜、微細凹凸を加えたもの。
  - その下の半透明な筋肉・組織の層も同じものを使う。
- 縞模様は、ジオメトリにパラメトリック座標（`aPat`、`aPatW`）を持たせて描く。シェーダはピクセル単位で線を描き、`fwidth` でアンチエイリアスする。
  - 頂点間隔に依存しないので、マクロ撮影の距離でも線が鋭い。
  - 線の太さとうねりはノイズで個体差を出す。
- 模様は `#define PAT_MODE` で切り替える（0 = なし、1 = 体の筋、2 = 脚の輪、3 = 尾肢の眼状斑）。
  - シラタエビのマテリアルは `PAT_MODE` を持たない。シェーダもキャッシュキーも従来と同じなので、見た目は変わらない。
- 距離 LOD はゲームの `ShrimpDriver` の段階表示をそのまま使う（3 m 以遠で組織・内臓、6 m 以遠で脚と触角を省く）。
  - 脚のマテリアルのキーも `cuticle-v3-app` で始まるので、脚の LOD 判定はそのまま効く。
- アマモはシラタエビの環境の `InstancedMesh` と、揺れの頂点シェーダを流用している。
  - CPU 側の `World.bladeFrame()` が同じ式で葉の位置と向きを求め、取り付いた個体が葉と一緒に揺れる。

## 5. ゲームへの組み込み
- 種データ: `public/data/species/palaemon_pacificus.json`。
  - 走水マップの礫・砂の潮だまり、浅場、アマモ場に出現する。夜に多い。
- ドライバ: `drivers/index.ts` の `isosuji` に登録した。
  - シラタエビの `ShrimpDriver` を `ISOSUJI` プロファイルで使うので、距離 LOD、意図（休む・歩く・泳ぐ・摂餌・逃避）、水際の制約はシラタエビと共通になる。
- ゲームの世界にはアマモの葉の位置を返す `bladeFrame()` がない。そのため `CLING` はビューアだけで動く。
  - ゲーム内では、アマモ場でも底を歩く。
- 種プロファイルを渡さなければ、`ShrimpModel` も `Shrimp` も `ShrimpDriver` もシラタエビのまま動く。
  - 外骨格のシェーダとキャッシュキーも従来と同じ。

## 6. 確認方法
- ビューア: `npm run dev` → http://localhost:5173/gerupamasini/reference/isosuji-viewer/
  - パネルの「選択個体の行動を指定」で 7 つの状態を切り替えられる。
  - 「クリック: 刺激」で `ESCAPE_BACKWARD` を起こせる。
  - 夜↔昼スライダで、夜の活動と昼の隠れ方が変わる。
- 見比べ: `?species=shirata` を付けると、同じ環境で土台のシラタエビ（全長は同じ比率で拡大）を表示する。
