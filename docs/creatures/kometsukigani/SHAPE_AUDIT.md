# コメツキガニ 形状の監査と作り直し（写真との比較）

前のモデルを「完成品として微調整」した結果、形態が実物から大きく外れていた（巨大な白いはさみ、太い筒状の眼柄、太い脚、クモのような脚の広がり、角張った甲）。今回は色・質感を外した**無着色のグレー模型**と**黒いシルエット**で、実物写真と形だけを比べてから作り直した。この文書はその記録。

単位はすべて甲幅（CW = 1）。写真の番号は利用者提供の資料集「コメツキガニ 写真資料70枚」（PDF）の番号、`2.webp`〜`6.webp` は会話に添付された写真。

## 3. 直し方の方針

1. まず形（無着色のグレー模型と黒いシルエット）。正面・真上・側面・斜め前の 4 方向で写真と比べ、合うまで繰り返す。
2. 形が合ってから、色・顆粒・剛毛・砂汚れ・個体差。
3. 最後にもう一度 4 方向で写真と比べる。

## 4. 作り直した後の比較

### 確かめ方

- 開発用ビューアの `scene=clay`（無着色のグレー模型）と `scene=sil`（白地に黒いシルエット）、`ortho=<画面の高さ（CW）>`（正射影）で撮り、シルエットの輪郭を写真に赤線で重ねた（正面: 063。甲幅 1 CW = 289 px に合わせた）。
- 正面・真上・側面・斜め前の 4 方向を、グレー模型と色つきの両方で写真と並べた（正面 063、真上 057・049、側面 050・060、斜め前 064・023・069）。
- 色をつける前に、正面・真上・側面のシルエット、脚の長さ比、はさみの大きさ、眼柄の太さを写真と合わせた。

### 残っている違い

- 脚の関節: 節のつなぎ目が丸い筒の端に見え、写真の半透明の関節膜より機械的に見える。
- 斜め上から見ると、写真より脚がやや長く細く見える（写真の脚は縁の半透明の部分と剛毛で太く見える）。
- 写真ごとの光（夕方の暖色、水槽）とビューアの光は合わせていないので、色の比較はおおよそ。
