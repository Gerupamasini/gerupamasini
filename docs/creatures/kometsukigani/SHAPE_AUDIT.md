# コメツキガニ 形状の監査と作り直し（写真との比較）

前のモデルを「完成品として微調整」した結果、形態が実物から大きく外れていた（巨大な白いはさみ、太い筒状の眼柄、太い脚、クモのような脚の広がり、角張った甲）。今回は色・質感を外した**無着色のグレー模型**と**黒いシルエット**で、実物写真と形だけを比べてから作り直した。この文書はその記録。

単位はすべて甲幅（CW = 1）。写真の番号は利用者提供の資料集「コメツキガニ 写真資料70枚」（PDF）の番号、`2.webp`〜`6.webp` は会話に添付された写真。

## 3. 直し方の方針

1. まず形（無着色のグレー模型と黒いシルエット）。正面・真上・側面・斜め前の 4 方向で写真と比べ、合うまで繰り返す。
2. 形が合ってから、色・顆粒・剛毛・砂汚れ・個体差。
3. 最後にもう一度 4 方向で写真と比べる。

- 開発用ビューアの `scene=clay`（無着色のグレー模型）と `scene=sil`（白地に黒いシルエット）、`ortho=<画面の高さ（CW）>`（正射影）で撮り、シルエットの輪郭を写真に赤線で重ねた（正面: 063。甲幅 1 CW = 289 px に合わせた）。

## 7. 写真との差を数値で詰める（シルエットの重なり・部位の色）

目で並べるだけでは差が残っても気づきにくいので、写真との差を数値にして、差の大きい所から直した。

### 測り方

- **写真の切り抜き**: 写真ごとに GrabCut（OpenCV）でカニの領域を切り抜く（背景の砂が似た色の写真は、体の芯・眼柄を「確実にカニ」、腹の下の砂を「確実に背景」と指定して分ける）。063（正面）、049（後ろ斜め上）、009（標本の真上）。
- **姿勢と視点の当てはめ** `tools/viewers/kometsukigani/fit.mjs`: 開発用ビューアの黒いシルエットを正射影で描き、写真の切り抜きとの重なり（IoU）が最大になるよう、カメラの向き・位置と、写真ごとに違う姿勢（体高、体の傾き、脚ごとの足先の距離・振り・高さ・指節の角度、鉗脚の関節角）を座標降下法で合わせる。カメラの縮尺は写真で測った甲幅で固定する。姿勢をそろえた後に残る差が、形の差。`roi` を指定すると、その範囲（例: 甲だけ、体だけ）で重なりを測る。
- **差の図**: 写真にしかない所を緑、模型にしかない所を紫で塗り、模型の輪郭を写真に重ねる。
- **部位の色**: 写真と描画の同じ部位（甲・顎脚・掌・腕節の瘤）で、明るさ（L）、10 / 90 パーセンタイル、色み（a・b）、細かい・中くらい・大きいムラの量を比べる。

### 結果

### 残っている差

- **脚の姿勢**: 写真ごとに脚の置き方が違い（標本は脚を平らに押さえた姿勢、049 は手の上で縮めた姿勢）、立ち姿の IK では再現しきれない。全体の重なりの差の大半はこれで、形の差ではない。

- **光**: 063 は夕方の低い暖色の光、049 は曇りの屋外で、ビューアの光とは違う。色の比較はおおよそ（明るさの差 ±5 程度は光の差とみなした）。

### 色

- 腹甲の側板は生時に紫〜青（b30 は鮮やかな青紫、b39 は薄い藤色、b61 は銀白）。脚の付け根に向かって濃く、前方（はさみの付け根のあいだ）は淡い。縫合線と板の縁は白い。全体に黒い細点（標本 b66）。
- 腹部は白っぽい青灰色の細点、節の境は細い線、中央の節に薄い褐色の線（b30・b66）。標本の黄褐色（b66・b69 の正中や顎脚の付け根）は保存の色と見て使わなかった。

### 作り方

- 甲の下半分を、側壁・顔・腹甲の 3 つに分けた（`ScopimeraGlobosaGeometry.js` の `carapaceFn`）。顔は Morphology の `FACE`（高さごとの前後の位置）に沿って下がり、側壁とは横 0.2〜0.42 のあいだで混ぜる。最初は混ぜる幅を狭く（0.17〜0.3）したが、正面から見ると口のまわりが四角い暗い穴になった（b67・b68 にはない）ので広げた。
- 腹甲は Morphology の `STERNUM.outline` の多角形を滑らかにした輪郭から中心へ縮める板。縫合線はメッシュの間隔より細く、形状に入れると陰影が縞になったので、質感（白い線と浅い溝）だけで描く。位置は形状と質感で同じ `STERNUM.sutures` を使う。
- 腹部は節の長さと幅（`ABDOMEN`）から輪郭を作る 1 枚の板。節の境の溝と線も同じ値から質感で描く。尾節の先は丸い縁で閉じる（点にすると先端に小さな突起が出た）。
- 第 3 顎脚の 063 の輪郭は正面から見た形なので、33° 傾けた分だけ板に沿って伸ばした（0.33 / cos 33° ≈ 0.39）。伸ばす前は顎脚の上端が前縁から 0.09 下にあり、正面から見ると顎脚の上に暗いすき間ができた。

### たたんだはさみ

付け根が前へ 0.235 動いたので、関節角を合わせ直した。「たたむ」は 063 で読んだ腕節の瘤・掌・指先の位置（8 章）に合わせ、ほかのプリセット（すくう・口元・振り上げる・構える・しまう）は付け根が動く前の瘤・掌・指先の位置を保つように合わせた。063 のシルエットだけに当てはめると体の重なりは 0.934 まで上がるが、はさみが外へ開いて脚の画素を覆う形になり、写真で読んだ掌の位置（横 0.33）から外れるので採らなかった。
