# コメツキガニ 参考写真（Phase 2）

利用者提供の写真資料集「コメツキガニ 写真資料70枚 / 多方向・形態・細部」（PDF, 36 ページ）と、利用者が会話に添付した巣穴と砂団子の写真 1 枚を使った。PDF の各写真には撮影者・掲載元・出典リンクが付いている。権利は各撮影者・掲載元に帰属する（CC BY-NC などの条件付きを含む）。リポジトリには画像を含めない。

形態は標本写真（001–013、「微小生物の画像集」）を主に計測した。行動・色・巣穴・砂団子は野外写真（014–070、主に iNaturalist の研究グレード観察）を複数個体で比較した。
