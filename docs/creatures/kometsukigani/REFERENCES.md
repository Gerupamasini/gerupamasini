# コメツキガニ 参考写真（Phase 2）

利用者提供の写真資料集「コメツキガニ 写真資料70枚 / 多方向・形態・細部」（PDF, 36 ページ）と、利用者が会話に添付した巣穴と砂団子の写真 1 枚を使った。PDF の各写真には撮影者・掲載元・出典リンクが付いている。権利は各撮影者・掲載元に帰属する（CC BY-NC などの条件付きを含む）。リポジトリには画像を含めない。

形態は標本写真（001–013、「微小生物の画像集」）を主に計測した。行動・色・巣穴・砂団子は野外写真（014–070、主に iNaturalist の研究グレード観察）を複数個体で比較した。

## 追加の写真（利用者添付 2.webp〜6.webp）と照合

2 回目の作り込みで利用者が添付した 5 枚。開発用ビューアのプリセット（`preset=p1…p6`）がそれぞれのカメラ・光・地面・色型・姿勢を再現し、`tools/viewers/kometsukigani/compare.mjs` で写真と横に並べて部位ごとに比べた（写真はリポジトリに入れていない。比べるときは `p1.png`… の名前で 1 つのフォルダに置く）。

| 写真 | 内容 | プリセット | 使い道 |
|---|---|---|---|
| 2.webp | 水槽、正面、床すれすれ（淡色の個体） | p1 | 顔の高さの比（第 3 顎脚 : 眼柄の根元から顎脚上端まで ≈ 100 : 35）、眼柄の太さ、はさみの色、脚の帯と剛毛、部位ごとの平均色 |
| 3.webp | 手のひらの上、腹面 | p2 | 腹甲の紫と白い縫合線、雄の腹部、脚の腹側（帯がない）、はさみの指の桃色と黄色い先 |
| 4.webp | 水槽、正面やや上（カーキの個体） | p3 | 眼柄の太さ（直径 ≈ 0.07 CW）と角膜の窓、背面の区域のふくらみ、第 3 顎脚の白い帯 |
| 5.webp | 黒い砂の野外、斜め上（灰色の個体が砂団子を持つ） | p4 | 灰色の型、砂団子の大きさ（甲幅の約 1/3）と密度、黒い砂の白黒の粒 |
| 6.webp | 黒い砂の野外、地面の高さ（紫の雄のウェービング） | p5 | ウェービングの体高（腹甲が砂から ≈ 0.8 CW）、足先の広がり（≈ 2.7 CW）、はさみの形と色、歩脚長節の赤褐色 |
| 標本 007 | 背面（既存の資料集） | p6 | 甲の輪郭と模様、歩脚の長さ |
