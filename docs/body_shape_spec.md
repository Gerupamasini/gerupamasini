# シロチドリ 3D 形状仕様 v4.2（正面・側面・上面・後面・断面、体の作り直しと v3 との中間の太さ）

- 対象: シロチドリ *Charadrius (Anarhynchus) alexandrinus nihonensis*、成鳥雄・夏羽（基準個体）。
- 作成日: 2026-10-03。v3（2026-09-30）は側面シルエットだけに合わせて体を彫刻し、幅は後から少しずつ広げていた。
  正面から見ると「縦長の細い卵に首が見える」形で、ユーザーの正面写真（下記）とまるで違った。v4 は**体の SDF を
  一から作り直し**、正面・側面・上面・後面を同時に満たす。
- 権威の順位（v4）:
  1. **正面の形**: ユーザーの正面写真（以下「ユーザー写真」。リポジトリには入れない）。カタログの正面・後面・斜め写真
     （p013、p059、p063、p037、p038 ほか）と食い違うところはユーザー写真を採る。
  2. **側面の形**: v3 と同じ relaxed 中央値シルエット（17 枚、Frame A）。v4 でも IoU ≥ 0.93 を保つ。
  3. 羽色・頭の細部・尾・姿勢プリセット・文献寸法は v3 のまま（付録 V3 §6、§11–§13、§15、§20）。
- **v4.1（2026-10-03、validation §AC）**: 斑と頭の形をユーザー写真に合わせた。胸側斑を白い顔と喉を囲む馬蹄形の
  帯に、褐色の肩をその外側に、頭頂を広く丸く、顔の模様（眼の周り・過眼線・額の黒帯）を軽くし、翼の見える下縁を
  2–3 mm 下げた（§8、§10、§11、§13 の「v4.1」）。
- **v4.2（2026-10-04、validation §AD）**: ユーザーの指摘「今度は逆に太すぎる。前（v3）と今（v4.1）の中間くらいが
  よい」。体の太さを v3 と v4.1 の中間にした（下の「v4.2」節）。§2–§13 の幅・脚・翼の x・胸側斑の線の数値は
  v4.2 節の値で置き換える。高さ方向（側面の輪郭）、斑の模様、顔、動きは v4.1 のまま。
- 写真と写真から作ったもの（マスク・切り抜き・比較画像）は scratchpad の `rebuild/`・`mark4/`・`mid/` だけに置く。
- 作業ファイル（scratchpad `rebuild/`）:
  - `meas/`: ユーザー写真の GrabCut マスク（`user_mask2.png`）、カタログの正面・後面の切り抜きと幅の表
