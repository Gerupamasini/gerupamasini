# ヒメハゼ *Favonigobius gymnauchen* — 写真準拠のリアルタイム 3D モデル（Three.js）

東京湾の干潟・浅い砂底にすむヒメハゼの成魚（標準体長 SL 43 mm、全長 TL 約 53 mm）を、ノードスクリプトで手続き的に生成した glTF（GLB）として作っています。中身は次のとおりです。

- **形態**: 頭部の SDF 彫刻、断面ロフト、条＋鰭膜の鰭
- **リグ・アニメーション**: 24 関節のスキン、鰭のモーフ
- **シェーダー**: 体積透過シェーダー（ビューア）と、glTF 標準 PBR（ゲーム）の両方に対応
- **行動**: 行動 AI と、干潟の行動デモ

モデリングの基盤は、マハゼ稚魚の GLB パイプライン（ブランチ `claude/adoring-faraday-h25n7c`）です。形・寸法・模様・色はすべて、ユーザー提供の写真資料 70 枚（iNaturalist）と文献で決めています。

> 写真資料の権利は各権利者に帰属します。写真は計測にだけ使い、このリポジトリには含めていません。

**根拠タグ**（コード内コメントも同じタグを使います）

| タグ | 意味 |

## 3. 形態（写真計測と文献）

**計測方法**
- 写真は吻端と尾鰭基部（下尾骨後端）の 2 点で正規化し、%SL 座標にしてから計測しました。x は吻端から尾鰭基部方向、y は体軸からの距離で、背側が正です。
- 側面計測には、物差し・カラーカード付きの標本写真を使いました: 004/005/006（同一個体 A）、022、025/031（同一個体と思われる C）、026。生体写真 003, 007, 014, 028, 029, 057, 067, 069, 070 も使っています。
- 背面写真 049 と 058 は体幅に、頭部の拡大写真は眼・口・鰓蓋に使いました。

**値の決め方**: モデルの値は `src/fish/species.js`（共有定数）と `tools/himehaze/anatomy.mjs`（形状）にまとめています。写真の範囲と文献の値が食い違う場合は、写真の範囲を優先しました。

**断面**:
- 吻端は小さな楕円です。
- 眼の高さでは上側が丸く、下側が平らになります。
- 胸部が最も幅広で、腹面は扁平です（背面 049/058 で幅を計測）。
- 体幹後半は縦長、尾柄は強く側扁します。

**鰭の色・模様**（P。生体 001/014/054、標本 025/026/031/004）

- **D1**
  - 透明な膜に、錆褐色の小斑 3〜4 列（2.0 × 1.0 %SL）が並び、第1棘には暗色の横帯が入ります。
  - 第 5〜6 棘間の膜に黒斑（3.0 × 1.7 %SL の横長楕円、鰭高の 45–50% の位置）があります。成魚では**雌雄とも**に見られ、幼魚 019 にはありません。
  - 縁は淡色です。
- **D2**
  - 鰭条と鰭条の間に、横長の斑（2.3 × 0.9 %SL）が 5 列（h = 1, 3, 5, 7, 9 %SL）並びます。後方・上方ほど小さくなります。
  - 生体では斑の周りを青白い網目が縁取ります。鰭の先端 20% は無地です。
- **尾鰭**
  - 上側 2/3 に、錆褐色の点が縦帯状に 6 列並びます。
  - 基部の黒斑は芯部が 2 × 1.8 %SL で、鰭条に沿って 3 本の筋が伸び、全体で「<」形になります。
  - 下側 1/3 は淡黄色で、下から 2〜3 本目の主鰭条に沿って暗色の筋（x 103–113 %SL）があります。
  - 上縁の黒い短線は 001/014 だけに見られるので、繁殖期の雄の表現に回しました。
- **胸鰭**: 透明で、基部に小褐点が 2〜3 個あります。
- **臀鰭**: 透明で、わずかに黄色みがあります。
- **腹鰭盤**: 半透明の乳白色です。繁殖期の雄は外側の鰭条が黒くなります（051、A）。

## 5. 体色・模様

**体側の斑**: 写真 7 個体の %SL 格子上で斑の中心を測り、`anatomy.mjs` の `PATTERN` に入れました。

| 要素 | 写真（P）での計測 | 文献（F） |
|---|---|---|
| 体側中央の暗色斑 | 中心 x = 28.3 / 41 / 57 / 73 / 87.4 %SL。各斑は 2 個の小斑が対になったもので、その周りに錆色点の群れがある | 体側中央に黒色斑 4 個（鱗 2 枚分）。保存個体では 4–5 個、それぞれ小円斑 2 個の対 |
| 尾鰭基部斑 | 中心 97.8 %SL、成魚では後方が二叉 | **横向きの Y 字状に二叉**（幼魚では丸い） |
| 背側 | 鞍状の淡い斑、項部はくすんだ色、鱗ごとに錆色の点 | 淡褐色の地に暗褐色の小斑が密にある |
| 頭部 | 眼から吻への暗色帯、眼下の斑と斜線、頬の斑、前鰓蓋の棒状斑、鰓蓋上部の点、鰓が透けたピンク（007/070） | 眼下に小黒斑、そこから上顎後端へ斜線 |
| 胸鰭基部 | 上端の体表に暗褐斑 | 胸鰭基部の上角に小黒点 |
| 腹面 | 乳白色。腹膜が白く不透明で、消化管は透けない | 腹部は白っぽい |
| 繁殖期の雄 | 頬から鰓蓋が黒褐色で、細かい点描状（062、014）。吻と唇は淡色のまま | 繁殖期の雄は**頬が真っ黒になる** |

**地色の較正**

1. 生体を中性光で撮った写真（007/070/003）では、体側中央の地色が麦わら色でした（sRGB の B/R が 0.55–0.65）。
2. 最初のレンダーは B/R 0.80 で、灰色すぎました。
3. 原因は、**空気中の値のままのフレネル反射**（F0 0.028）が白い鏡面光を足していたことでした。水中では体表粘液（n ≈ 1.37）が水（n = 1.333）と接するため、F0 は約 0.0002 まで下がります（F: 光学）。
4. そこでビューアの体表スペキュラーを `uWetF0`（既定 0.1）で弱め、黄色素胞のフィルターと地色を写真の値に合わせました。
5. 結果、体側中央はレンダー sRGB (156,137,96) に対し、写真 070 が (161,139,94) となりました（[§12](#12-検証ログ)）。

**個体差**: ゲーム用に、明るさ ±7%、暖色度 ±4%、体長 ±6%（大型個体が少数出る分布）をシード値から決めます（`individualVariation`）。写真 025（淡色）と 026（濃色）の差がこの幅に入ることを確認しました。

## 7. 矛盾点・不明点

1. **雄の糸状棘の位置**
   - 日本の資料（ZUKAN、JAWIKI、STAR）は「第1背鰭の**第2棘**」、CN-Fauna は「第1・第2棘」、FishBase 系の記述は「第1棘」としています。
   - 写真 031/025/054 では、伸長しているのは**第1棘**です。
   - モデルは写真に従い第1棘にしました。
2. **D1 の黒斑と縁の色**
   - 文献（CN-Fauna、NIBR）では「灰色で縁が黒く、斑は 3 列」です。
   - 写真では、成魚の雌雄とも第 5〜6 棘間に黒斑があり、縁は淡色です。
   - モデルは写真に従いました。中央に黄帯付き黒斑があるのはミナミヒメハゼの雄の特徴なので、それとは別物です。
3. **頭長**
   - 写真の膜縁での頭長は 23.5–25 %SL、CN-Fauna の比から換算すると 27–28 %SL です。
   - 計測の定義の違いや、CN-Fauna 標本が小型（38–43 mm）であることが原因と考えられます。
4. **尾鰭の形**
   - CN-Fauna は「鈍く尖る」、韓国の資料は「丸い」としています。
   - 写真は、後縁がほぼ直線になる丸形です。
5. **項部の鱗**: 無鱗（0 枚）とする記述と、「0–7 枚」とする記述があります。モデルは無鱗にしました。
6. **未確認の点**
   - 胸鰭条数（16–17 は 1 資料のみ）と尾鰭の分節鰭条数。
   - 原記載（Bleeker 1860）、日本産魚類検索の本文。
   - 本種の巣の溝の本数と寸法、求愛行動、非繁殖期の頬の生時色、虹彩の色（写真では金褐色〜オリーブ）。
   - デモで使っている値はすべて G です: 溝 6 本・長さ約 10 cm、行動の閾値・時間、効用の重み。

## 9. リグ・アニメーション

24 関節のスキンです。D1・D2・臀鰭・尾鰭の鰭は、骨ではなく鰭条ごとのモーフ（`fold` 寝かせる / `flex` しならせる）で動かします。胸鰭はさらに `waveS`/`waveC`（波打ち）を持ちます。

| 指定された名前 | 実装 |
|---|---|
| Root / Body | `J_root`（腹鰭盤の位置、28.5 %SL）と、オブジェクトの原点 |
| Spine01–05 | `J_sp1`–`J_sp5`（37–73 %SL） |
| TailBase / Mid / Tip | `J_sp6`, `J_sp7` / `J_caudal`（尾鰭基部 100 %SL） / `J_caudal2`（110 %SL） |
| Head | `J_head`（21 %SL） |
| Jaw | `J_jawL/R`（下顎）、`J_premax`（前上顎骨の突出）、`J_hyoid`（舌骨）、`J_suspL/R`（懸垂骨）、`J_opercL/R`（鰓蓋）。吸い込みや呼吸で連動する |
| DorsalFin1 / DorsalFin2 / AnalFin | `Fin_Dorsal1/2`, `Fin_Anal` の `fold`/`flex` モーフ（体幹の骨にスキン） |
| Pectoral_L / R | `J_pecL/R` ＋ `fold`/`flex`/`waveS`/`waveC` モーフ |
| Pelvic | `J_pelvic` ＋ `fold` |
| Eye_L / R | `J_eyeL/R`（左右独立。視線は ±0.45 rad まで眼だけで追い、それを超えると頭が向く） |

**焼き込んだクリップ**: `Idle`, `Swim`, `Yawn`。リアルタイムの動きは `Behavior.js` が手続き的に生成します。

**動きの特徴**:
- 頭の首振りの履歴を、体節が後ろへ遅れて再生します（進行波、約 400 mm/s）。
- 呼吸は不規則です（深さと周期が揺らぐ）。
- 胸鰭のストロークでホップします。
- 着地すると砂の粒子が舞います。

## 10. 行動 AI とゲーム組み込み

```js
import { loadHimehazeTemplate, HimehazeActor } from './src/game/HimehazeActor.js';
import { HimehazeEcology } from './src/game/Ecology.js';

const tpl = await loadHimehazeTemplate('models/himehaze.glb');
const fish = new HimehazeActor(tpl, {
  seed: 7,                                   // 個体差と行動乱数の種（Math.random は使わない）
  ground: (x, z) => ({ y, normal }),         // 地形レイキャスト
  heightAt: (x, z) => y,                     // 安価な高さ関数（接地点ごとに使う）
  onEvent: (type, pos, actor) => {},         // 'takeoff' 'land' 'strike' 'bury' 'unbury'
});
fish.place(x, z, heading);
scene.add(fish.root);
const eco = new HimehazeEcology(fish, world, { male, breeding, nest, home });
// 毎フレーム
eco.update(dt);                              // 知覚 → 欲求 → 状態 → 運動指令 → fish.update(dt)
HimehazeActor.separate(actors);              // 静止個体どうしのめり込みを防ぐ
fish.setLOD(level);                          // §11
```

**World インターフェース**（ホストゲーム側で用意する。`src/game/World.js` が見本）

```
predators[]  { position, radius, danger }
food[]       { type: 'copepod'|'amphipod'|'polychaete'|'mysid'|'crab', size (m), position, moving, visible }
fishes[]     HimehazeEcology の一覧（同種の検出に使う）
shelters[]   { position, radius }
player       { position, velocity }          // 接近の速さで脅威度が上がる
heightAt(x, z), current (Vector3), timeOfDay (0–24), tide (0–1)
eat(food), sand(pos, intensity, heading)
```

**欲求**（0〜1）

| 欲求 | 変化 |
|---|---|
| hunger | 時間とともに増え、捕食で減る |
| fear | 上昇は速く、減衰は遅い |
| energy | 動くと減り、静止で回復する |
| curiosity | SCAN 中に減る |
| territoriality | 雄で高い |
| breedingDrive | 巣を持つ繁殖期の雄 |
| boldness | 個体の性格 |

**刺激**: distanceToPlayer / Predator / Food / Shelter / Bottom / Conspecific、waterCurrent、timeOfDay、tideState。

**状態**

| 状態 | 動き |
|---|---|
| IDLE | 腹鰭盤で静止。ときどき流れに向き直る、または背鰭を立てる |
| SCAN | 眼→頭→体の順に周囲を見回す |
| CRAWL | ホップ→停止→見回しの繰り返し |
| SHORT_SWIM | 短い遊泳 |
| FREEZE | 鰭を立てて静止し、脅威を注視する |
| ESCAPE | C 字型の急発進→着地→潜砂（60%）または FREEZE |
| BURY | 砂に潜る |
| FORAGE | 探索→注視→接近→吸い込み→砂を吐く |
| REST | 夜間は砂に半ば潜る |
| COURTSHIP | 巣の溝の手入れ。雌が来たら側面誇示・接近・巣への誘導（1 回 6–12 秒、その後休止） |
| TERRITORIAL | 雄どうしの側面誇示と突進 |

**選択の仕組み**: 状態は効用スコアで選びます。現在の状態に 15% のヒステリシスを足し、シード付き乱数で ±10% 揺らします。危険が大きいときは割り込みで ESCAPE / FREEZE に移ります。

**デモ**: `game.html?fish=6&seed=3&preset=turbidFlat&hour=17`
- カメラが観察者（プレイヤー）です。
- 素早く近づくと、FREEZE → ESCAPE → BURY と反応します。
- ゆっくり近づくと 10 cm 前後まで許容し、その先で FREEZE になります（§12）。

## 11. LOD・性能

ジオメトリ LOD は `node tools/build-model.mjs [--male] --lod 1|2` で生成します。骨格・モーフ・UV は LOD0 と共通です。ゲームでは LOD0 の材質を保ったまま、ジオメトリだけを差し替えます（`loadHimehazeTemplate` が `*_lod1.glb` / `*_lod2.glb` を自動で読み込みます）。デモでは画面上の全長（ピクセル数）で段階を切り替えます。

| LOD | 画面上の TL | 体の頂点数 | 内容 |
|---|---|---|---|
| 0 | > 140 px | 104k（18.5 MB、テクスチャ 2k） | すべて（口腔・歯・鰓腔、全メッシュが影を落とす、透過・クリアコート） |
| 1 | > 45 px | 19.5k（`_lod1.glb` 3 MB） | 歯と鰓腔を非表示、鰭は影を落とさない |
| 2 | > 12 px | 4k（`_lod2.glb` 1.6 MB） | 口腔も非表示、透過なしの軽量材質、影は体だけ |
| 3 | それ以下 | 4k | 腹鰭・臀鰭を非表示、影なし |

体積透過シェーダー（`index.html`）は背景バッファを使う多パス構成なので、ビューア専用です。ゲームでは glTF 標準 PBR を使い、水中の光学補正（`underwater`）を掛けています。同じポーズで止めた状態で LOD0〜3 を撮影し、鰭と体のずれがないことを確認しました。

## 12. 検証ログ

すべてヘッドレス Chromium（SwiftShader）で撮影し、写真と同じ %SL 座標に正規化して比べました。

### 輪郭

- **側面**: 025/026/004 と、白シルエットで重ね合わせて一致を確認しました。
  - 背と腹の輪郭、眼の位置と大きさ（025 と重なる）、口角、鰓蓋縁を確認しました。
  - 尾柄の先端が丸く閉じていた不具合を直しました（高さの絞り込みと `endFade` を調整）。
- **背面**: 049 の体幅と重ねて確認しました。
- **鰭**: `fins=spread` で全開にし、広げた標本 031/025/026 の輪郭と重ねました。
  - D1/D2/臀鰭の高さが写真より 4 割ほど低かったので、計測値に合わせて直しました。
  - 尾鰭は写真どおりの截形に近い丸形です。

### 色

| 部位（%SL） | レンダー | 写真 070 | 写真 007 | 写真 025 |
|---|---|---|---|---|
| 体側中央 63–68 / 0…+2 | (156,137,96) | (161,139,94) | (128,103,63) | (190,170,135) |
| 尾柄 88–92 | (151,132,89) | (153,131,84) | (121,102,68) | (192,163,117) |

- 修正前は (166,151,121) で灰色すぎました。原因の切り分けにデバッグ表示 4〜7 を使い、主因は空気中のフレネル値でした。
- 腹側の体側がまだ写真よりやや白く出ます。背景が白い場合に、薄い組織を光が透過するためです。
- 鰭の斑は、色素の色を吸収にも反映させることで、灰色から写真どおりの錆褐色になりました。

### 雄（031/025/062/014）

- 第1棘の糸状部は先端 x ≈ 47 %SL で、031 の 48.3 と一致しました。
- 黒い頬は、最初は吻まで届く黒い帯になっていました。062 に合わせて「眼の前縁下から鰓蓋縁まで、上縁は眼窩に沿い、点描状」に直しました。

### 行動（固定 60 Hz のシミュレーション、6 個体）

- **餌**: 撒いてから 30 秒で 8 個を捕食しました。
- **急接近**（30 cm/s）: FREEZE → ESCAPE → BURY（0.3 秒で恐怖 0.86）。
- **ゆっくり接近**（2 cm/s）: 16 cm までは採餌を続け、12 cm で FREEZE、7 cm で ESCAPE しました。
- **夜（22:30）**: 全個体が REST で砂に潜りました。
- **雄**: 巣の手入れと求愛を交互に行い、誇示は 1 回あたり有限の時間で終わりました。

### 接地

- 修正前は、高さを魚の位置 1 点でしか取らず、砂漣の上で 1–9 mm 浮いていました。ロール角の符号も逆でした。
- 接地点ごとに地形の高さで解くよう直した結果、体の最下点は砂から 0〜1.4 mm、腹鰭盤の縁はわずかに砂に沈むようになりました。
