# マハゼ幼魚（*Acanthogobius flavimanus*）写実 3D モデル — Three.js

全長 約50 mm（標準体長 41 mm）の幼魚を、生体の半透明感を重視して再現したモデルとビューアです。

- `models/mahaze_juvenile.glb` — 完成モデル（単位 m、+Y 背側、+Z 吻端方向）
- `index.html` + `src/` — 回転・拡大、正面光／逆光／側光の切替ができるビューア（独自シェーダー同梱）
- `tools/` — モデルを再生成するビルドスクリプト（形状・テクスチャはすべて手続き生成で、写真は貼っていません）

## 実行

```bash
npm run serve        # → http://localhost:8080/   （依存なし。three.js r186 は vendor/ に同梱）
npm install && npm run build:model   # GLB を作り直す場合のみ（約1分）
```

WebGL2 と `EXT_color_buffer_float` に対応したブラウザで動作します（デスクトップ版 Chrome、Edge、Firefox、Safari 17 以降）。

操作: ドラッグで回転、ホイール／ピンチで拡大（眼の接写まで）、右ドラッグで移動。キー `F` / `B` / `S` で正面光／逆光／側光、`1` / `2` / `3` でカメラ位置のプリセット、`W` で泳ぐ、`Y` であくび。
何もしなければハゼが自分で行動します。ほとんどの時間はじっとしていて、1回の休止は多くが10〜30秒、ときには1〜2分続きます（自動で動かしたとき、全体の約97%が静止）。動くのは平均して1分に2回弱で、多くは小さな位置直し、ときどきダッシュ、あくびはまれです。砂底に腹びれの吸盤で着底し、胸びれを下後方へ広げて下側の鰭条を砂につけ、しりびれは腹に沿って後ろへ畳みます。動くのはほぼ鰓と眼だけで、胸びれは呼吸に合わせてわずかに震え、ときどきゆっくり扇ぐ程度です。ときどき警戒姿勢をとり、胸びれと立てた吸盤で体の前を持ち上げて頭を上げます（体の後ろ半分と尾は砂についたまま）。そこから、向きを素早く変えて尾を2〜4回打つ短いダッシュ（胸びれを体に畳み、背びれを立てる）で進み、滑空して着地します。ほかに、胸びれで小さく位置を直す、第1背びれを立てる、ときどきあくびをする、といった行動をします。左右の眼は別々にサッカードします。キー `D` で背びれを立てます。
URL パラメータで表示を固定できます（例: `?light=back&view=tail&env=tank`、あくびの途中で止める `?anim=yawn:1.0`）。読み込むモデルは `window.MAHAZE_MODEL_URL` で差し替えられます（`.gltf` とテクスチャを分けた形式でも可）。

## モデルの内容

| 部位 | 内容 |
|---|---|
| 胴体 | 104k 頂点。上下で指数を変えた超楕円断面のロフトに、SDF スカルプト（眼窩の隆起と開口、口唇、口裂、鰓蓋の縁、胸びれ基部、泌尿生殖突起、鼻孔、両眼の間の溝）を重ねて形状を作っています。尾柄は薄い刃状になって尾びれの基部へ移行します。 |
| 頭部 | 側面は、幼魚の側面写真に %SL 目盛りを当てて測りました（吻端の高さ、背側輪郭の立ち上がり、眼の位置、口裂、鰓蓋の縁）。上面・正面・斜め前方は、写真ごとに目印（吻端、左右の眼、口角）から正射影カメラを逆算し、同じ向きで描いたモデルの輪郭を重ねて比べ、形を直す作業を繰り返しました。上から見ると吻は先細りの丸い楔形で、眼の後ろから頬にかけて滑らかに幅が増します。正面から見ると口幅は頭幅の約6割で、頬は口の高さで最も張り出します。眼は頭頂に寄った盛り上がり（眼の間隔は眼径より狭い）に収まり、瞳は横・やや上・やや前を向きます。上唇は前が厚く、口角へ向かって細くなり、口角の後ろで頬へ回り込んで消えます。下唇は上唇より薄く、両側では上唇の内側に収まります。上唇は吻と同じオリーブ褐色に細かな黒色素胞が散り、下唇は淡いクリーム色です（口の縁だけ湿った粘膜のわずかな暖色）。唇の表面には横方向の細かなひだと微小な乳頭があり、周囲の皮膚より少しマットです。上顎はわずかに前に出ます。吻端はロフトのUVが一点に集まるため、正面から投影した専用テクスチャ（snout cap）で塗り分けています。頬は眼の下で張り出します。胴体メッシュは口裂と鰓蓋の縁で切り離してあり、口や鰓蓋が実際に開きます。口角の手前約1.6 mmは上下の唇が皮膚でつながったまま伸びるので、口を開けても角が丸く、口角まで裂けたような形にはなりません。 |
| 口と鰓の内部 | 口蓋・口底・頬の粘膜（開口部からしか光が入らないので奥ほど急に暗い）、口底の舌（先端が丸く自由な平たい葉状）、上下顎の歯（骨格標本に合わせ、外列は間隔をあけて並ぶ大きな円錐歯で、先端が後ろ・内側へ曲がる。下顎前端のものが最大。その内側に細かい絨毛状歯帯が2列。どちらも口角の少し手前まで並ぶ）、咽頭の奥に見える鰓弓と鰓弁の間の暗赤色、鰓蓋の裏打ち、鰓腔の壁、左右4本ずつの鰓弓と赤い鰓弁 |
| 眼 | 角膜の膨らみを持つ眼球（眼の関節に付いていて左右別々に動く）と、虹彩テクスチャ（暗いブロンズ色の虹彩、細い金色の瞳孔縁、金色の斑点） |
| リグ・アニメーション | 24 関節（脊椎 7 節と尾、頭、左右の下顎、左右の懸垂骨、前上顎骨、舌骨、左右の鰓蓋、眼、各ひれ）。懸垂骨は頬と鰓蓋を支える骨で、口蓋骨と舌顎骨の2か所で頭骨に関節し、その2点を結ぶ線を軸に横へ開きます。左右の下顎は方骨で蝶番のように下がると同時に、方骨が外へ動く分だけ結合部を中心に水平にも開きます。このため、あくびでは口が細い横長の隙間ではなく、幅広く丸く開きます。開く順番は、顎、次に舌骨と懸垂骨（頬が横に張り出す）、最後に鰓蓋です（吸い込み型の口の拡張と同じ前から後ろへの順）。閉じるときも同じ順で、最後に鰓蓋から水を吐きます。ハゼの鰓孔は体の横に限られるので、胸びれ基部より下では鰓蓋は開きません。ひれにはモーフターゲットを入れています（畳む、水流で後ろへしなる、胸びれを波打たせる）。glTF には `Idle`（毎分約70回の呼吸と胸びれのスカーリング）、`Swim`（8 Hz、振幅包絡 A(x)=L(0.02−0.08x+0.16x²)、波長 0.95L の亜鯵型遊泳）、`Yawn`（ゆっくり開いて保持し、素早く閉じてから鰓蓋で水を吐く）を収録しています。ビューアは同じ姿勢モデル（`src/fish/pose.js`）を手続き的に動かしています。 |
| ひれ | 鰭条数は文献値（第1背びれ VIII–IX、第2背びれ I,12–14、しりびれ I,11–12、胸びれ 20–22、腹びれ I,5）の範囲内で、第1背びれ VIII、第2背びれ I,13、しりびれ I,11、胸びれ 20（左右）、腹びれ I,5（左右）、尾びれは主鰭条 17（両端の2本は不分枝、15本分枝）＋上下3本ずつの副鰭条です。胸びれは骨格標本に合わせて丸い扇形にしました（最上位の鰭条は最長の約1/3で、中央が最長）。最上位2本と最下位1本は不分枝です。鰭条の間をプリーツ状に折った膜で作っています。左右の腹びれ（各 I,5）は癒合して楕円形の吸盤になっています。前縁は棘の間の膜（膜蓋）で閉じ、縁が付け根より約0.45 mm下がった浅いお椀形です。魚はこの縁で着底し、腹は砂からわずかに浮きます。泳ぐときは吸盤を畳んで腹に沿わせます。 |
| テクスチャ | 胴体 2048×1024：ベースカラー、法線（鱗・筋節・孔器・乳頭突起・皺）、AO／粗さ、色素（メラニン／虹色素胞／黄色素胞）、透過／厚み。ひれアトラス 2048²：色＋被覆率、法線、データ（鰭条・メラニン・虹色素胞・被覆率）。虹彩 1024² |
| 標準 PBR | `KHR_materials_transmission` / `volume` / `ior` / `clearcoat` と `KHR_mesh_quantization` を使っているので、他の glTF ビューアでもそれなりに半透明に表示されます。Khronos glTF Validator の結果はエラー 0、警告 0 です。 |
| 独自データ | マテリアルの `extras.mahaze` に体積プロファイル表（断面 512 個）、脊椎の配置、色素テクスチャへの参照を入れています。 |

## 半透明表現（`src/materials/`）

- **胴体（BodyMaterial）**: 不透明パスで描画し、深度も書き込みます。ブレンドは使わないので、描画順による破綻が起きません。透明感は、GLB に入れた解析的な体積をピクセルごとにレイマーチして計算しています。
  - 背景の透過: 水→組織→水の2回の屈折を追跡し、光路長に応じてチャンネル別に減衰させます。散乱しなかった成分はシャープに、前方へ散乱した成分はミップでぼかして合成するので、薄い尾部は透け、厚い頭部や腹部は乳白色に濁ります。
  - 逆光: 光源方向の組織の厚みに拡散近似の減衰をかけた透過光を加えます。薄い部分ほど飴色に光ります。
  - 内部構造: 脊柱（椎体の関節を含む）、神経棘・血管棘、W 字の筋隔膜、水平隔膜、鰓弁（血色）、頭骨を体積内の散乱・吸収分布として持っています。
  - 内臓と背骨: 脊柱（ガウス分布の管）と、肝臓・消化管・黒い腹膜・腎臓・心臓・脳・耳石（楕円体）が光を遮ります。光線が中を通る長さを解析的に積分するので、細い背骨や小さな耳石も粗いサンプリングで取りこぼしません。背景の透過・逆光の拡散光・表面近くの色味の3か所に効き、逆光では背骨が体の中ほどの暗い線として、内臓が胸びれ後方の影として見えます。砂に落ちる影にも、背骨と内臓の部分に濃い芯が入ります。「内部構造」スライダーで強さを変えられます。
  - 皮膚の色素: メラニン、虹色素胞、黄色素胞で入射側と出射側の両方を減衰させるので、黒い色素斑は逆光でも黒いまま残ります。浅い層と深い層の色素胞を分けて焼き込んであり、深いものはぼけて見えます。
  - 表面: 波長ごとに変えたラップ拡散で亜表面散乱を近似しています。厚みに応じて反射率も変え、濡れた皮膚の GGX と粘液膜の2ローブで光沢を出しています。
- **ひれ（FinMaterial）**: 薄い板の単散乱（HG 位相関数）で扱います。ひれ1枚ごとに、①透過率の乗算、②散乱光の加算の2パスで描き、毎フレーム奥から手前へソートしています。そのため色付きの透過も重なりも正しく描けます。ひれは背景バッファにも描いているので、薄い胴体の向こう側にあるひれも透けて見えます。
- **口・鰓の内部（InteriorMaterial）**: 濡れた粘膜、ひだ、鰓弁の縞模様。胴体と同じスケルトンでスキニングしています。
- **行動（`src/fish/Behavior.js` / `src/fish/pose.js`）**: 着底、方向転換、ダッシュ、滑空、着地、胸びれでの位置直し、背びれ立て、あくびを状態遷移で切り替えます。ひれの形（畳む・しなる・波打つ）と関節の姿勢は同じ関数から毎フレーム計算しています。
  - 方向転換は体で行います（ハゼの胸びれは推進の打ち下ろし向きで、舵取りには向きません）。まず眼が新しい方向を見て、頭が振れます。各体節は頭の向きの履歴を、体での位置に応じた遅れ（曲がりのパルスが約8体長/秒で尾へ伝わる）で追うので、体はC字に曲がってから尾へ向かって伸びます（ステージ1）。ダッシュの最初の尾の一打はC字と逆向きの振り戻しです（ステージ2）。
  - 体の置き方: 吸盤の縁、腹の線、尾びれ下葉にある接地点のうち、その姿勢で一番低いものが砂に触れる高さに体を置きます。ひれの砂に押し付けられた部分は、砂の上に平らに寝ます。
  - 胸びれ: ハゼの胸びれは、推進の打ち下ろし（胸びれを体側へ強く引き寄せる動き）に向いた作りです。位置直しは両方の胸びれを同時に使うホップで行います。全開で素早く後ろへかく推進（ストローク周期の30%）と、半分畳んでゆっくり戻す動きを交互に繰り返し、かくたびに体が少し前に出ます。ダッシュは強い一かきで始まり、あとは胸びれを細く畳んで体側に沿わせます。着地前は大きく開いてブレーキをかけ、そのまま砂に下ろします。鰭条は水に押されてしなり、かくときは先端が遅れ、泳いでいるときは後ろへ流れます。
  - 着底中は吸盤を軸に、泳いでいるときは重心（体長の約35%）を軸に回ります。頭の回転速度は約700°/秒までに抑えてあり、大きな方向転換ほど曲げを深くするのではなく時間をかけます。曲がる側の胸びれは支点として開き、外側は体に押し付けます。尾びれ・背びれは体節の角速度に遅れてしなります。
- **眼（EyeMaterial）**: 角膜で屈折させて虹彩に視差をつけ、瞳孔から突き出た水晶体の反射、虹彩の虹色の反射を加えています。
- **環境**: 水柱（スネルの窓と光芒）、コースティクス、半透明の魚が落とす色付きの柔らかい影、砂粒、マリンスノー。背景は「水中」と、写真資料に近い「明るい水槽」を切り替えられます。
- 解析表示: 「厚み」「透過光のみ」「内部構造」

## ファイル構成

```
index.html                 ビューア（UI）
src/main.js                読み込み、描画パス（背景バッファ → 本描画 MSAA HDR → トーンマップ）、照明、UI
src/materials/*.js         胴体・ひれ・眼・口と鰓の内部のシェーダーと共通 GLSL（すべてスキニング対応）
src/fish/pose.js           共通の姿勢モデル（体の波、ひれの状態、呼吸、あくび）
src/fish/Behavior.js       行動の状態遷移
src/scene/Environment.js   背景、砂底、浮遊粒子
src/scene/Post.js          ブルーム、ACES、ビネット
tools/build-model.mjs      GLB ビルド（tools/mahaze/*.mjs が形状・色素・ひれ・眼・口と鰓の内部・リグとクリップの定義）
vendor/three/              three.js r186（MIT）
```

参考写真（添付資料）は形態・斑紋・色調の照合にだけ使い、画像そのものはモデルに含めていません。
