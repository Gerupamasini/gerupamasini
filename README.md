# マハゼ幼魚（*Acanthogobius flavimanus*）写実 3D モデル — Three.js

全長 約50 mm（標準体長 41 mm）の幼魚を、生体の半透明感を重視して再現したモデルとビューアです。

- `models/mahaze_juvenile.glb` — 完成モデル（単位 m、+Y 背側、+Z 吻端方向）
- `index.html` + `src/` — 回転・拡大、正面光／逆光／側光の切替ができるビューア（独自シェーダー同梱）
- `tools/` — モデルを再生成するビルドスクリプト（形状・テクスチャはすべて手続き生成で、写真は貼っていません）

## 実行

```bash
npm run serve        # → http://localhost:8080/   （依存なし。three.js r186 は vendor/ に同梱）
npm install && npm run build:model   # GLB を作り直す場合のみ（約1分）
```

WebGL2 と `EXT_color_buffer_float` に対応したブラウザで動作します（デスクトップ版 Chrome、Edge、Firefox、Safari 17 以降）。

操作: ドラッグで回転、ホイール／ピンチで拡大（眼の接写まで）、右ドラッグで移動。キー `F` / `B` / `S` で正面光／逆光／側光、`1` / `2` / `3` でカメラ位置のプリセット。
URL パラメータで表示を固定できます（例: `?light=back&view=tail&env=tank`）。

## モデルの内容

| 部位 | 内容 |
|---|---|
| 胴体 | 77k 頂点。上下で指数を変えた超楕円断面のロフトに、SDF スカルプト（眼窩の隆起と開口、口唇、口裂、鰓蓋の縁、胸びれ基部、泌尿生殖突起、鼻孔、両眼の間の溝）を重ねて形状を作っています。尾柄は薄い刃状になって尾びれの基部へ移行します。 |
| 眼 | 角膜の膨らみを持つ眼球（左右別ノード）と、虹彩テクスチャ（金色の瞳孔縁、放射状の繊維、黒色素） |
| ひれ | 第1背びれ VIII、第2背びれ I+13、しりびれ I+11、尾びれ 17 本＋前縁の副鰭条、胸びれ 20 本（左右）、腹びれの吸盤。鰭条の間をプリーツ状に折った膜で作っています。 |
| テクスチャ | 胴体 2048×1024：ベースカラー、法線（鱗・筋節・孔器・乳頭突起・皺）、AO／粗さ、色素（メラニン／虹色素胞／黄色素胞）、透過／厚み。ひれアトラス 2048²：色＋被覆率、法線、データ（鰭条・メラニン・虹色素胞・被覆率）。虹彩 1024² |
| 標準 PBR | `KHR_materials_transmission` / `volume` / `ior` / `clearcoat` と `KHR_mesh_quantization` を使っているので、他の glTF ビューアでもそれなりに半透明に表示されます。Khronos glTF Validator の結果はエラー 0、警告 0 です。 |
| 独自データ | マテリアルの `extras.mahaze` に体積プロファイル表（断面 512 個）、脊椎の配置、色素テクスチャへの参照を入れています。 |

## 半透明表現（`src/materials/`）

- **胴体（BodyMaterial）**: 不透明パスで描画し、深度も書き込みます。ブレンドは使わないので、描画順による破綻が起きません。透明感は、GLB に入れた解析的な体積をピクセルごとにレイマーチして計算しています。
  - 背景の透過: 水→組織→水の2回の屈折を追跡し、光路長に応じてチャンネル別に減衰させます。散乱しなかった成分はシャープに、前方へ散乱した成分はミップでぼかして合成するので、薄い尾部は透け、厚い頭部や腹部は乳白色に濁ります。
  - 逆光: 光源方向の組織の厚みに拡散近似の減衰をかけた透過光を加えます。薄い部分ほど飴色に光ります。
  - 内部構造: 脊柱（椎体の関節を含む）、神経棘・血管棘、W 字の筋隔膜、水平隔膜、内臓塊と色素のある腹膜、鰓弁（血色）、頭骨を体積内の散乱・吸収分布として持っています。「内部構造」スライダーで強さを変えられ、既定値では控えめにしています。
  - 皮膚の色素: メラニン、虹色素胞、黄色素胞で入射側と出射側の両方を減衰させるので、黒い色素斑は逆光でも黒いまま残ります。浅い層と深い層の色素胞を分けて焼き込んであり、深いものはぼけて見えます。
  - 表面: 波長ごとに変えたラップ拡散で亜表面散乱を近似しています。厚みに応じて反射率も変え、濡れた皮膚の GGX と粘液膜の2ローブで光沢を出しています。
- **ひれ（FinMaterial）**: 薄い板の単散乱（HG 位相関数）で扱います。ひれ1枚ごとに、①透過率の乗算、②散乱光の加算の2パスで描き、毎フレーム奥から手前へソートしています。そのため色付きの透過も重なりも正しく描けます。ひれは背景バッファにも描いているので、薄い胴体の向こう側にあるひれも透けて見えます。
- **眼（EyeMaterial）**: 角膜で屈折させて虹彩に視差をつけ、瞳孔から突き出た水晶体の反射、虹彩の虹色の反射を加えています。
- **環境**: 水柱（スネルの窓と光芒）、コースティクス、半透明の魚が落とす色付きの柔らかい影、砂粒、マリンスノー。背景は「水中」と、写真資料に近い「明るい水槽」を切り替えられます。
- 解析表示: 「厚み」「透過光のみ」「内部構造」

## ファイル構成

```
index.html                 ビューア（UI）
src/main.js                読み込み、描画パス（背景バッファ → 本描画 MSAA HDR → トーンマップ）、照明、UI
src/materials/*.js         胴体・ひれ・眼のシェーダーと共通 GLSL
src/scene/Environment.js   背景、砂底、浮遊粒子
src/scene/Post.js          ブルーム、ACES、ビネット
tools/build-model.mjs      GLB ビルド（tools/mahaze/*.mjs が形状・色素・ひれ・眼の定義）
vendor/three/              three.js r186（MIT）
```

参考写真（添付資料）は形態・斑紋・色調の照合にだけ使い、画像そのものはモデルに含めていません。
