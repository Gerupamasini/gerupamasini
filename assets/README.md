# assets

- `models/kentish_plover.glb` — generated by `npm run export-glb`: LOD0 mesh (body, feathers, bill/legs, eyes),
  the 171-bone avian skeleton, plumage baked to vertex colours, and all baked clips
  (01_Idle, 02_Walk, 03_Run, 05_ForageSearch, 06_Peck_worm/crab, 07_Preen_×6, 07_Scratch, 07_WingStretch,
  07_Shake, 08_Rest_×3, 09_Alert, 10_Takeoff, 11_Flight, 12_Landing). Intended as an interchange asset
  (e.g. for sculpt/texture refinement in Blender); the runtime uses the procedural pipeline in `src/`.
- `textures/` — intentionally empty: plumage, feather, keratin and eye materials are procedural shaders
  (docs/optimization.md §3–4 describes the KTX2 pipeline for authored textures).
- `animations/` — intentionally empty: clips are embedded in the GLB; the runtime animation is procedural.
